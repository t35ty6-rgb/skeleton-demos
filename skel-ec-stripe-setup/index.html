SKEL·EC × STRIPE · SETUP

Skel·EC で 本物の決済 を 使えるようにする
— 小学生でも わかる Stripe Connect セットアップ —

Skel·EC で 「実際にクレジットカードで お買物が出来る」 ようにするには、 Stripe (ストライプ) という 決済システムと 繋ぐ必要があります。 このガイドは その作業を 順番に 写真付きで 説明します。 1度やれば 何個サロンが増えても 1クリックで繋がる仕組みです。

⏱ 約 10〜15 分 📋 1度だけ 💴 無料 (テストモード)

📖 これから何をするか (全体像)

Skel·EC は Stripe ConnectStripe Connect = 「複数のお店を 1個の親アカウントから まとめて 管理する仕組み」。 Skeleton が 親、 各サロンが 子。 売上は Stripe が 各サロンの口座に 直接振込む。 という仕組みを 使います。 これにより:

OWNER 吉田

1度だけ やる事

  • Stripe アカウント作成
  • テストキー (sk_test_) を Jobs に渡す
  • Connect 機能を 有効化
🤖 JOBS

自動で やる事

  • テストキーを サーバーに セット
  • 各サロン用の Connect 子アカウント 自動作成
  • 決済 webhook 自動接続
SALON 各店

サロンごとに やる事

  • admin から 「🚀 Stripe で接続」ボタン 押す
  • 本人確認・口座番号 入力 (5分)
  • 完了 → 即 決済受付開始
ポイント10店舗 = 10回 sk を集める という ダサい方式 ではなく、 1度 Skeleton側 を セットアップしたら、 サロン側 は admin の 1クリック で完了 する作りです。 これは Lea / Shopify / L-Message が やってる定石。

📚 出てくる用語の早見表 (7つだけ)

わからない言葉が出てきたら ここに戻って 見れば OK。 本文中の オレンジ下線こんな感じで タップ/マウス を 乗せると 説明が 出てくる仕組みです。 も 用語解説。

用語1Stripe (ストライプ)
= 世界で使われてる 決済代行サービス。 月額¥0、 1取引ごと 3.6%。 ジャパネット / Mercari / Shopify が 全部 使ってる。
用語2Connect (コネクト)
= Stripe の 「複数店舗を 親アカ から まとめる」 機能。 Skeleton が 親、 サロンが 子。
用語3Express (エクスプレス)
= Connect の 「簡単モード」。 サロンは 5分の フォーム入力 だけで OK。 KYC は Stripe側 が やってくれる。
用語4オンボーディング
= 「お店を 登録する 一連の作業」。 名前 / 住所 / 銀行口座 / 本人確認書類 を Stripe に 渡すこと。
用語5sk_test_xxxxx
= テスト用の 「秘密キー」。 これ で 開発中の決済を テスト可能。 本物カードは 通らない。 漏れても 大丈夫。
用語6sk_live_xxxxx
= 本番用の 秘密キー。 これ が 漏れると マジで 危ない。 本番開始 する時 だけ 使う。
用語7本人確認 (KYC)
= 「あなたが 本当に お店の人 か」 確認する 作業。 マイナンバーカード や 免許証 写真を Stripe に 送る。

10店舗 でも 決済 が 混ざらない 仕組み

オーナーが 気にしてた 「10店舗 の 決済 が 混ざらないか」 の 答え:

仕組み各サロン に 専用 の Stripe Connect アカウント (acct_xxx) が 作られる。 1サロン = 1アカウント。
決済が走るたびに metadata.tenantId = "サロン名" が 自動で 付く。
Stripe webhook が 受け取った時 metadata 見て 「サロンA の 決済 だ」 と 判定 → サロンA の 注文記録 に だけ 追加。
別サロンには 絶対 紛れない。

📋 よくある質問

既に Stripe アカウント 持ってる場合 は ?
Skel·EC 用に 新規アカウント を 作る ことを 推奨。 既存 (Mio EC / FP Compass 等) と 混ぜると 確定申告 が ややこしい。 同じメールでも 別アカウント 作成可。
本番モード (sk_live_) は いつ 使う ?
1〜2店舗 で テストモード で 動作確認 が 取れた後。 sk_live_ への 切替は 1コマンド。 既存サロン は そのまま 動く。
サロン が 本人確認 で 詰まった 場合 は ?
サロンが Stripe Dashboard に Stripe ID で ログイン → 「追加で 必要な書類」 を 確認 して 追加 アップロード。 完了したら 自動で Skel·EC admin に 反映。
Skeleton 手数料 (3.6% + ¥50) は 変更できる ?
変更可。 firebase functions:config:set stripe.platform_fee_pct=2.5 で 即変更。 各サロン の 売上 から 自動で 差し引かれる。
サロン から 「決済 が 動かない」 と クレーム が 来たら ?
admin の Stripe設定 で 「最新状態を 取得」 ボタン を 押す → 「未完了」 と 出れば KYC 残ってる。 「✓ 決済 準備完了」 なら Stripe 側 で エラー (Stripe Dashboard で エラーログ確認)。
テスト決済 を 試す には ?
shop で 商品を カート に入れ → 注文画面 で カード番号 4242 4242 4242 4242 / 有効期限 任意未来 / CVC 任意3桁 で 決済。 本物の お金は動かない。
