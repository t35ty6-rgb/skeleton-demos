📚 出てくる用語 (6つ だけ)

用語1Stripe (ストライプ)
= 世界最大級 の 決済代行 サービス。 1取引 3.6%。 ジャパネット / Mercari / Shopify が 使ってる。
用語2収納代行 (しゅうのうだいこう)
= 「A が B の 代わりに お金を 集めて、 後で B に 渡す」 仕組み。 コンビニ料金支払い も これ。 Skel·EC は Skeleton が A、 サロンが B。
用語3sk_test_xxxxx
= テスト用 秘密キー。 偽カード で 動作テスト 可能。 漏れても 危険性 ほぼ 0。
用語4sk_live_xxxxx
= 本番用 秘密キー。 これ が 漏れると 危ない。 本番運用 開始時 だけ 使う。
用語5Webhook (ウェブフック)
= Stripe が 「決済 完了したよ」 と Skel·EC に 通知する 専用URL。 これが ないと 注文記録が 作られない。
用語6whsec_xxxxx
= Webhook 署名シークレット。 偽の通知 を 弾くため の ハンコ。 Webhook URL 登録 後 に 発行される。

毎月の 振込 (自動)

JOBS

月末 締め → 翌月 1日 に Jobs が 自動で 各サロンの 売上合計 を 計算 → Skeleton 銀行口座 から 各サロン口座 へ 一斉振込。

具体例サロンA が 6月 に ¥30,000 売上 → Skeleton 手数料 ¥1,130 (3.6%+¥50×3件) 差引 → 7月1日 サロンA口座 に ¥28,870 入金。 admin の 「振込履歴」 に 自動記録。
⚠️ 大事: 初期 (1〜5サロン) は Jobs が 手動振込 + admin の recordPayout CF で 記録。 30サロン超 になったら 自動振込 cron に 切替 (全銀協 FB データ生成 → 手動 アップ or 全銀API)。
🛡

10店舗 でも 売上 が 混ざらない 仕組み

仕組み決済 1件 ごとに metadata.tenantId = "サロン名" が 自動付与。 Stripe webhook で metadata 見て 「サロンA の 決済 だ」 と 判定 → サロンA の 売上累計 にだけ 加算。 別サロンには 絶対 紛れない。 Firestore /tenants/{tenantId}/balance.pending_jpy に 累積。 月末 cron が 各サロン分を 集計 → 振込リスト生成。

Firestore データ構造:

/tenants/
  hikari-salon/
    balance.pending_jpy: 28,870 (6月分)
    balance.paid_total_jpy: 152,400
    payout_bank: { bank: 'みずほ', acct: '1234567' }
    orders/ (注文記録 別途)
  momoi-seikotsu/
    balance.pending_jpy: 67,200
    ...完全に別フォルダ

📋 よくある質問

Lea風 収納代行 って 法的に大丈夫 ?
日本では 年間 取扱高 1億円未満 なら 資金移動業 登録 不要 (収納代行スキーム)。 30〜50店舗 規模までは これで OK。 1億 超え そう になったら 司法書士相談 + 資金移動業者 登録。
サロンが 「振込が来ない」 とクレーム来たら ?
admin の 「振込履歴」 タブ を 開いて 確認。 当月分が pending_jpy に 計上されてれば 翌月1日振込予定。 振込済みなのに 着金してないなら 銀行 経由で 戻ってきてる (口座番号 間違い 等)。
返金 / チャージバック が 発生したら ?
Skeleton が 一旦 被る (Stripe ダッシュボードで処理)。 後で サロン に 請求書 で 戻し (収納代行 契約書 に明記)。 詐欺・カード偽造 等は Stripe の Radar が 大半弾く。
Skeleton 手数料 を 変更したい
変更可。 firebase functions:config:set stripe.platform_fee_pct=2.5 stripe.platform_fee_jpy=30 で 即変更。 既存 売上 累計には 影響なし、 次回決済 から 新料率。
本番モード (sk_live_) に 切り替えるタイミング ?
1〜2 サロン で テストモード 1ヶ月 動かして 振込フロー 含めて 検証 OK だった後。 切替 は 1コマンド (config:set stripe.platform_sk=sk_live_xxx)。 既存サロン は 何もしなくて 動き続ける。
テスト決済 を 試す には ?
shop で 商品 を カート に入れ → 注文画面 で カード番号 4242 4242 4242 4242 / 有効期限 任意未来 / CVC 任意3桁 → 決済 → admin の 「今月 振込予定」 が 加算 されれば 動作OK。
