— Concept

B'up の 3 つ の 軸

流行りの トレーニング でも、 短期の 数字 でもなく、 「壊さず 続けられる 日常」 を 一緒 に 組み立てます。 BODY · BEAUTY · BALANCE の 3 軸 が、 その ため の 骨格 です。

BODY
体を、 整える。

呼吸 · 体幹 · お尻 · 脚 の 順で、 自分 の 身体 を 使った トレーニング を 段階的 に。 マシン に 頼らず、 産後 や 40代 の 身体 に 無理 の ない 強度 で 積み重ねます。

BEAUTY
姿勢 と、 佇まい。

「痩せない」 「疲れやすい」 の 多く は、 姿勢 の 崩れ と 筋力 の アンバランス。 骨盤 · 肩 · 脚 の バランス を 整え、 立ち姿 · 歩き方 · 座り姿 を リ・デザイン します。

BALANCE
続けられる、 日常。

週1 でも、 月2 でも、 「行ける ペース」 で。 美肌食マイスター視点 の 食事 アドバイス と セット で、 極端 な 制限 なし。 「日常 の 自分 が 少しずつ 好き に なれる」 変化 を 目指します。

— For You

  • ✓

— Session

60分 の セッション の 流れ

初回 も、 2回目 以降 も、 4ステップ。 話す · 見る · 動く · 整える。 急がず、 その日 の 体調 に 合わせて 進めます。

STEP 01
Consultation · 約10分

まず は、 じっくり 話 を 聞く こと から。

今日 の 体調、 これまで の ダイエット歴、 生活リズム、 睡眠、 食事 の 傾向 まで、 一つ ずつ 丁寧 に 整理 して いきます。 特に 初回 は、 産後 の 身体 状態 や 過去 の 怪我 なども お聞き し、 無理 の ない スタート地点 を 一緒 に 決めます。

「早く 始めたい」 より も 「正しく 始める」 を 大切 に して いる ので、 ここで 急ぐ こと は ありません。 話して いる うち に、 ご自身 でも 気づいて いなかった 課題 が 見えて くる こと も あります。

所要 約10分
STEP 02
Posture Check · 約10分

骨盤 · 肩 · 脚 の バランス を 丁寧 に 確認。

「痩せない」 「疲れやすい」 の 原因 の 多く は、 姿勢 の 崩れ と 筋力 の アンバランス に あります。 鏡 の 前 で 立ち姿 · 座り姿 · 歩き方 を 確認 し、 どこ に 癖 が あるか、 どこ の 筋肉 が 使えて いない か を 見極めます。

産後 の 方 は 特に、 骨盤 の 開き や 反り腰、 抱っこ に よる 猫背 が 定着 しがち。 ここで 見つかった 課題 が、 そのまま トレーニング の 優先順位 に なります。

所要 約10分
STEP 03
Training · 約30分

その日 の 体調 に 合わせて、 自重中心 で。

マシン は 一切 使いません。 呼吸 · 体幹 · お尻 · 脚 の 順 で、 自分 の 身体 を 使った トレーニング を 段階的 に 組み立てます。 強度 は 「翌日 に 響かない ギリギリ」 を 狙って 調整 する ので、 続けやすさ が 違います。

体力 に 自信 の ない 方 でも、 5分 ごと に 小休憩 を 挟みながら 進める ので 大丈夫。 会話 しながら 進められる 強度 が 基本 です。 HIP · ヒールウォーキング 特化 の 日 など、 目的別 の カスタマイズ も 可能。

所要 約30分
STEP 04
Cool Down & Advice · 約10分

ストレッチ と、 次回 まで の 過ごし方 まで。

トレーニング後 は 入念 に ストレッチ。 当日 〜 翌日 の 身体 の 変化 を 最小限 に 抑え、 次 の セッション まで 良い 状態 を 保てる よう に します。 ここ が 雑 だと、 続かない 原因 に なります。

最後 に、 次回 まで の 「今日 から 意識 する こと」 を 1〜2個 だけ お伝え します。 食事 の ちょっとした 置き換え、 日常 での 姿勢 意識、 寝る前 の 1分 ストレッチ など、 無理 なく 続けられる 範囲 で。 美肌食マイスター としての 食事 アドバイス も ここで。

所要 約10分
