「Failed to send messages」 真因修正 core

プロバイダ 跨ぎ で userId が 不一致 だった 致命的バグ を 解消

真因
今まで customer.lineFriendId に 入れてた userId は Skelton プロバイダ 配下 の LIFF で取った値。 各 FP の bot は 別プロバイダ なので、 その userId に push 送れず 400 Failed to send messages エラー。
修正
公式LINE 友だち追加 → lineWebhook が follow event 受信 → その bot 自身 が 取った userId / アイコン / 名前 を customer doc に保存 → 即 ウェルカム + アンケートURL を 自動 push 送信。 この userId は その bot で push 100% 通る。
副産物
お客様 アイコン (pictureUrl) と 名前 (displayName) が CRM に 自動反映。 「アイコン取れてない / 名前ちゃんと取れてない」 問題 も 同時に 解決。
▼ 検証手順
  1. テスト用 別アカウント で 公式LINE を 友だち追加 解除 → もう一度 追加。
  2. 即座 に LINE で「ご登録ありがとうございます！」 + アンケートURL が 2通 届く こと。
  3. CRM (stg index.html) を 開いて、 顧客一覧 に そのお客様 が アイコン付き で 新規追加 されてる こと。
  4. 顧客モーダル → LINE タブ で 「✉ 返信」 から テスト送信 → 届く こと。 → 過去「Failed to send messages」 が 消えてる こと。
① 友だち追加 で ウェルカム 2通 届いた / アイコン+名前 反映 / 返信成功
弐

アンケート URL に userId 埋め込み

LIFF 「同意しますか」 で 詰む 問題 と 重複 customer 作成 防止

変更
ウェルカム push で 送る アンケート URL に ?uid=Uxxxxx を baked in。 お客様 タップ → 回答 → submitSurveyAnswer が uid で follow event で 作った customer doc を 引いて merge (新規作成しない)。
消える問題
① LIFF「同意しますか」 で 止まる / ② Bot Link Aggressive ON/OFF 依存 / ③ 同じお客様 が 重複 customer として 別エントリ で 入る バグ。
▼ 検証手順
  1. 上の テスト用 survey URL (?uid=TEST_UID_001) を 開く。
  2. 13問 全て 答えて 送信。
  3. CRM で 顧客一覧 → そのテスト顧客 が uid=TEST_UID_001 として 紐付いて 入ってる こと。
  4. もう一度 同じ URL で 別回答 を 送信 → 重複作成 されず 既存 doc に merge される こと。
② uid で 100% 紐付け / 重複作成なし

テナント別 カスタム質問 new

各 FP が 自分の 専門領域 に 合わせて 質問 を 追加 (最大 5問)

編集場所
account.html 内 「アンケート カスタム質問」 セクション (Zoom連携 の すぐ上)。
追加できる タイプ
選択肢式 (radio・1つ選ぶ) / 複数選択 (checkbox) / 自由記入 (textarea)。 選択肢 は 改行区切り 入力。
挿入位置
デフォルト Q9 (悩み) の 後ろ、 候補日 の 前。 顧客 から見れば 自然な 流れ。
保存先
Firestore: tenants/{tid}.surveyConfig.customQuestions
▼ 検証手順
  1. stg account.html を 開く (要ログイン)。
  2. 「アンケート カスタム質問」 セクション まで スクロール。
  3. 「＋ 質問を追加」 を 押す → カード が 出る。
  4. 例: 質問文 = 投資経験 は ありますか? / タイプ = 選択肢式 (radio) / 選択肢 = あり (改行) なし。
  5. 「保存」 → 「✓ 保存しました」 表示。
  6. stg survey を 開く → 13問 進める → Q9 (悩み) の 次 に カスタム質問 が 出る こと。
  7. 回答 → 送信 → CRM で 顧客 surveyAnswers に custom_1 = "あり" として 入ってる こと。
③ 編集 → 保存 → 顧客アンケート で 表示 → 回答 が CRM に 入る

判定: 全 3 項目 OK なら 「promote」

stg で 3項目 動作確認 できたら
LINE で 「promote」 と 一言 投げる → 本番 (app.skeleton-inc.jp) に 即同期。
1項目でも ダメ なら 何が変か LINE で 教えて → 即修正。
