🛠 マスタープロジェクト 初期作成ガイド

この作業は最初の1回だけでOK(以降は全クライアントがこのマスターのコピーを使う)
所要時間: 約30分 / Skeleton社内用ドキュメント

🎯 マスタープロジェクトとは?

ホットペッパー予約LINE通知ツールの「もとのプログラム」。Skeleton管理のGoogleドライブに1個だけ置いておく。

新しい客に納品するたびに「ファイル → コピーを作成」で複製して、各客固有の設定(LINEトークン等)を書き込む流れ。

→ つまり このページの作業は、Skeleton としてツール販売を始める時に1回だけやればOK。

この作業は Skeleton管理のGoogleアカウント(司の個人Gmail or 法人Skeleton用アカウント)でログインした状態で行います。各客のアカウントではない。
1

Skeleton管理のGoogleアカウントでログイン

⏱ 1分

ブラウザで Google にログイン中のアカウントを確認。違うアカウントなら切り替える。

  • 普段使ってる司の個人Gmail(t3.5ty6@gmail.com 等)でOK
  • もしくは Skeleton 法人用アカウントを作って使う(将来は推奨)
2

Google Apps Script を開く

⏱ 1分
🔗 Google Apps Script を開く

画面に「Apps Script」と書いてある黄色いページが開けばOK。

3

「新しいプロジェクト」をクリック

⏱ 30秒

画面の左上に「+ 新しいプロジェクト」と書かれた青い大きなボタンがあるので押す。

真っ白なエディタ画面が開いて、左サイドバーに Code.gs という1ファイルだけが表示されてるはず。

4

プロジェクト名を変える

⏱ 30秒

画面上部「無題のプロジェクト」と表示されているところをクリック。名前を消して下のように書く:

[MASTER] HotPepper Notify v1.0

Enterキーで確定。

5

デフォルトの Code.gs を削除

⏱ 30秒
  • 左サイドバーの Code.gs の右側にある「⋮」(縦三点)を押す
  • メニューから「削除」を選ぶ
  • 「ファイルを削除しますか?」のダイアログで「OK」
6

6つの .gs ファイルを順番に追加

⏱ 約20分(コピペ作業)

ローカルの hotpepper-line-tool/ フォルダにある6つのファイル(.gs)を、1つずつGASに追加していく。

1.Config.gs
2.Parser.gs
3.Line.gs
4.Calendar.gs
5.Main.gs
6.Diagnostics.gs

各ファイルの追加手順:

  1. 左サイドバーで「+ 新しいファイル」→「スクリプト」を選ぶ
  2. ファイル名を入れる(例: Config。.gsは自動で付く)
  3. VSCode等で hotpepper-line-tool/Config.gs を開く
  4. 中身を全選択(Cmd+A)→ コピー(Cmd+C)
  5. GASエディタに戻って、新規ファイルの中身を全選択→Delete→貼り付け(Cmd+V)
  6. 保存(Cmd+S)
  7. 残り5ファイルも同じ要領で追加
MonthlyReport.gs と BulkBroadcast.gs も同じディレクトリにあるけど、現時点ではマスターには含めなくてOK(将来オプション機能用)。
7

Config.gs の値を「テンプレ用デフォルト値」に整える

⏱ 2分

マスターのConfig.gsは、各客にコピーされる前の「ひな型」。具体的な客のトークンやグループIDは入れないので、こんな状態でOK:

const CONFIG = {
  LINE_CHANNEL_ACCESS_TOKEN: 'ここにLINEチャネルアクセストークンを貼る',
  LINE_TO_IDS: ['ここに通知先IDを貼る'],
  CALENDAR_ID: 'primary',
  CALENDAR_IDS: { hotpepper:'', rakuten:'', minimo:'', epark:'' },
  FROM_ADDRESS: '',
  ...
};

placeholder の文字列が残ってればOK。各客に納品時に setup-template が動的に置き換える。

8

「共有」を設定して、コピー可能にする

⏱ 2分

各客がこのマスターを開いて「コピーを作成」できるようにする。

  1. GASエディタの右上「共有」ボタンを押す
  2. 「一般的なアクセス」を「制限付き」→「リンクを知っている全員」に変更
  3. 権限は 「閲覧者」 にする(これでOK・「コピーを作成」は閲覧者でも可能)
  4. 「リンクをコピー」を押す
必ず「閲覧者」で。「編集者」にすると、誰かがマスターを書き換えると全クライアントに影響する。
9

マスターURLを社内ドキュメントに記録

⏱ 1分

STEP 8でコピーしたURLを、意思決定ログ/skeleton-master-gas.md に記録する。

新規ファイル作成内容:

# Skeleton マスター GASプロジェクト

- 名前: [MASTER] HotPepper Notify v1.0
- 作成日: 2026-05-13
- URL: https://script.google.com/d/.../edit (← STEP 8でコピーしたURL)
- 所有者: t3.5ty6@gmail.com
- バージョン履歴:
  - v1.0 (2026-05-13): 初期作成
10

動作確認

⏱ 5分

シークレットウィンドウで上のURLを開いて、自分の別Googleアカウントで「ファイル→コピーを作成」が押せることを確認。

確認後、シークレットで作ったコピーは削除しておく(ドライブ汚染防止)。

🎉 マスター作成完了!

これで以降は、新規クライアント納品のたびに各クライアントの onboarding-wizard / setup-template でこのマスターを参照する STEP 6 がそのまま動きます。

マスターのコードを更新したくなった時は、GASエディタで直接編集して保存すれば次の客から新版がコピーされます(過去のクライアントの稼働コピーは影響なし)。
