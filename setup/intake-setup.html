SKELETON INC.

申込フォームの
Sheets自動集約セットアップ

客の申込内容が自動でスプレッドシートに溜まる仕組みを作る(1回だけやればOK)

🎯 何をするか

客が 申込フォーム から送信した内容を、自動でGoogle Sheetsに記録する仕組みを作る。約15分。1回設定すれば以降ずっと自動。

この作業は Skeleton管理のGoogleアカウント(skeleton.admin@gmail.com 等の社内マスター)でログインして行う。客のアカウントではない。
1

客台帳スプレッドシートを開く(または新規作成)

⏱ 2分
  1. Skeleton社内の「客台帳」スプレッドシートを開く
  2. 下部の「+」ボタンで新しいシートを追加
  3. シート名を 申込フォーム に変える
  4. 1行目に以下を入れる(列ヘッダー):
    日時 / サロン名 / 住所 / 代表者 / スタッフ数 / 電話 / メール / 予約サイト / プラン / 備考
🔗 Google Sheetsを開く
2

SheetsのIDをコピー

⏱ 30秒
  1. SheetsのURLを見る:
    https://docs.google.com/spreadsheets/d/1AbCdEfGhIjKlMnOpQrStUvWxYz/edit
  2. 太字部分(/d/ と /edit の間)が Sheets ID。コピー
  3. このあとSTEP 4で使う
3

Google Apps Script で新しいプロジェクトを作る

⏱ 1分
  1. 下のボタンを押して script.google.com を開く
  2. 左上「+ 新しいプロジェクト」を押す
  3. 画面上部の「無題のプロジェクト」を Skeleton 申込フォーム受信 に変える
🔗 Google Apps Scriptを開く
4

下のコードを貼る → SHEET_ID を置換

⏱ 3分
  1. 下の「📋 コピー」を押す
  2. GASエディタの Code.gs の中身を 全部消す(Cmd+A → Delete)
  3. 貼り付け(Cmd+V)
  4. コード中の 'PUT_YOUR_SHEET_ID_HERE' を、STEP 2でコピーしたSheets IDに書き換える(' シングルクォートはそのまま)
  5. 保存(Cmd+S)
// Skeleton 申込フォーム受信用 Web App // このコードを Google Apps Script に貼り、SHEET_ID を置換してデプロイする const SHEET_ID = 'PUT_YOUR_SHEET_ID_HERE'; // ← ここを書き換える const SHEET_NAME = '申込フォーム'; function doPost(e) { try { const data = JSON.parse(e.postData.contents); const sheet = SpreadsheetApp.openById(SHEET_ID).getSheetByName(SHEET_NAME); sheet.appendRow([ new Date(), data.salonName || '', data.address || '', data.ownerName || '', data.staffCount || '', data.phone || '', data.email || '', (data.sites || []).join(' / '), data.planText || data.planCode || '', data.note || '' ]); return ContentService.createTextOutput(JSON.stringify({ok: true})) .setMimeType(ContentService.MimeType.JSON); } catch (err) { return ContentService.createTextOutput(JSON.stringify({ok: false, error: String(err)})) .setMimeType(ContentService.MimeType.JSON); } } // 動作確認用(GASエディタで手動実行できる) function testAppend() { const sheet = SpreadsheetApp.openById(SHEET_ID).getSheetByName(SHEET_NAME); sheet.appendRow([new Date(), 'テストサロン', '東京', '山田', '3', '090-xxx', 'test@example.com', 'ホットペッパー', 'デモ', 'テスト送信']); Logger.log('追加完了'); }
5

ウェブアプリとして公開する

⏱ 3分
  1. GASエディタの右上「デプロイ」ボタンを押す
  2. 「新しいデプロイ」を選ぶ
  3. 歯車マーク → 「ウェブアプリ」を選ぶ
  4. 設定を以下に:
    • 説明: 申込フォーム受信v1
    • 次のユーザーとして実行: 自分(skeleton管理アカウント)
    • アクセスできるユーザー: 全員
  5. 「デプロイ」を押す
  6. 「承認」ダイアログが出るので: 権限を確認 → 詳細 → プロジェクト名に移動 → 許可
  7. 「ウェブアプリのURL」が表示される。これをコピー
コピーしたURLが https://script.google.com/macros/s/AKfycb.../exec の形式ならOK
6

動作確認

⏱ 2分
  1. GASエディタで関数選択ドロップダウンから testAppend を選ぶ
  2. 「▶ 実行」を押す
  3. 客台帳Sheetsの「申込フォーム」タブを開く → テスト行が追加されてればOK
7

取得したURLをJobsに教える

⏱ 1分

STEP 5でコピーした https://script.google.com/macros/s/.../exec のURLを Jobs(俺)にチャットで送ってくれ。
俺が apply-form.html のコードに埋め込んで再デプロイする。

これで完了。以降、客が 申込フォーム から送信した内容は自動でSheetsの「申込フォーム」タブに行が追加される。

📊 出来上がりの流れ

  1. 司が客に申込フォームURLをLINEで送る
  2. 客がスマホで記入 → 「Skeletonに送信」を押す
  3. 自動で客台帳Sheetsの「申込フォーム」タブに行が追加される
  4. 司がSheetsを見て → Skeleton側で導入ウィザードのSTEP 0に転記 → STEP 1〜9で事前準備
  5. 当日 STEP 10〜12で現場作業
