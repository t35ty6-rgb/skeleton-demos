今 の 現実

ツールが 5つ に 散らかって、 客管理が 手作業。

予約は Google カレンダー、 決済は 銀行振込、 リマインドは LINE 手打ち、 回数券は Excel、 Zoom URL は 毎回 発行。 独立したい 気持ち は あるが、 事務作業 に 週10時間 溶けていく。

  • Zoom URL の 発行と 送信 を 毎回 手動
  • 回数券の 残数 を Excel で 管理、 客と 齟齬 が 起きる
  • リマインドは LINE 手打ち、 送り忘れる 日 も ある
  • 決済は 銀行振込、 未入金の 追跡 に 時間 が 取られる
  • 予約変更 の やりとり が すべて チャット

SkelFit を 使うと

1つの 画面 で、 客 と レッスン と 決済 が つながる。

予約 が 入れば Zoom URL が 自動発行、 前日 に LINE で リマインド、 決済は Stripe の サブスク 課金、 回数券 は 自動で 減算。 トレーナー は 「レッスンの中身」 に 100% 集中できる。

  • Zoom URL は 予約と 同時に 自動発行、 客の LINE に 直送
  • 回数券 の 残数 は 自動計算、 客側 LIFF に 常時 表示
  • 前日リマインド、 当日リマインド は cron 完全自動
  • 月4回 / 月8回 の サブスク を Stripe で 自動 課金
  • 予約変更 は 客が LIFF で 自己完結
機能

レッスン提供の 全部 を、 1つの ワークフロー に。

「予約 → Zoom → レッスン → 記録 → 次回予約」 の 一連 の 流れ を、 トレーナー が 何も 手打ち しないで 回せる 状態に する。

よくある質問

問い合わせ 前 に、 まず これ。

既存 の 客 は そのまま 移行 できますか? 離れませんか?
今 使ってる LINE 公式アカウント と Zoom アカウント を そのまま 引き継ぎます。 客 から 見ると 「予約フォーム が キレイになった」 「Zoom URL が 自動で 届く」 位 の 体感 で、 別サービス に 引っ越した という 感覚 は 出しません。 セットアップ時 に 既存客 リスト を CSV で 頂ければ こちら で 移行 します。
Zoom の 有料プラン は 必要 ですか?
1レッスン 40分 以内 なら Zoom 無料プラン で 動きます。 50分〜 の レッスン を 提供する なら Pro (¥2,000/月) が 必要 です。 SkelFit は Zoom API を 叩いて URL を 発行する だけ なので、 プラン は トレーナー が 自由に 選べます。
売上 に 手数料 が かからない のは 罠 が あるのでは?
ありません。 Stripe の 決済 手数料 (3.6% + ¥40) は 発生 しますが、 SkelFit の 取り分 は ゼロ。 月 ¥9,800 を 払う のは、 週10時間 の 事務作業 を 外注 する 対価 です。 「売上 に 応じて 手数料 が 増える」 モデル は トレーナー が 頑張るほど 損 する 構造 だから、 SkelFit は 月額 だけ の フラット に した。
1人 で 動かせますか? 事務 が 苦手 でも 大丈夫?
1人 で 動かせます。 セットアップ (Zoom / LINE / Stripe 接続) は こちら が 全部 代行、 客の カルテ 入力 も 音声 で メモ できる ので タイピング 苦手 でも 平気 です。 「レッスン 中 と 直前 直後 以外 は SkelFit を 開かなくて 済む」 状態 を 目指しています。
解約 したら 客 との つながり は 切れますか?
切れません。 LINE 公式アカウント と Zoom は トレーナー 名義 で 契約 されている ので、 SkelFit を 解約 しても 客との 連絡 手段 は そのまま 残ります。 SkelFit を 抜ける 時 は 客の カルテ を CSV で 出力 して お渡し します。
β 20名 に 入るか 入れないか、 決め手 は 何ですか?
β トレーナー の 選定 基準 は 「独立志向 か」 と 「既存 の 客が 5名 以上 いる か」 の 2つ です。 客 ゼロ から 始めたい 方 は Phase 2 で ご案内 します (集客 の 仕組み が Phase 2 で 追加予定 の ため)。 スケジュール が 埋まり 次第 一旦 締切 → Phase 2 (2026年 秋) で 追加募集。
