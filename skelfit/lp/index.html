今の現実

ツールが 5つに散らかって、 客管理が手作業。

予約は Google カレンダー、 決済は銀行振込、 リマインドは LINE 手打ち、 回数券は Excel、 Zoom URL は毎回発行。 独立したい気持ちはあるが、 事務作業に週10時間溶けていく。

  • Zoom URL の発行と送信を毎回手動
  • 回数券の残数を Excel で管理、 客と齟齬が起きる
  • リマインドは LINE 手打ち、 送り忘れる日もある
  • 決済は銀行振込、 未入金の追跡に時間が取られる
  • 予約変更のやりとりがすべてチャット

SkelFit を使うと

1つの画面で、 客とレッスンと決済がつながる。

予約が入れば Zoom URL が自動発行、 前日に LINE でリマインド、 決済は Stripe のサブスク課金、 回数券は自動で減算。 あなたは 「教える中身」 に 100% 集中できる。

  • Zoom URL は予約と同時に自動発行、 客の LINE に直送
  • 回数券の残数は自動計算、 客側 LIFF に常時表示
  • 前日リマインド、 当日リマインドは cron 完全自動
  • 月4回 / 月8回のサブスクを Stripe で自動課金
  • 予約変更は客が LIFF で自己完結

よくある質問

問い合わせ前に、 まずこれ。

既存の客はそのまま移行できますか? 離れませんか?
今使ってる LINE 公式アカウントと Zoom アカウントをそのまま引き継ぎます。 客から見ると 「予約フォームがキレイになった」 「Zoom URL が自動で届く」 位の体感で、 別サービスに引っ越したという感覚は出しません。 セットアップ時に既存客リストを CSV で頂ければこちらで移行します。
Zoom の有料プランは必要ですか?
1レッスン 40分以内なら Zoom 無料プランで動きます。 50分〜 のレッスンを提供するなら Pro (¥2,000/月) が必要です。 SkelFit は Zoom API を叩いて URL を発行するだけなので、 プランはトレーナーが自由に選べます。
売上に手数料がかからないのは罠があるのでは?
ありません。 Stripe の決済手数料 (3.6% + ¥40) は発生しますが、 SkelFit の取り分はゼロ。 月 ¥9,800 を払うのは、 週10時間の事務作業を外注する対価です。 「売上に応じて手数料が増える」 モデルはトレーナーが頑張るほど損する構造だから、 SkelFit は月額だけのフラットにした。
1人で動かせますか? 事務が苦手でも大丈夫?
1人で動かせます。 セットアップ (Zoom / LINE / Stripe 接続) はこちらが全部代行、 客のカルテ入力も音声でメモできるのでタイピング苦手でも平気です。 「レッスン中と直前直後以外は SkelFit を開かなくて済む」 状態を目指しています。
解約したら客とのつながりは切れますか?
切れません。 LINE 公式アカウントと Zoom はトレーナー名義で契約されているので、 SkelFit を解約しても客との連絡手段はそのまま残ります。 SkelFit を抜ける時は客のカルテを CSV で出力してお渡しします。
β 20名に入るか入れないか、 決め手は何ですか?
β トレーナーの選定基準は 「独立志向か」 と 「既存の客が 5名以上いるか」 の 2つです。 客ゼロから始めたい方は Phase 2 でご案内します (集客の仕組みが Phase 2 で追加予定のため)。 スケジュールが埋まり次第一旦締切 → Phase 2 (2026年秋) で追加募集。
