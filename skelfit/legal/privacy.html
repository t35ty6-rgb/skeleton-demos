プライバシーポリシー

最終 更新 2026-07-15

スケルトン株式会社 (以下 「当社」) は、 SkelFit (以下 「本サービス」) の 提供 に あたり、 お客様 の 個人情報 の 適切 な 保護 に 関する 責務 を 認識し、 個人情報保護法 その他 の 法令 を 遵守 します。

[OWNER 差替 マーカー] 黄色 ハイライト の 部分 は 実法人 登記 or 実 連絡先 で 差し替え て ください。

1. 取得 する 情報

1.1 トレーナー (契約者) から

  • 氏名 / メール / 電話番号 / 事業所所在地
  • 公開 プロフィール (公開名、 キャッチコピー、 経歴)
  • Zoom / LINE / Stripe の 連携 に 必要な 認証情報 (secret を含む)
  • 決済 情報 (クレジットカード情報 は Stripe が保持、 当社は 参照のみ)

1.2 客 (エンドユーザー) から

  • LINE の ユーザー ID / 表示名 / プロフィール画像
  • トレーナー との セッション 履歴、 予約 情報
  • 体組成 (体重 / 体脂肪率 / 筋肉量) — トレーナー が レッスン 指導 目的 で 記録
  • 目標 / メモ / セッション 中 の 会話 記録
  • 決済 情報 (Stripe 経由)

2. 利用 目的

  • トレーナー ⇔ 客 の レッスン 提供 に 必要な 予約 / 通知 / 決済 の 処理
  • 体組成 / 進捗 の 記録 と 可視化 (トレーニング 指導 の 質 向上 目的)
  • 本 サービス の 改善 と 障害対応
  • 法令 に基づく 対応 (税務、 会計、 個人情報 開示請求)

3. 第三者 提供

客 の 個人情報 は、 本人 の 同意 なく 第三者 に 提供 しません。 ただし 以下 は 「委託先 に 対する 提供」 に あたり、 別途 同意 なく 提供 します:

  • Zoom Video Communications, Inc. (Meeting URL 発行 目的)
  • LY Corporation (LINE 通知 送信 目的)
  • Stripe, Inc. (決済 処理 目的)
  • Google LLC (Firebase / Firestore / Cloud Functions の インフラ 提供)

4. 要配慮個人情報 の 取り扱い

体組成 (体重 / 体脂肪率 / 筋肉量) は、 個人情報保護法 に 定める 「要配慮個人情報」 に 直接 該当 は しませんが、 「健康 状態 に類する 情報」 として 慎重 に 取り扱います。

  • トレーナー が 客 の レッスン 指導 目的 に のみ 利用
  • 客 本人 は LIFF から いつでも 記録 の 参照 / 訂正 / 削除 が 可能
  • 解約 後 90日 で 削除 (決済 履歴 は 会計 法 に基づき 7年 保管)

5. 保管 期間

  • アカウント 情報: 契約 中 は 継続、 解約後 90日 で 削除
  • セッション / 体組成 記録: 解約後 90日 で 削除
  • 決済 履歴: 会計法 に基づき 7年 保管

6. 開示 / 訂正 / 削除 の 請求

お客様 は 当社 に 対し、 保有 する 個人情報 の 開示 / 訂正 / 削除 を 請求 する こと が できます。 下記 窓口 に メール で ご連絡 ください:

個人情報 保護 責任者: 吉田 司 / 連絡先: jobs@skeleton-fp.jp

7. 変更

本 ポリシー は 予告 なく 変更 する 場合 が あります。 重要 な 変更 は LINE と メール で 通知 します。
