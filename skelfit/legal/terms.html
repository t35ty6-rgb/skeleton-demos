利用規約 (β 版)

最終 更新 2026-07-15 / β 期間中 の 暫定 規約

[OWNER 差替 マーカー] 本規約 の 黄色 ハイライト 部分 (法人名 / 準拠法 の 裁判所) は 実法人 登記 完了時 に 正式化 して ください。 それ以外 は そのまま 使え ます。

第 1条 (適用)

本 規約 は SkelFit (以下 「本サービス」) を 利用 する すべて の トレーナー (以下 「利用者」) と スケルトン株式会社 (以下 「当社」) の 間 の 権利義務 を 定める もの です。

第 2条 (β 期間)

  1. 本 サービス は 現在 β 期間 で あり、 機能 追加 / 変更 / 削除 が 頻繁 に 発生 する 可能性 が あります。
  2. β 期間中 の セットアップ は 当社 の Skeleton staff が 手動 で 代行 します。
  3. β 期間 の 満了 タイミング は 別途 通知 します。

第 3条 (料金 と 決済)

  1. 本 サービス の 利用料 は LP 掲載 の 通り。
  2. Stripe 決済 手数料 (3.6% + ¥40/決済) は 客支払 から 差し引かれ、 利用者 の 手取り に 反映 されます。
  3. 30日 無料期間 の 満了 7日前 に LINE と メール で 事前 通知 します。

第 4条 (データ の 帰属)

  1. 利用者 が 本サービス に 登録 した 客 情報、 セッション 履歴、 決済 履歴 は、 すべて 利用者 に 帰属 します。
  2. 当社 は 本 データ を 本サービス の 提供 目的 に のみ 利用し、 第三者 提供 は しません (プライバシー ポリシー 記載 の 委託先 を 除く)。
  3. 解約時 は 客 の カルテ を CSV 形式 で 出力 して 利用者 に お渡し します。

第 5条 (解約)

  1. 利用者 は 24時間 いつでも admin panel から 解約 できます。
  2. 解約 の 効力 は 当月末、 提供済 期間 の 返金 は ありません。
  3. 解約後 90日 で アカウント と 客 データ を 削除 します (会計 法 に基づく 決済 履歴 は 7年 保管)。

第 6条 (禁止事項)

利用者 は 以下 の 行為 を 行っては なりません:

  • 法令 に 違反 する 行為
  • 第三者 の 権利 を 侵害 する 行為
  • 本 サービス の 運営 を 妨害 する 行為 (rate limit 逸脱、 不正 アクセス、 リバース エンジニアリング 等)
  • 薬機法 / 景表法 に 違反 する 表現 で 客 に 誤解 を 与える 行為

第 7条 (免責)

  1. 当社 は 本サービス の 障害 / 中断 / データ 消失 に 起因 する 損害 に つき、 β 期間中 は 一切 の 賠償 を しません。 β 卒業 後 は 別途 SLA を 定めます。
  2. Zoom / LINE / Stripe の 各社 サービス に 起因 する 障害 は、 各社 規定 に 従います。

第 8条 (準拠 法 と 管轄)

本 規約 の 準拠 法 は 日本法 と し、 本 サービス に関する 紛争 は 福井 地方裁判所 を 第一審 の 専属的 合意 管轄 と します。
