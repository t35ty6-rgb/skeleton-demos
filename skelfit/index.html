Zoom + 予約 + LINE + 決済。
それ全部、あなたの名前の教室で。

パーソナルトレーナー、ヨガ講師、音楽・語学の先生、カウンセラー。オンラインで 1on1(or 少人数)を教えるプロのためのインフラ。このデモは客側・トレーナー側の両画面を実際に触って動作確認できます。

FOR TRAINER · 業務ツール

トレーナー画面を触る

ダッシュボード、予約カレンダー、客カルテ、LINE 送信、食事管理 (AI 下書き)、宿題動画ライブラリまで。SaaS 側の全機能。

  • 今日の予約 → Zoom URL 自動発行
  • 客の食事写真 → 🤖 AI 下書き生成 → 編集して返信
  • 宿題動画 → YouTube URL 貼るだけ、客の LIFF に即反映
  • 客の「やった」ログが LINE トークに時系列で流れる

FOR CUSTOMER · スマホ画面

客の画面 (LIFF) を触る

成川歩花さん (デモ客) の視点。体重・食事・宿題を記録、トレーナーからのフィードバック確認、動画で運動、進捗をチャートで見る。

  • 体重・体脂肪率をワンタップ記録 → 折れ線グラフに追加
  • 食事写真 + メモ → トレーナーへ送信
  • 宿題動画 → ▶ 見る → ✓ やった で完了記録
  • 今日やったことがホームに時系列表示

デモの見どころ (3分ツアー)

客の画面で体重「63.9kg」を記録 → 「+ 食事を追加」で朝食メモ → 「宿題」タブで動画の「✓ やった」を押す
別タブでトレーナー画面 → LINE メッセージ → 山本美咲さんを選ぶ → 3件の緑バブル (🍔 体重/食事/宿題完了) が chat に混ざる
食事管理で未返信の食事 → 「🤖 AI 下書き生成」 → AI 生成文を編集 → 「送信」 → 客の LIFF に返る
公開 LP を見る (客に見せるページ) 動画を差し込む (YouTube URL 貼るだけ)

デモモードについて: データは全てブラウザの localStorageに保存されます。他の見る人には影響しません。リセットボタンで初期状態に戻せます。実運用時は Firebase Firestore にバックエンド接続し、tenant 分離+ LINE Bot 連携+ Zoom Server-to-Server OAuth で本番動作します。
