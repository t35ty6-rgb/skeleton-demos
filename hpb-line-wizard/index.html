手順 2 · 客先 で · 稼働 確認

手順 1 で 出た URL を 開いて 緑 確認

客先 に 着いたら、 手順 1 の ターミナル で 出た URL を タブレット の ブラウザ で 開く。 開いた 画面 の 一番 上 が 緑 の 「動いて ます ●」 なら 事前 準備 OK。

URL の 見た目
https://script.google.com/macros/s/AKfyc.../exec
  1. 事務所 で メモ した URL を ブラウザ で 開く
  2. 画面 の 一番 上 を 見る → 緑 の 「動いて ます ●」 なら OK
  3. もし 灰色 の 「まだ 動いて ない」 なら → 画面 下 の 緑 「本稼働 開始」 button を 一度 押す → 緑 に 変わる
「アプリを確認 していません」 の 警告 が 出た 場合: 左下 「詳細」 → 「移動 (安全 では ない ページ)」 → 一番下 「許可」 の 順 に 押す。 自社 で deploy した 画面 なので 安全。
次 に 進む タイミング
一番 上 が 緑 の 「動いて ます」 に なった
03
手順 3 · 客先 で · LINE 友だち追加

お客様 の LINE に bot を 追加

事前 に 用意 した 「LINE 友だち追加 QR」 を お客様 の スマホ で 読み取って もらう。 これ で お客様 の LINE に 通知 が 届く 準備 が 整います。

  1. お客様 に スマホ で LINE アプリ を 開いて もらう
  2. 用意 した QR コード を 画面 に 表示 or 印刷物 で 提示 → お客様 が LINE の 「友だち追加 → QR コード」 で 読み取り
  3. 友だち追加 が 完了 → 「(サロン名) 予約通知」 の アカウント が 友だち リスト に 追加 される
  4. お客様 に そのまま 待って もらう (何 も しない で OK)
QR は LINE Official Account Manager の 対象 アカウント の 「ホーム → 友だち追加」 画面 から いつでも 取得可。 QR 出せ ない 状況 なら 「友だち追加 URL」 を LINE で 送信 でも 代用可。
次 に 進む タイミング
お客様 の LINE に 「(サロン名) 予約通知」 が 追加 された
04
手順 4 · 客先 で · ホットペッパー 側

予約 メール の 送り先 を 変える

ホットペッパー (サロンボード) が 予約 通知 メール を 送る 先 を、 手順 1 の 出力 の 専用 アドレス に 変えます。 これ で 予約 が 入る と 通知 が 動き始めます。

サロンボード を 開く ↗
  1. お客様 に サロンボード の ID / パスワード を 教えて もらう → スタッフ が ログイン
  2. 右上 の 「店舗設定」 または 「各種設定」 を 押す
  3. 左 メニュー の 「メール送信先設定」 または 「予約通知メール設定」 を 選ぶ
  4. 「送信先 メール」 の 欄 に 手順 1 の 出力 の 専用 アドレス を 貼り付け → 「保存」
貼り付ける アドレス の 形
t3.5ty6+<お客様 の 名前>@gmail.com
アドレス を 忘れた 場合 は 手順 1 で 走らせた add-client.sh の 出力 log を 確認 (ターミナル の 上 に scroll、 or `~/.skeleton-hpb-clients/<slug>/` の log ファイル)。
次 に 進む タイミング
サロンボード の 画面 で 「保存 しました」 と 出た
05
手順 5 · 客先 で · 最終 確認

実 予約 で 通知 が 届く か 確認

サロンボード で ダミー の テスト予約 を 1件 入れて、 1分 待つ。 お客様 の LINE と カレンダー に 自動 で 反映 されれば 導入 完了。

  1. サロンボード の 予約管理 画面 で 「新規予約」 を 選ぶ
  2. 顧客名: テスト太郎 / 明日 の 適当 な 時間 / 適当 な メニュー で 予約 を 保存
  3. 1 分 待つ (何 も 押さ ない で OK)
  • お客様 の LINE に 「新規予約 テスト太郎 様」 の 通知 が 届く
  • お客様 に カレンダー 共有 招待メール (Gmail に 届いてる) を 開いて 「追加」 を タップ してもらう → お客様 の Google カレンダー に 予定 が 表示
    • 3 分 待っても LINE に 通知 が 届か ない 場合 → スケルトン に 連絡 (何時 何分 に テスト予約 したか + お客様 の LINE 名前 を 伝える)。
    次 に 進む タイミング
    LINE に 通知 が 届いた + カレンダー に 予定 が 表示 された
    ✓

    4. お客様 の カレンダー に 予約 の 予定 が 追加 される
