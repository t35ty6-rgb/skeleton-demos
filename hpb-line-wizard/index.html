01
手順 1 · スケルトン から の リンク を 開く

「動作 確認 画面」 を 開く

訪問前 に スケルトン から LINE か メール で 長い URL が 3 つ 届いてる はず。 その 中 の 「動作 確認 画面 URL」 と 書かれた もの を タップ して 開いて ください。 (この 画面 と は 別 の タブ で 開く)

見た目 の 例
https://script.google.com/macros/s/AKfyc.../exec
  1. スケルトン から 届いた LINE or メール を 開く
  2. 「動作 確認 画面 URL」 と 書かれた リンク を タップ → ブラウザ の 別タブ で 開く
  3. 開いた 画面 の 一番 上 を 見る → 緑 の 「動いて ます ●」 の 表示 が あれば OK
  4. もし 灰色 の 「まだ 動いて ない」 の 表示 なら → 画面 を 下 に スクロール → 緑 の 「本稼働 開始」 button を 一度 押す → 表示 が 緑 に 変わる
「アプリを確認 していません」 の 警告 が 出た 場合: 左下 「詳細」 → 下 に 出る 「移動 (安全 では ない ページ)」 → 一番下 の 「許可」 の 順 に 押す。 スケルトン が 作った 自社 の 画面 なので 安全 です。
URL が 見つから ない 時: スケルトン の 担当者 に LINE で 「動作 確認 画面 の URL 送って」 と 連絡 → 5 分 以内 に 送って もらえる。
次 に 進む タイミング
開いた 画面 の 一番 上 が 緑 の 「動いて ます」 に なった
02
手順 2 · LINE 友だち追加

お客様 の LINE に bot を 追加

スケルトン から 届いた 「LINE 友だち追加 QR」 を お客様 の スマホ で 読み取って もらう。 これ で お客様 の LINE に 通知 が 届く 準備 が 整います。

  1. お客様 に スマホ で LINE アプリ を 開いて もらう
  2. スケルトン から 届いた QR コード を 提示 → お客様 が LINE の 「友だち追加 → QR コード」 で 読み取り
  3. 友だち追加 が 完了 → 「(サロン名) 予約通知」 の アカウント が 友だち リスト に 追加 される
  4. お客様 に そのまま 待って もらう (何 も しない で OK)
QR コード が 見つから ない 場合 は スケルトン に 連絡 → 「友だち追加 URL」 を LINE で 送って もらう (お客様 が タップ するだけ)。
次 に 進む タイミング
お客様 の LINE に 「(サロン名) 予約通知」 が 追加 された
03
手順 3 · ホットペッパー 側 の 設定

予約 メール の 送り先 を 変える

ホットペッパー (サロンボード) が 予約 通知 メール を 送る 先 を、 スケルトン から 届いた 専用 アドレス に 変えます。 これ で 予約 が 入る と 通知 が 動き始めます。

サロンボード を 開く ↗
  1. お客様 に サロンボード の ID / パスワード を 教えて もらう → スタッフ が ログイン
  2. 右上 の 「店舗設定」 または 「各種設定」 を 押す
  3. 左 メニュー の 「メール送信先設定」 または 「予約通知メール設定」 を 選ぶ
  4. 「送信先 メール」 の 欄 に スケルトン から 届いた 専用 アドレス を 貼り付け → 「保存」
貼り付ける アドレス の 形
t3.5ty6+<お客様 の 名前>@gmail.com
アドレス が 見つから ない 場合 は スケルトン に 連絡 → 「どの アドレス を 貼れば いい?」 と 聞く。
次 に 進む タイミング
サロンボード の 画面 で 「保存 しました」 と 出た
04
手順 4 · 動作 の 最終 確認

実 予約 で 通知 が 届く か 確認

サロンボード で ダミー の テスト予約 を 1件 入れて、 1分 待つ。 お客様 の LINE と カレンダー に 自動 で 反映 されれば 導入 完了。

  1. サロンボード の 予約管理 画面 で 「新規予約」 を 選ぶ
  2. 顧客名: テスト太郎 / 明日 の 適当 な 時間 / 適当 な メニュー で 予約 を 保存
  3. 1 分 待つ (何 も 押さ ない で OK)
  • お客様 の LINE に 「新規予約 テスト太郎 様」 の 通知 が 届く
  • お客様 に カレンダー 共有 招待メール (Gmail に 届いてる) を 開いて 「追加」 を タップ してもらう → お客様 の Google カレンダー に 予定 が 表示
    • 3 分 待っても LINE に 通知 が 届か ない 場合 → スケルトン に 連絡 (何時 何分 に テスト予約 したか + お客様 の LINE 名前 を 伝える)。
    次 に 進む タイミング
    LINE に 通知 が 届いた + カレンダー に 予定 が 表示 された
    ✓

    導入 完了

    予約 が 入ったら 1 分 以内 に 客 の LINE と 客 の カレンダー に 自動 反映 される。

    最後 の 確認 (これ が 通れば 完璧)
    1. お客様 の サロンボード で テスト 予約 を 1件 入れる
    2. 1 分 待つ (button は 何 も 押さ ない)
    3. 手順 2 で 作った LINE 公式 アカウント に 予約 通知 が 届く
    4. お客様 の カレンダー に 予約 の 予定 が 追加 される
