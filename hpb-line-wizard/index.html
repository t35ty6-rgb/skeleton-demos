訪問 前 に 用意 する 3 つ
  • スケルトン から 送られて きた 専用 URL (LINE や メール で 届いてる)
  • スケルトン から 送られて きた お客様 用 の メール アドレス (t3.5ty6+... の 形式)
  • お客様 の スマホ で LINE と サロンボード に ログイン できる 状態
01
手順 1 · まず 画面 を 開く

専用 URL を 開いて 許可 する

スケルトン から 届いた 専用 URL を 下 の 欄 に 貼り付けて 「開く」 を 押す。 開いた 画面 で 「許可」 を 押すと 設定 用 の 画面 が 出て きます。

専用 URL を 貼り付け
  1. 開いた 画面 の 左下 に ある 「詳細」 の 文字 を 押す
  2. 下 に 出る 「(プロジェクト名) に 移動 (安全 では ない ページ)」 を 押す
  3. 次 の 画面 の 一番下 の 「許可」 button を 押す
  4. 3 枚 の 白い カード が 並んだ 設定 の 画面 が 表示 されれば OK
「安全 では ない」 は 怖い 表示 に 見える けど 大丈夫: スケルトン が 作った 自社 用 の 画面 に Google が 自動 で 出す 定型 警告 です。 押して 進めて OK。
次 に 進む タイミング
3 枚 の 白い カード の 設定 画面 が 出た
02
手順 2 · LINE の 準備

LINE 公式 アカウント を 作る

お客様 の LINE で 公式 アカウント を 作って、 通知 に 使う 「長い 文字列」 と 「ID」 の 2 つ を メモ します。 少し 手順 多い ので 落ち着いて。

LINE Business の 画面 を 開く ↗
  1. お客様 の LINE アカウント で ログイン → 右上 「アカウント 作成」 → サロン名 を 入力 → 無料 プラン で 作成
  2. 作成後、 右上 の 「設定」 (歯車 マーク) を 押す → 左 メニュー の 「Messaging API」 → 「利用する」 を 押す
  3. 別 の 画面 (LINE Developers) に 移動 する → 上 の タブ で 「Messaging API 設定」 を 押す → 画面 を 一番下 まで スクロール
  4. 「チャネル アクセストークン (長期)」 の 欄 の 「発行」 を 押す → 出て きた 長い 文字列 (200 文字) を コピー
  5. 同じ 画面 の 「あなたの ユーザーID」 の 「U」 で 始まる 33 文字 を コピー
「再発行」 は 絶対 押さない: 初めて の 時 は 「発行」 だけ。 「再発行」 を 押す と 前 の 文字列 が 使え なく なります。
次 に 進む タイミング
長い 文字列 (200文字) と U... 33 文字 を メモ 帳 に 貼り 付けた
03
手順 3 · 設定 画面 に 貼り付け

メモ した 3 つ を 設定 画面 に 貼る

手順 1 で 開いた 設定 の 画面 (白い カード が 並んでる 画面) に 戻る。 一番上 の 「LINE 通知先」 の カード に、 手順 2 で メモ した もの を 貼り付けます。

  1. 「チャネル アクセストークン (長期)」 の 欄 に 200 文字 の 文字列 を 貼り付け
  2. 「通知先ID」 の 欄 に U で 始まる 33 文字 を 貼り付け
  3. 「サロン名」 の 欄 に お客様 の サロン 名 を 入力 (例: 「ヘアサロン花子」)
  4. 画面 右下 の 緑 の 「保存」 button を 押す
次 に 進む タイミング
画面 下 に 「保存 しました」 と 緑 の 文字 が 出た
04
手順 4 · 動作 の 確認

試しに 通知 を 送って みる

設定 画面 に 戻り、 3 番目 の カード (動作テスト) を 開いて、 上 から 順 に 4 つ の button を 押す だけ。

  1. 1 番 の button: 「試しに LINE に 通知 を 送る」 → お客様 の LINE に 「テスト太郎 様 の 予約 が 入りました」 が 届く
  2. 2 番 の button: 「試しに カレンダー に 予定 を 入れる」 → Google カレンダー の 明日 に 「予約 · テスト太郎」 の 予定 が 追加 される
  3. 3 番 の button: 「メール を 試しに 読む」 → まだ 予約 メール が 来て ない ので 空振り で OK
  4. 4 番 (緑) の button: 「本番 の 動作 を 開始 する」 → 画面 上 の 表示 が 灰色 の 「まだ 動いて ない」 から 緑 の 「動いて ます」 に 切り替わる
1 番 の button で 「status=429」 の 赤い エラー が 出た 場合 → LINE の 別 設定 が 邪魔 してる の が 原因。 次 の 手順 5 で 直します、 今 は 気 に せず 進んで OK。
次 に 進む タイミング
画面 上 の 表示 が 緑 の 「動いて ます」 に なった
05
手順 5 · LINE の 邪魔 な 機能 を 切る

LINE の 5 項目 を 表 の 通り に

LINE の 初期 設定 の まま だと、 誰か が LINE に 話しかけた 時 に 自動 で 返信 してしまって 月 の 上限 200 通 を 使い切って しまい ます。 それ を 止める 作業。

LINE の 管理画面 を 開く ↗
  1. お客様 の LINE 公式 アカウント を 選ぶ
  2. 右上 の 「設定」 (歯車 マーク) を 押す → 左 メニュー の 「応答設定」
  3. 下 の 表 の 通り に 5 項目 を 切り替え → 一番下 の 「保存」 を 押す
項目設定 する 値
応答モードBot
応答メッセージOFF
あいさつメッセージOFF
WebhookOFF
グループ トーク の 参加ON
次 に 進む タイミング
5 項目 全部 が 表 通り に なって 「保存」 を 押した
06
手順 6 · ホットペッパー 側 の 設定

予約 メール の 送り先 を 変える

ホットペッパー (サロンボード) が 予約 通知 メール を 送る 先 を、 スケルトン から もらった 専用 アドレス に 変えます。 この 作業 で 予約 メール が 仕組み に 届く ように なります。

サロンボード を 開く ↗
  1. お客様 が サロンボード に ログイン
  2. 右上 の 「店舗設定」 または 「各種設定」 を 押す
  3. 左 メニュー の 「メール送信先設定」 または 「予約通知メール設定」 を 選ぶ
  4. 「送信先 メール」 の 欄 に スケルトン から もらった 専用 アドレス を 貼り付け → 「保存」
貼り付ける アドレス の 形
t3.5ty6+<お客様 の 名前>@gmail.com
アドレス は スケルトン から 事前 に 送られて きて ます (メール や LINE で)。 見つから ない 場合 は スケルトン の 担当者 に 「どの アドレス を 貼れば いい?」 と 聞く。
次 に 進む タイミング
サロンボード の 画面 で 「保存 しました」 と 出た
07
手順 7 · カレンダー を お客様 に 共有

お客様 用 の カレンダー を 作る

予約 が 入った 時 の 予定 を お客様 が 自分 の カレンダー アプリ で 見られる ように、 お客様 専用 の カレンダー を 新しく 作って 共有 します。

Google カレンダー を 開く ↗
  1. 左 メニュー の 「他 の カレンダー」 の 右 に ある 「+」 を 押す → 「新しい カレンダー を 作成」 を 選ぶ
  2. カレンダー 名 に お客様 の サロン 名 を 入力 → 「カレンダー を 作成」 を 押す
  3. 左 メニュー に 出て きた その カレンダー に カーソル を 合わせて 「⋮」 (三 点) → 「設定 と 共有」 を 押す
  4. 下 に スクロール → 「特定 の ユーザー と 共有」 → 「ユーザー を 追加」 で お客様 の Gmail を 入力 → 「送信」
  5. 同じ 画面 を もっと 下 に スクロール → 「カレンダーID」 の 長い 文字列 (末尾 に @group.calendar.google.com) を コピー
  6. 最初 の 設定 画面 に 戻る → 3 番目 の カード (動作 テスト) の 中 の 「高度な 設定」 を 開いて → 「Google カレンダー ID」 の 欄 に 貼り付け → 「保存」
次 に 進む タイミング
お客様 に メール で 招待 が 届く / お客様 が 「追加」 を 押す
✓

導入 完了

予約 が 入ったら 1 分 以内 に 客 の LINE と 客 の カレンダー に 自動 反映 される。

最後 の 確認 (これ が 通れば 完璧)
  1. お客様 の サロンボード で テスト 予約 を 1件 入れる
  2. 1 分 待つ (button は 何 も 押さ ない)
  3. お客様 の LINE に 予約 通知 が 届く
  4. お客様 の カレンダー に 予約 の 予定 が 追加 される
