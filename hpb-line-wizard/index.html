Phase C · 接続 と 稼働

客用 カレンダー を 作って 共有

owner の Google カレンダー に 客専用 サブカレンダー を 作り、 客 の Gmail に 共有 する。 客 は 自分 の カレンダー アプリ から 予約 一覧 を 見られる。

STAFF が 操作
Google カレンダー を 開くcalendar.google.com ↗
Part 1 · サブカレンダー を 作る
  1. 右上 アイコン で t3.5ty6@gmail.com に 切替
  2. 左メニュー 「他 の カレンダー」 の + → 「新しい カレンダー を 作成」
  3. 名前: サロン名 (例: サロン花子) → 「カレンダー を 作成」
Part 2 · 客 に 共有
  1. 作った カレンダー を 左メニュー で hover → ⋮ 三点 → 「設定 と 共有」
  2. 下 に scroll → 「特定 の ユーザー や グループ と 共有」 → 「ユーザー や グループ を 追加」
  3. 客 の Gmail アドレス を 入力 → 権限 「予定 の 表示 (すべて の 予定 の 詳細)」 → 「送信」
  4. 客 に 招待メール が 届く → 「追加」 で 客 の カレンダー に 表示 開始
Part 3 · カレンダーID を 設定パネル に 貼付
  1. 同 「設定 と 共有」 画面 の 下 に scroll → 「カレンダーID」 の 欄
  2. 末尾 @group.calendar.google.com を 含む 長い ID を コピー
  3. 設定 パネル の Section 3 → 高度な 設定 → Google カレンダー ID に 貼付
  4. 「保存」 クリック → 以降 の 予約 は 客専用 カレンダー に 入る
先 に これ を やって おく と 綺麗: STEP 08 の 試験 前 に 済ませて おく と 試験 の テスト イベント も 客専用 カレンダー に 入る (primary に 残らない)。
