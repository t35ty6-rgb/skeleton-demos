開始 前 の 確認
  • owner から 設定 URL を もらった (LINE / Slack で)

01
Step 01 · スタート

owner から の URL を 開く

LINE / Slack で もらった 設定 URL を 下 に 貼付 → 「開く」。 初回 は 認証 3 クリック。

設定 URL
  1. 開いた 画面 で 「詳細」 → 「(プロジェクト名) に 移動 (安全 では ない ページ)」
  2. 権限 リスト の 一番下 「許可」
  3. 設定 パネル (青 の 3 枚 の カード) が 表示 された ら OK
「安全 では ない」 は Google の 定型 warning。 owner の 自作 script なので 承認 で 問題 なし。
この step の 完了 条件
設定 パネル が 表示 された
02
Step 02 · LINE 準備

客 の LINE で 3 つ 取得

客 が LINE Business に ログイン → 公式アカウント 作成 → チャネル 発行 → 2 つ の 値 を もらう (トークン + 通知先ID)。

LINE Business を 開く ↗
  1. 客 の LINE で ログイン → 「新しい アカウント を 作成」 (無料 プラン)
  2. 画面 右上 設定 → 「Messaging API を 利用する」 を ON
  3. LINE Developers Console に 遷移 → 「Messaging API 設定」 タブ の 一番下
  4. 「チャネル アクセストークン (長期)」 → 「発行」 で 200 文字 が 出る → コピー
  5. 同じ 画面 の 「あなたの ユーザーID」 の U で 始まる 33 文字 を コピー
「発行」 じゃ なく 「再発行」 は 押さない (他 端末 の トークン が 死ぬ)
この step の 完了 条件
トークン (200文字) と 通知先ID (U... 33文字) を メモ した
03
Step 03 · 設定 パネル

3 値 を 貼付 して 保存

STEP 01 の 設定 パネル に 戻り、 Section 1 (LINE 通知先) の form に 3 値 を コピペ。

  1. チャネル アクセストークン の 欄 に 200 文字 を 貼付
  2. 通知先ID の 欄 に U... 33 文字 を 貼付
  3. サロン名 の 欄 に 客 サロン 名 を 入力
  4. 右下 の 緑 「保存」 button を クリック
この step の 完了 条件
「保存 しました」 の 緑 メッセージ が 出た
04
Step 04 · 動作 テスト

試験 3 個 → 本稼働 開始

設定 パネル の Section 3 を 展開。 button を 上 から 順 に 押す だけ。

  1. 試験 ① LINE に テスト通知 → 客 の LINE に 「新規予約 テスト太郎」 が 届く
  2. 試験 ② カレンダー に テスト登録 → Google カレンダー の 明日 に 予定 が 出る
  3. 試験 ③ 直近メール 解析 → 今 は 空振り で OK (メール まだ 届いて ない)
  4. ④ 本稼働 開始 の 緑 button → 上部 pill が 「稼働中」 に 変わる
試験 ① で 「status=429」 の エラー → LINE 応答メッセージ が ON の まま で 上限 到達。 STEP 05 で 直す。
この step の 完了 条件
上部 pill が 「稼働中」 に なった
05
Step 05 · LINE 応答 設定

LINE の 4 項目 を 直す

客 の LINE 公式アカウント の 応答設定 を 下 の 表 の 通り に。 これ で 月間 200通 を 予約通知 に 全部 使える。

Official Account Manager を 開く ↗
  1. 対象 アカウント → 右上 設定 → 左 「応答設定」
  2. 下 の 表 の 通り に 5 項目 を 設定 → 「保存」
項目値
応答モードBot
応答メッセージOFF
あいさつメッセージOFF
WebhookOFF
グループ トーク の 参加ON
この step の 完了 条件
応答設定 5 項目 を 保存 した
06
Step 06 · サロンボード

サロンボード の 宛先 変更

予約通知 メール の 送信先 を owner から もらった 客専用 アドレス に 差し替え。

サロンボード を 開く ↗
  1. 客 が サロンボード に ログイン
  2. 右上 「店舗設定」 or 「各種設定」
  3. 「メール送信先設定」 or 「予約通知メール設定」
  4. 送信先 メール を owner から もらった アドレス に 変更 (t3.5ty6+... の 形式) → 保存
貼付 する アドレス (owner が 教える)
t3.5ty6+<客slug>@gmail.com
この step の 完了 条件
サロンボード で 「保存」 が 完了 した
07
Step 07 · カレンダー 共有

客 の カレンダー に 反映

owner の Google カレンダー に 客専用 サブカレンダー を 作って、 客 の Gmail に 共有。 客 は 自分 の カレンダー アプリ で 予約 が 見える ように なる。

Google カレンダー を 開く ↗
  1. 左メニュー 「他 の カレンダー」 の + → 「新しい カレンダー を 作成」 → 客 サロン名
  2. 作成 後、 左メニュー で 客カレンダー を hover → ⋮ 三点 → 「設定 と 共有」
  3. 「特定 の ユーザー と 共有」 → 客 の Gmail を 追加 → 権限 「予定 の 表示」 → 送信
  4. 同 画面 下 の カレンダーID (@group.calendar.google.com 付き) を コピー
  5. 設定 パネル の Section 3 → 高度な 設定 → Google カレンダー ID に 貼付 → 保存
この step の 完了 条件
客 の Google カレンダー に 客カレンダー が 表示 された
✓

導入 完了

予約 が 入ったら 1 分 以内 に 客 の LINE と 客 の カレンダー に 自動 反映 される。

最終 確認
  1. サロンボード で テスト予約 を 1件 追加
  2. 1 分 待つ (手動 button は 押さない)
  3. 客 の LINE に 予約通知 が 届く
  4. 客 の カレンダー に イベント が 追加 される
