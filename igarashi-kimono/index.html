08 · For partners

ホテル · 旅行会社 向け、
a dedicated flow.

個人予約 と ホテル / 旅行会社 経由 の 予約 を 別 管理 する ため、 二重予約 リスク を 排除。 パートナー 専用 の 管理画面 · 卸価格 · 請求書払 に 対応 します。

Track A · 個人予約

Direct booking

Web · Instagram · LINE 経由 の 個人客。 都度決済 (Stripe)。 単価 は 定価。

  1. 予約 サイト から プラン 選択
  2. クレジット 決済 → 確定
  3. 実動日 に 対応
  4. 実動翌日 レビュー 依頼
Track B · ホテル 経由

Hotel concierge

提携 ホテル の コンシェルジュ 経由。 15〜20% 卸価格。 月末 一括請求。

  1. ホテル 専用 管理画面 で 予約 登録
  2. Igarashi 側 で 承認 · 二重 チェック
  3. 実動日 に ホテル へ 出張
  4. 月末 に ホテル へ 請求書 発行
Track C · 旅行会社 経由

Travel agency

Klook · GetYourGuide · JTB 等 の 旅行会社 経由。 20〜25% 手数料。 API 連携 対応。

  1. API 経由 の 空き 照会
  2. 予約 確定 → 自動 スロット 押さえ
  3. 実動日 に 対応
  4. 月次 レポート · 支払
✓

二重予約 完全 防止

3 track の 空きスロット は 1つ の DB で 一元管理。 A で 予約 が 入った 瞬間 に B / C の 空き からも 引き算、 逆も 同様。 手動 突き合わせ ゼロ。
