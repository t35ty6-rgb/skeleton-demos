MapsLeads 利用規約

最終改訂日: 2026 年 7 月 31 日

本利用規約 (以下 「本規約」) は、 スケルトン株式会社 (以下 「当社」) が 提供 する Chrome 拡張機能 「MapsLeads」 (以下 「本サービス」) の 利用条件 を 定める もの です。 本サービス を 利用 する 全ての 方 (以下 「利用者」) は、 本規約 に 同意 した もの と みなし ます。

第 1 条 (適用範囲)

本規約 は、 本サービス の 提供条件 および 本サービス の 利用 に関する 当社 と 利用者 と の 間 の 権利義務関係 を 定める もの と し、 利用者 と 当社 の 間 の 本サービス の 利用 に かかる 一切 の 関係 に 適用 され ます。

第 2 条 (ライセンス)

  • 当社 は 利用者 に 対し、 本サービス を 非独占的 に 利用 する 権利 を 付与 します。
  • 本サービス の ライセンス は 1 ライセンス に つき 1 台 の PC で 利用 可能 です。 複数 PC で 利用 する 場合 は 追加 ライセンス の 購入 が 必要 です。
  • 利用者 は 発行 された ライセンス キー を 第三者 に 譲渡・貸与・共有 して は なりません。

第 3 条 (料金)

本サービス は 買い切り 型 (1 ライセンス ¥4,980 税込) です。 支払 後 の 返金 は、 当社 の 責 に 帰す べき 事由 が ある 場合 を 除き、 承れ ません。 無料 トライアル (5 検索まで) を 事前 に お試し の 上、 ご購入 ください。

第 4 条 (利用者 の 責任)

  • 利用者 は、 本サービス を 利用 する に あたり、 Google LLC が 定める Google マップ 利用規約 を 遵守 しなければ なりません。
  • 本サービス は 人間 が 検索 する ペース を 想定 した 待機時間 を 挟んで います が、 利用者 の 意図的 な 大量 hammering は 禁止 します。
  • 本サービス で 収集 した 情報 の 利用 について は 利用者 の 責任 に おいて 適法 に 行う もの と します。
  • 本サービス で 取得 した 電話番号 · メール アドレス 等 に 対する 迷惑営業 · スパム 行為 は 禁止 します (特定商取引法 · 個人情報保護法 遵守)。

第 5 条 (禁止事項)

  • 本サービス の 逆コンパイル、 リバースエンジニアリング、 改変、 再配布
  • ライセンスキー の 第三者 への 譲渡 · 転売
  • 本サービス を 用いた 違法 · 反社会的 な 情報 収集
  • Google マップ サーバ に 対する 過度な 負荷 の 意図的 な 発生
  • 当社 · 第三者 の 権利 を 侵害 する 行為

第 6 条 (サービス の 保証 · 免責)

  • 本サービス は、 現状 有姿 で 提供 され、 特定 の 目的 への 適合性、 商品性、 完全性、 有用性 について 何ら 保証 する もの では ありません。
  • Google マップ の 仕様変更 に より 一時的 に 本サービス が 動作 しない 場合 が あります。 購入 後 1 年間 は 無償 アップデート を 提供 します が、 復旧 の 時期 について は 保証 いたし ません。
  • 本サービス で 収集 した 情報 の 正確性 · 最新性 について は 保証 しません。 利用者 の 責任 に おいて 確認 の 上 ご利用 ください。
  • 本サービス の 利用 に 関連 して 発生 した 一切 の 損害 について、 当社 は 責任 を 負い ません。 ただし 当社 の 故意 又 は 重過失 に 基づく もの を 除き ます。

第 7 条 (サポート)

本サービス の 使用方法 に関する お問合せ、 動作不具合 の 報告 は sales@skeleton-inc.jp まで お寄せ ください。 平日 (土日祝除く) 3 営業日 以内 に 返信 いたします。

第 8 条 (規約 の 変更)

当社 は、 必要 と 判断 した 場合、 利用者 に 事前 通知 する こと なく 本規約 を 変更 する こと が できます。 変更後 の 本規約 は 本ページ に 掲載 された 時点 から 効力 を 生じる もの と します。

第 9 条 (準拠法 · 裁判管轄)

本規約 の 準拠法 は 日本法 と し、 本サービス に 関して 紛争 が 生じた 場合、 福井地方裁判所 を 第一審 の 専属的合意管轄 裁判所 と します。
