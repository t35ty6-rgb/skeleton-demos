MapsLeads プライバシーポリシー

最終改訂日: 2026 年 7 月 31 日
結論から: MapsLeads は 利用者 の 個人情報 · 検索履歴 · 収集結果 を 一切 外部 送信 しません。 全て お使い の Chrome 内 (chrome.storage.local) に 保存 され、 当社 サーバ で は 一切 保持 しません。

スケルトン株式会社 (以下 「当社」) は、 Chrome 拡張機能 「MapsLeads」 (以下 「本サービス」) の 提供 に あたり、 利用者 の プライバシー を 最大限 に 尊重 します。 本ポリシー は、 本サービス に おける 個人情報 の 取扱い を 定める もの です。

1. 収集 する 情報

本サービス は、 以下 の 情報 のみ を お使い の Chrome ブラウザ 内 に 保存 します:

  • 検索条件 (都道府県 · 市 · 業種 · フィルタ 設定)
  • 収集結果 (店名 · 業種 · 電話 · 住所 · ウェブサイト · Instagram · LINE 等 の 公開情報)
  • ライセンス キー
  • トライアル 利用回数

これら の 情報 は 全て chrome.storage.local API を 用いて お使い の Chrome の ローカルストレージ に 保持 され、 当社 サーバ に 送信 されること は ありません。

2. 送信 しない 情報

本サービス は、 以下 の 情報 を 外部 に 送信 しません:

  • お使い の PC / ブラウザ の 識別情報
  • 利用者 の IP アドレス
  • 収集した 店舗 の 情報
  • 検索クエリ の 履歴
  • 使用時間 · 使用頻度 等 の 統計情報

3. 外部 サービス と の 通信

本サービス が 通信 する 外部 サービス は 以下 の 通り です:

  • Google マップ (www.google.com / www.google.co.jp): 検索結果 の 取得 の ため、 通常 の Chrome での閲覧 と 同様 の 通信 が 発生 します。
  • ライセンス サーバ: 使用 しません。 ライセンス 検証 は 完全 に クライアント サイド で 行われ ます。

4. Cookie · トラッキング

本サービス は 独自 の Cookie · トラッキング ピクセル を 一切 使用 しません。 Google マップ 側 の Cookie は、 利用者 の 通常 の Chrome 設定 に 従い ます。

5. ユーザ 権利

本サービス は 情報 を 外部 に 送信 しません が、 保存 された ローカル データ の 削除 を 希望 する 場合 は 以下 の 方法 で 削除 できます:

  • chrome://extensions で MapsLeads を アンインストール する と、 関連 する 全 ローカル データ が 削除 されます。
  • popup 内 の 「リセット」 ボタン で 収集結果 の みを クリア できます。

6. 未成年 者 の 利用

本サービス は 業務 用途 (BtoB 営業リスト 作成) を 想定 して おり、 未成年者 の 利用 は 想定 して いません。 保護者 の 同意 の もと で のみ ご利用 ください。

7. 変更

本ポリシー の 内容 は 予告 なく 変更 される 場合 が あります。 変更 後 の ポリシー は 本ページ に 掲載 された 時点 から 効力 を 生じます。

8. お問合せ

本ポリシー に関する お問合せ は sales@skeleton-inc.jp まで お寄せ ください。
