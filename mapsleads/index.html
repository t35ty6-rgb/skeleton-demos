Google マップ の 利用規約 に 抵触 しませんか

本ツール は 人間 が 検索 する ペース を 大幅 に 超えない 待機時間 (デフォルト 1.2 秒 / スクロール、 0.6 秒 / 店舗) を 挟んで います。 大量 hammering は しません。 通常 の 営業 リスト 作成用途 (1 日 数十 検索) の 範囲 で ご利用 ください。

1 検索 で 何件 取れますか

Google マップ 側 の 表示 上限 で 通常 20〜120 件 / 検索 です。 より 深い 網羅 が 必要 な 場合 は 業種 を 細分化 (「美容室」 → 「メンズ美容室」) するか、 郵便番号 で 町単位 に 絞る と 追加 取得 できます。

「HP 無し」 の 判定 精度 は

Google マップ の 詳細 パネル に ウェブサイト 欄 が 未登録 の 店舗 を 「HP 無し」 と 判定 します。 加えて 「ウェブサイト 欄 が HotPepper / 楽天ビューティ / minimo など の 予約 ポータル のみ」 の 場合 も 「自社 HP 無し」 として 検出 します (フィルタ で 分離 可能)。

Instagram / 公式 LINE の 検出 は どこまで

Google マップ の 詳細 に 登録 されている リンク を ベース に 検出 します。 具体的 に は Instagram (instagram.com/...) と LINE 公式 (lin.ee/... / liff.line.me/...) の URL が Maps 上 に 掲載 されている 場合 に hit します。 Maps に 未登録 で 実 は SNS を やっている 店 は 検出 されません (Phase 2 で 別途 対応 予定)。

1 キー 1 PC の 縛り は なぜ
