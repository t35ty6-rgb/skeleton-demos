よくある質問

導入前 に 気になる ポイント まとめ。

Google マップ の 利用規約 に 触れませんか?

本ツール は 「人間 が 検索 する ペース」 を 大幅 に 超えない 待機時間 (デフォルト 1.2 秒/スクロール · 0.6 秒/店舗) を 挟んで います。 大量 hammering は しません。 通常 の 営業リスト 作成用途 (1 日 数十 検索) の 範囲内 で ご利用 ください。 サーバに 対する 過度な 負荷 を 意図的 に かける 使用 は 利用規約 で 禁止 しています。

1 検索 で 何件 取れますか?

Google マップ 側 の 表示 上限 で 通常 20〜120 件 / 検索 です。 より 深い 網羅 が 必要 な 場合 は 業種 を 細分化 (「美容室」 → 「メンズ 美容室」 「40代 女性 向け 美容室」 等) するか、 エリア を 町単位 まで 絞る と 追加取得 できます。

HP 無し の 判定 精度 は?

Google マップ の 詳細パネル に ウェブサイト 欄 が 未登録 の 店舗 を 「HP 無し」 と 判定 します。 加えて 「ウェブサイト 欄 が HotPepper / 楽天ビューティ / minimo など の 予約ポータル のみ」 の 場合 も 「自社 HP 無し」 として 検出 します (フィルタ で 分離 可能)。

Instagram / 公式 LINE の 検出 は どこまで?

Google マップ の 詳細 に 登録 されて いる リンク を ベース に 検出 します。 具体的 に は Instagram (instagram.com/...) · LINE 公式 (lin.ee/... / liff.line.me/...) の URL が Maps 上 に 掲載 されて いる 場合 に hit します。 Maps に 未登録 で 実 は SNS を やって いる 店 は 検出 されません (Phase 2 で 別途 対応 予定)。

ソフトウェア の 性質上、 ライセンス キー 発行後 の キャンセル・返金 は 承れません。 5 検索 の 無料 トライアル で 動作 を ご確認 の上、 ご購入 ください。

Google マップ の DOM 構造 は 年 1〜2 回 変更 が 入ります。 購入 後 1 年間 は 仕様変更 に 対応 する 無償 アップデート を 提供 します (2 年目以降 は アップデート 版 ¥1,980 / 年)。
