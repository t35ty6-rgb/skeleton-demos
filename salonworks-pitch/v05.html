Salonworks
三大訴求 · v05 · LP整合 · 2026-07-18
Sales Pitch — LPと同じ声で

サロンの1日を、
1つの管理画面で。

7つのSaaSを行き来して手入力する業務を、Salonworks は 1つのテナントに束ねる。予約 · 物販 · LINE の 3軸 が 1本の動線 で 繋がると、 一度掴んだ客は 静かに離れなくなる。 —— この LP の 骨格 を、 三大訴求 5案 × 3列 に 展開。
v04 → v05 v04 「逃さない / 見える化 / 離さない」 は 損失回避型 に振り過ぎて 「なぜ Salonworks か」 の 本丸 が 抜けた。 v05 は 本日 公開 の LP と 声を揃えて 「束ねる (7 SaaS→1) / 見える (サロンの1日 1画面) / 離さない (LTV)」 の 3幕 に。 実データ (hikka2 稼働 · 205顧客 · 621予約 · 11 KPI · -¥35k/月 · ¥0初期) を 全 15案 に 織り込み。

三本柱

各 Pillar から 1案 選定 → copy-reviewer → スライド展開
1
Pillar I · Consolidate束ねる
01
7 SaaS を 1テナントに
別々の月額を、1本にする。
Air + STORES + Lステップ + カルテアプリ + 集計Excel で 月 ¥5,000 × 5〜7本。 合計 月¥35,000 の 束が Salonworks 1つ に。
02
セットアップは弊社側で
初期0円、3日で本番稼働。
LINE公式 · Stripe · 営業時間 · スタッフ · メニュー · 商品 を こちらで組んで納品。 翌週から現場運用スタート。
03
3社契約 → 1社契約
請求書は、1枚で終わる。
予約表アプリ · EC構築会社 · LINE配信ツール の 3社 3請求書 が 1社 1請求書。 経理も 契約更新 も 1本化。
04
サロン特化の統合設計
サロン用に、あつらえた。
Air は 美容室予約 専用、 STORES は 汎用EC、 Lステップ は 配信専用。 サロン全業務 を 1製品 で 束ねた のは 前例なし。
05
hikka2 サロン 実稼働
205名の顧客を、1画面で。
福井県 の パートナーサロン hikka2 にて、 205名の顧客 · 621件の予約 を 1つの管理画面 で 運用中。 デモ画面 ではない。
2
Pillar II · Visualize見える
01
サロンの1日を1本の帯で
1日の全動線が、1画面に。
朝の予約通知 → 来店カルテ → 施術中の物販 → 会計 → 帰宅後リマインド。 3つの SaaS を 行き来せず、 1つのタブ で 完結。
02
予約 · 物販 · LINE の 全接点統合
客の全部が、時系列で並ぶ。
カルテ画面 に 予約履歴 + 購入履歴 + LINE会話 + 撮影写真 + 使用薬剤 が 経過時間で分類 (業界前例なし)。 「3ヶ月ぶりの○○様」 が 即座に わかる。
03
11 KPI + 6ヶ月推移
経営を、数字で回す。
売上 / 客単価 / 継続率 / 90日再来店率 / LINE友だち / カルテ入力率 の 11指標 が リアルタイム集計。 「なんとなく」 が 消える。
04
30秒発行 · 名指し個別配信
クーポンは、30秒で送る。
左で入力 すると 右に LINE見え方 が リアルタイム反映。 タグ一斉 と 「1人ずつ個別選択」 の 両対応、 送信結果 も 自動 で KPI に。
05
iPad で 朝礼 に そのまま
朝礼の資料は、これ1枚。
本日の予約6件 · 想定客単価 · 担当シフト を iPadで音声読み上げ。 スタッフ全員が同じ画面で、 開店前 の 5分 で 情報共有 完了。
3
Pillar III · Retain離さない
01
消費目安 30日 の 自動同期
シャンプーの残量まで、追う。
買った商品ごとに 消費目安を登録 → 残量が減る頃合いに LINEで 「そろそろですよ」 → 次回来店の予約導線 まで 直結。
02
前回施術 + 4週間 の 自動発火
28日で、次の予約に繋げる。
「そろそろカラーの時期です」 の LINE通知 → タップ → LIFF予約 → 空きスタッフ選択 → 完了 まで 離脱ゼロの動線。
03
5回¥30,000 の 先払い設計
先払いで、資金繰りを前倒し。
「5回コース¥30,000」を 先払い販売 → 売上は 当月一括計上 + 5回リピート拘束。 失効通知 も 自動、 紙の回数券カード は不要。
04
施術中の物販レコメンド
勧め忘れを、ゼロにする。
「今日のケアには◯◯シャンプーが合います」 を タブレット上で選択 → 会計時のカゴに自動追加。 施術単価 に 物販 が 上乗せ される。
05
個別名指し LINE 配信
「〇〇様」の、名指しで届く。
「45日ぶりの○○様、 お元気 ですか?」 を タグ に 関係なく 1人指名 で 自動配信。 手動 100人打ち の 5時間 が、 3クリック に。
