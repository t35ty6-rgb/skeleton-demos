Sales Pitch — 損失を、埋める

一度掴んだ客は、
二度と逃さない。

サロン経営で 一番 の 損失 は、 「戻れた はず の 客」 が 静かに 離れる こと。 Salonworks は LINE を 一本 に して、 その 離脱 の 瞬間 を アプリ が 察知 する。
v03 → v04 「常連 が 戻る」 系 の 説明調 は 弱い。 「一度 掴んだ 客 を、 逃さない」 の 損失 回避 型 に 全 差し替え。 営業資料 は 「パッと見て うち に 欲しい」 と 思わせる 一撃 が 命。

三本柱

各 Pillar から 1案 選定 → copy-reviewer → スライド展開
1
Pillar I · Never Lose逃さない
01
4条件 連動 発火 の お誘い
一度掴んだ客は、二度と逃さない。
前回 施術 + 消費目安 + 空席 + タグ の 4変数 を アプリ が 見て、 離脱 の 瞬間 を LINE で 埋める。
02
離脱 前 の 名指し 配信
常連が消える前に、AIが止める。
前回 来店 から 45日、 まだ 予約 なし。 「〇〇 様、 お元気 ですか?」 の 一言 が 自動 で 飛ぶ。
03
直前 空席 の 即時 通知
空席という損失を、消す。
直前 キャンセル の 瞬間、 「近隣 + 平日 昼 可」 の タグ に 秒 で 声かけ。 空席 = 現金 の 蒸発。
04
手動 100人 打ち を 3クリック に
お誘いを、一度も打ち逃さない。
「そろそろ お客様...」 を 手打ち で 100 人 に 送ってた 5時間 が 3クリック に。 打ち忘れ ゼロ。
05
タグ × 履歴 の 精密 発火
予約が、勝手に埋まる。
お誘い の 精度 が 上がれば 予約 は 勝手 に 埋まる。 営業 電話 ゼロ で 稼働率 UP。
2
Pillar II · See Everything見える化
01
LINE 軸 の 客 カード
客の全部を、一人残らず掴む。
予約 · 買い物 · 施術 記録 が LINE 客 1人 に 紐付き。 「あの 常連 さん が 定期便 買ってる」 が 見える。
02
「誰だっけ?」 を 消す
「あの客、誰だっけ?」を、消す。
名前 と 履歴 が LINE アイコン と 一緒 に 出る。 常連 の 顔 と 名前 と 好み が 全部 揃う。
03
3 分裂 の SaaS を 1 個 に
3つのSaaSを、1つに潰す。
iSalon + Shopify + LINE公式 の 月額 計 ¥15,000〜¥30,000 が Salonworks 1個 に。
04
バラバラ の 客管理 を 束ねる
バラバラの管理を、終わらせる。
エクセル · 予約帳 · LINE公式 · Shopify 管理 の 5個 開いてた 現状 が 1個 に。
05
予約 · 物販 · タグ 一体
客の全履歴が、指1本で開く。
タップ 一回 で 予約 · 物販 · 施術 · タグ が 全部。 「敏感肌 + カラー 3回 以上」 の 精密 セグメント が 育つ。
3
Pillar III · Never Lose Again離さない
01
サロン品 質 を 家 で 維持
楽天に、客を渡さない。
施術後、 「今日 使った の これ です」 の 商品カード が LINE に。 タップ で 定期便、 楽天 に 流れる 客 を 止める。
02
消費目安 90日 の 自動 同期
サロンの効果を、家で切らさない。
「そろそろ シャンプー 切れる」 が 自動 で LINE。 施術効果 が 家 で 続く → 次回 の 出発点 が 高い。
03
単発 客 を 生涯 客 に
一度買った客を、単発で終わらせない。
Stripe サブスク で 定期便 が 自動 課金、 初回 割引 も 実 反映。 MRR が 月々 積み上がる。
04
継続率 の 劇的 改善
客が離れる前に、次を差す。
お誘い + 家 で 続く + 定期便 の 3段 で、 LTV が 従来 の 130〜150% に。
05
施術 → 販売 の 動線 自動化
客単価を、勝手に押し上げる。
施術 の 隣 で 物販 が 動く。 LINE カード が 「これ 良い よ」 の 代わり、 客単価 +30%。

Jobs 推薦 の 組み合わせ

掴んだ客は、逃さない。
全部を、掴む。
そして、離さない。
I-01 「一度掴んだ客は、二度と逃さない。」 / II-01 「客の全部を、一人残らず掴む。」 / III-04 「客が離れる前に、次を差す。」
逃さず · 掴み · 離さない。 営業資料 の 3幕 が 完結。
