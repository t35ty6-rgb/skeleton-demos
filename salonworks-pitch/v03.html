Three Pillars

常連が、勝手に戻ってくる
サロンをつくる。

LINE 一つで、予約 · 物販 · 客管理を束ねる。 客の 「そろそろ」 を アプリが察して、 サロンから自動でお誘い。 施術は続き、 客は離れない。
v02 → v03 明朝 · B&W の 和風 が 強すぎた の で、 サロン 現場 に 近い モダン SaaS 表現 (sans-serif + LINE 緑 + Skel·EC ピンク) に 差し替え。 主役 コピー は 保持。

三本柱

各 Pillar から 1案 選定 → copy-reviewer → スライド展開
1
Pillar I · Inviteお誘い
01
4条件 連動 発火
常連が、勝手に戻る。
前回 カラー から 8週。 家 の シャンプー も そろそろ。 明日 14時 空きました。 この 3つ を アプリ が 見て、 LINE を 1通。
02
AI 予測 の 来店 提案
お誘いが、自動で飛ぶ。
「そろそろ お客様...」 を 手打ち で 100人 に 送ってた 5時間 が 3クリック に。
03
直前 空席 の 即時 通知
空席が、消えていく。
直前 キャンセル の 瞬間、 「近隣 + 平日 昼 可」 の タグ に 秒 で 声かけ。
04
離脱 前 の 名指し 配信
客の気配を、先読み。
前回 来店 から 45日、 まだ 予約 なし。 「〇〇 様、 お元気 ですか?」 の 気遣い の 一言 が 自動 で。
05
タグ × 履歴 の 精密 発火
私を、見てくれてる。
客 の 感覚。 一斉 配信 じゃない、 名指し の LINE が 適切 な タイミング で。 「私 だけ に」 感 が 本物。
2
Pillar II · Unify統合
01
LINE 軸 の 客 カード
客の全部が、一画面に。
予約 · 買い物 · 施術記録 が LINE の 客 1人 に 紐付き。 「あの 常連 さん が 定期便 買ってる」 が 見える。
02
3 分裂 の SaaS を 1 個 に
3つのSaaSが、1つに。
iSalon + Shopify + LINE公式 の 月額 計 ¥15,000〜¥30,000 が Salonworks 1個 に。
03
客 が 覚える の は LINE だけ
LINE 一つで、全部。
友だち追加 だけ で 客 登録 完了。 会員登録 · アプリ dl · URL 記憶 全部 不要。
04
予約 · 物販 · タグ 一体
客が、見えるようになる。
「敏感肌 + カラー 3回 以上 + 60日 未来店」 の 精密 セグメント が 育つ。
05
バラバラ の 客管理 を 束ねる
バラバラだった客管理を、束ねる。
エクセル · 予約帳 · LINE公式 · Shopify 管理 の 5個 開いてた 現状 が 1個 に。
3
Pillar III · Retain継続化
01
施術効果 の 家 内 維持
サロンの効果が、家でも続く。
施術後、 「今日 使った の これ です」 の 商品カード が LINE に。 タップ で 定期便。
02
消費目安 90日 の 自動 同期
買い忘れが、ゼロに。
「そろそろ シャンプー 切れる」 が 自動 で LINE。 客 は 楽天 に 流れない。
03
Stripe サブスク 直結
定期便が、勝手に育つ。
初回 割引 (% or ¥) が 実 課金 に 反映、 解約 は マイページ 完結。 MRR が 積み上がる。
04
継続率 の 劇的 改善
客が、離れない。
お誘い + 家 で 続く + 定期便 の 3段 で、 LTV が 従来 の 130〜150% に。
05
施術 → 販売 の 動線 自動化
客単価が、勝手に上がる。
施術 の 隣 で 物販 が 動く。 LINE カード が 「これ 良い よ」 の 代わり。

Jobs 推薦 の 組み合わせ

常連が戻り、
客が見える、
そして離れない。
I-01 「常連が、勝手に戻る。」 / II-01 「客の全部が、一画面に。」 / III-04 「客が、離れない。」
お誘い で 呼び、 統合 で 束ね、 継続 で 稼ぐ。 サロン 経営 の 3段 が この 順序 で 揃う。

次のステップ

  1. 選定 — 各 Pillar から 1案 ずつ 選ぶ (例: I-01 / II-01 / III-04)
  2. Jobs に 番号 で 教える (「I-01, II-01, III-04」)
  3. copy-reviewer で 磨き → 最終文言 確定
  4. スライド版 展開 — 15〜20 スライド の pitch deck に 展開
