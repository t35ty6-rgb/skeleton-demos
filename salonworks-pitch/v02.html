Salonworks — 三大訴求

常連が、勝手に戻ってくる。

LINE 一つで、予約 · 物販 · 客管理を一体化するサロン専用SaaS。
v01 → v02 の 差分 — 4字 熟語 (「精密誘客」 等) は バイクカバー の 物 LP 用 で、 SaaS だと 企業パンフ に なる。 主役 を サロン オーナー が 実感 で 頷ける 短フレーズ に 変更。 3層構造 · B&W · Noto Serif JP は 維持。 各 pillar に 実物 の 例文 も 添えた。
Pillar I
お誘い
01
誘
4条件 連動 発火
常連が、
勝手に戻る。
前回 カラー から 8週。 家 の シャンプー も そろそろ。 明日 14時 空きました 。 この 3つ を アプリ が 見て、 LINE を 1通。
02
誘
AI 予測 の 来店提案
お誘いが、
自動で飛ぶ。
「そろそろ お客様...」 を 手打ち で 100 人 に 送ってた 5時間 が、 3クリック に。
03
誘
直前 空席 の 即時 通知
空席が、
消えていく。
直前 キャンセル が 出た 瞬間、 「近隣 + 平日 昼 可」 の タグ で 客 に 秒 で 声かけ。
04
誘
離脱 前 の 名指し 配信
客の気配を、
先読み。
前回 来店 から 45日、 まだ 予約 なし。 「〇〇 様、 お元気 ですか?」 の 気遣い の 一言 が 自動。
05
誘
タグ + 履歴 の 精密 発火
私を、
見てくれてる。
客 の 感覚。 一斉配信 じゃない、 名指し の LINE が 適切 な タイミング で。 「私 だけ に」 感 が 本物。
Pillar II
統合
01
統
LINE 軸 の 客 カード
客の全部が、
一画面に。
予約 履歴 も、 買い物 も、 施術記録 も、 LINE の 客 1人 に 全部 紐付き。 「あの 常連 さん が 定期便 買ってる 」 が 見える。
02
統
3 分裂 の SaaS を 1 個 に
3つのSaaSが、
1つに。
iSalon (予約) + Shopify (物販) + LINE公式 (集客) の 月額 計 15,000〜30,000円 が、 Salonworks 1個 に。
03
統
客 が 覚える の は LINE だけ
LINE 一つで、
全部。
友だち追加 だけ で 客 登録 完了。 会員登録 も、 アプリ dl も、 URL の 記憶 も、 客 に 何 も させない。
04
統
予約 · 物販 · タグ 一体
客が、
見えるようになる。
「敏感肌 + カラー 3回目 以上 + 60日 未来店」 の 精密 セグメント が サロン 側 で 育つ。
05
統
3 分裂 の 客管理 を 束ねる
バラバラだった
客管理を、束ねる。
エクセル、 予約帳、 LINE公式、 Shopify 管理画面。 5個 開いてた 現状 が、 1個 に なる。
Pillar III
継続化
01
続
施術効果 の 家 内 維持
サロンの効果が、
家でも続く。
施術後、 「今日 使った の これ です」 の 商品カード が LINE に。 タップ で 定期便、 家 で サロン品 質 継続。
02
続
消費目安 90日 の 自動 同期
買い忘れが、
ゼロに。
「そろそろ シャンプー 切れる」 が 自動 で LINE。 客 は タップ 1 回、 楽天 に 流れない。
03
続
Stripe サブスク 直結
定期便が、
勝手に育つ。
初回 割引 (% or ¥) が 実 課金 に 反映、 解約 は マイページ 完結。 MRR が 月々 積み上がる。
04
続
継続率 の 劇的 改善
客が、
離れない。
お誘い + 家 で 続く + 定期便 の 3 段 で、 LTV が 従来 の 130〜150% に。
05
続
施術 → 販売 の 動線 自動化
客単価が、
勝手に上がる。
施術 の 隣 で 物販 が 動く。 客 に 「これ 良い よ」 と 口頭 で 言う ストレス なし、 LINE カード が 代わり に 話す。

Jobs 推薦

  • Pillar I 誘 = 01 「常連が、勝手に戻る。」 — 修飾 「4条件 連動 発火」。 Salonworks 最大 の 独自性 を 感情 で 表現。
  • Pillar II 統 = 01 「客の全部が、一画面に。」 — 修飾 「LINE軸 の 客 カード」。 統合 の 実感 が 一番 伝わる。
  • Pillar III 続 = 04 「客が、離れない。」 — 修飾 「継続率 の 劇的 改善」。 経営者 の 財布 に 響く 一言。

組み合わせ た とき の 一言

  • 「常連が戻り、客が見える、そして離れない。」
  • お誘い で 呼び、 統合 で 束ね、 継続 で 稼ぐ。 サロン 経営 の 3 段 が この 順序 で 揃う。
