なぜ LINE か

サロン客 は もう、 LINE の 中 に 住んでる。

予約 サイト も、 EC も、 メール も、 客 は 「見に 行く」 必要 が ある。 LINE だけ は、 客 の トーク欄 に 直接 届く。 集める なら LINE。 4 つ の 数字 が それ を 裏付ける。
01
60%
LINE 通知 の 開封率
メール DM は 15% しか 開かれない。 LINE 通知 は 4 倍 見られる。 送った 4 通 に 1 通 じゃなく、 3 通 に 2 通 届く。
メール DM 15% → LINE 60%+
02
95%
サロン 客 の LINE 保有率
20〜50 代 女性 の 95% が LINE を 毎日 使う (総務省 情報通信白書)。 メール アドレス を 訊く より、 LINE 友だち追加 の 方 が ハードル が 低い。
メール 登録 面倒 → 友だち追加 1 秒
03
0秒
見に行かせない、 届ける
予約 サイト も EC も、 客 が 思い出して 開く まで 何 も 起きない。 LINE は 客 の 手 の 中 で 通知音 が 鳴る。 「見に行く 情報」 から 「届く 情報」 へ。
予約 サイト 客 が 開く まで 待つ → LINE = 届く
04
1本
客 の 一生 の ID
電話 番号 も メール も、 引越し や 転職 で 変わる。 LINE ID は 客 が LINE を やめない 限り 一生 変わらない。 5 年 前 の 客 に、 今日 でも 届く。
電話 · メール 変わる → LINE ID 一生 続く
SO

予約 も、 物販 も、 お誘い も、 LINE に 集める と、 客 と の 距離 が ゼロ に なる。 これ が Salonworks の 出発点。
