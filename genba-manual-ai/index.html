もやい結び 基本手順書

高所作業・救助・係留に用いる基本結索。荷重下でも解けず、荷重を外せば片手で解けるのが特徴。

概要

ロープの末端に固定サイズの輪をつくる結び。船の係留、荷造り、高所作業時の安全確保、救助現場で最初に習得すべき結索とされる。習得の難所は「うさぎが穴から出て木の後ろをまわる」で覚える手順3の方向認識。

手順(5ステップ)

  1. 輪をつくる。ロープの元側(長い方)を上、末端側(短い方)を下にして小さな輪をつくる。輪の直径は完成させる輪の1.5倍が目安。
  2. 末端を通す。末端側を、下から輪に通す。元側は左手で押さえて形が崩れないようにする。
  3. 元側にまわす。通した末端を、元側の後ろ側に一度まわす。「うさぎが穴から出て、木の後ろをまわる」と口伝で覚える。
  4. 輪に戻す。元側の後ろをまわった末端を、最初の輪に上から通して下に出す。
  5. 締める。元側と末端を同時に引き締め、形を固定する。最後に輪の大きさを確認する。

注意事項

  • 末端側の余りは輪の直径の3倍以上残すこと。短いと荷重時にすっぽ抜ける。
  • 濡れたロープ、合成繊維ロープは緩みやすい。作業前に一度荷重テストを行う。
  • 荷重方向は必ず元側から。末端側に荷重をかけると解けない結果になる。

ベテランのコツ(発話から抽出)

  • 「輪の中に手が入るサイズで作れ」 ─ ほどく時に指が入る余裕が必要。
  • 「片手で結べるように練習しろ」 ─ 高所・暗所では片手作業を強いられる。
  • 「見て覚えるより、100回結んで覚えろ」 ─ 手の記憶が第一。

習得チェックリスト

  • 目を閉じても結べるか
  • 片手だけで結べるか
  • 30秒以内に結べるか
  • 荷重下で解けない形状か
  • 荷重を外すと片手で解けるか
  • 余り長さは3倍以上あるか

03

技術継承

Phase 1 ─ 本デモの領域

現場の作業動画をAIが解析し、章立て・手順・使用工具・注意事項・ベテランのコツ・チェックリストを自動で書き起こします。若手はiPad一台で全マニュアルを検索・閲覧できます。

  • ベテランの発話も認識し「口伝のコツ」を文字に残す
  • 1本の動画から3〜5分でマニュアル1冊を生成
  • マニュアルは編集可。監修者が最終確認して公開
  • スマホ・タブレット・PDF出力の3形態に対応
01

属人化リスクの解消

Phase 2

キーパーソンの頭の中にある「業務・判断基準・過去の事例」を、LINEで毎日5分ヒアリングし、AIがナレッジデータベースに体系化します。後継者採用と並行して、退職・不在リスクを段階的に減らします。

  • 朝または夕方に定型質問をLINEで自動配信
  • 音声・テキスト・写真の3形式で回答可能
  • AIが自動で分類・タグ付け・検索可能化
  • 「あの時どうするか」を後任が検索で引ける
02

業務効率化(現場発)

Phase 3

ゼロから新しいシステムを入れるのではなく、今の勤務日報・工程管理をそのまま残したまま、現場作業員の「もっとこうだったら」という声だけを集めてITで形にする道具を提供します。

  • 現場作業員がスマホから音声/テキストで投稿
  • AIが分類・要約・優先度付け
  • 管理者ダッシュボードで見える化
  • 採用された改善案は現場に還元(貢献の可視化)
03 ─ 進め方

段階を踏んで、6ヶ月で3つを組み上げる。

3つを同時に進めるのではなく、効果が見えやすい「技術継承」から立ち上げます。現場が慣れたところで属人化解消・業務効率化に順次拡張します。
