01

1本目 の 8 ステップ会長 Reel · 8/2投稿予定

01

CapCut インストール (3分)

iPhone なら App Store で 「CapCut」 検索、 無料。 Mac 版 も 別途 あるが 今回 は iPhone 想定。

▶ App Store で 開く
2025-09 以降 完全 無料 化 (透かしなし export)。 課金オプション あるが、 今回は 無料範囲で完結。
02

新規プロジェクト ─ 縦 9:16 (30秒)

CapCut 起動 → 「新しいプロジェクト」 タップ → 写真アプリ から 会長 インタビュー動画 を 選択 → 「追加」。

  • 初期状態 で 縦横比 が 元動画 のまま になる ので、 画面右下 「比率」 → 9:16 に 手動 変更
  • フレームレート: 30fps (デフォルト でOK)
03

60-90秒 に トリム

会長の 発言 の うち、 「大野で、大野のためのビールを。」 を 頭出し。 前後を 削って 60-90秒 に。

0:00 - 0:05
Hook「大野で、大野のためのビールを。」 (会長発言)
0:05 - 0:50
語り 本編 (会長 の 想い、 なぜ 作った か)
0:50 - 1:10
3者集約 (醤油屋・アワーブリュー・飲食店)
1:10 - 1:20
締め「8月23日 発売」

タイムライン上 の 動画 タップ → 「分割」 or 端の 白いバー を ドラッグ で トリム。

Hook (最初 3-5秒) で スクロール止めるか 決まる。 会長 発言の 一番 強い 一言 を 頭に持ってきて
04

テロップ (キャプション) 差し込み

下 の テキスト を コピペ して、 タイムライン下 「テキスト」 タブから 各シーン に 差し込む。

「大野で、 大野のためのビールを。」 ─ 大野市飲食業協会 会長 ○○○○ 3者、2年。 8月23日 発売。
  • フォント: 「明朝 (M PLUS 1p)」 or 「Zen Old Mincho」 (CapCut 内蔵)
  • 色: 白 (#FFFFFF) / 縁: なし or 薄い墨
  • 位置: 画面 中央 or 下 1/3 (Instagram UI と 重ならない位置)
  • アニメーション: 「フェードイン」 のみ (派手なアニメ 禁止 ─ 静けさ 保持)
05

BGM 追加 ─ Piano or Ambient (2分)

下 タブ 「オーディオ」 → 「サウンド」 → 検索: cinematic piano or ambient warm。 試聴 → 気に入った 1曲 → 「+」 タップ で 追加。

  • 推奨: 「Slow Piano」「Acoustic Guitar Soft」「Ambient Warm」
  • 音量: 音声 の 邪魔しない -18dB 前後 (トラック 選択 → 音量スライダー を 30% 前後 に)
  • 禁: Bass強め・ドラム 強め の EDM (会長 の 発言が 埋もれる)
06

プレビュー確認 (1分)

再生ボタン で 通し再生。 チェック 4点:

  • 最初 3秒 で 会長 の 引用 が 表示 されている
  • 音声 と テロップ の タイミング が 合っている
  • BGM の 音量 が 音声を 邪魔していない
  • 60-90秒 に 尺 が 収まっている
07

Export ─ 1080×1920 mp4

右上 「エクスポート」 → 設定:

  • 解像度: 1080p
  • フレームレート: 30fps
  • ビットレート: 「推奨」 でOK
  • 透かし: なし (2025-09 以降 デフォルトで 透かしなし)

書き出し 開始 → 1-2分 待ち → 完成 mp4 が iPhone 写真アプリ に 自動保存。

08

Instagram Reels 投稿 (2分)

Instagram アプリ → 下 「+」 → 「リール」 → 書き出した mp4 を 選択 → 「次へ」。

「大野で、大野のためのビールを。」 3者、2年。 8月23日 発売。 ─ 大野市飲食業協会 会長 ○○○○ #大野名水ラガー #大野市飲食業協会 #越前おおの #アワーブリューイング
  • 位置情報: 「越前大野」 を 追加
  • 投稿時刻: 8/2 (土) 19:00 (福井 エンゲージ 最高帯)
  • カバー画像: 動画中 の Hook シーン (0:00-0:05) を 選択
  • 投稿後 1時間 は コメント返信 集中 (エンゲージ加速)

03

素材動画 が 手元にない 場合Mixkit CC0 stock · 代替 / 追加素材

会長・醤油屋・醸造家 の 取材動画 が まだ 撮れていない 場合、 or B-roll (差し込み映像) が 足りない 場合、 Mixkit CC0 (無料商用可) から DL済みの 12本 が 使える。 iPhone Safari で ↓ タップ → 「共有」 → 「CapCut にコピー」 で 直接 CapCut に 取り込める。

04

Jobs 側 で 編集する 場合素材Drive up → Jobs FFmpeg render

CapCut 自己編集 が 面倒 な 場合、 素材 3本 (会長・醤油屋・醸造家) を Google Drive に up して URL を Jobs に 貼れば、 FFmpeg で 5-10分 で 3本まとめて render → プレビューURL 返す。

  • ▸Drive アプリ → 「+」 → 「アップロード」 → 3本 選択 → 「リンクを取得」 → 「知っている全員」
  • ▸URL を Jobs チャット に 貼る
  • ▸Jobs が 中身確認 → 使う秒数 セレクト → FFmpeg で render → 3本 プレビュー URL 返す
