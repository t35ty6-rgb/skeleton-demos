03

CapCut ワークフローstep by step · 1本 5-10分

01

素材DL

上の Section 01 「Stock Clips」 の 各動画 の 「DL」 リンクを クリック して mp4 を まとめて DL。 スマホなら 「共有 → CapCut」 で 直接 CapCut に 送れる。

02

CapCut で 新規プロジェクト

比率: 9:16 (Instagram Reels) 解像度: 1080×1920 fps: 30

03

Reel別 素材構成 に従って 動画 drag&drop

Section 02 「Reel別 素材構成」 の 各 Reel カード に 書いてある 秒数区切り (0-5s / 5-10s / 10-15s) の 順に mp4 を タイムラインに 並べる。

  • 各クリップ を 指定秒数 に トリム (右クリック → 分割 → 削除)
  • 切替 は 単純カット (トランジション 使わない ─ Gallery Minimalism の 静けさ 保持)
04

キャプション テキスト overlay

Section 02 の 各 Reel の 青枠キャプション を コピー → CapCut 「テキスト」 で overlay。

  • フォント: Noto Serif JP (無料DL可) or CapCut標準の 「明朝」
  • 色: 白 / 縁: なし or 薄い墨
  • 位置: 画面 中央〜下 1/3
  • アニメーション: フェードイン のみ (派手なアニメ 禁止)
05

BGM 追加

CapCut 「オーディオ」 → 「サウンド」 → 検索: ambient or cinematic piano。 音量 -18dB 前後 (静か)。

  • 推奨: 「Slow Piano」「Acoustic Guitar Soft」「Ambient Warm」
  • Bass強め・ドラム強め の EDM は 禁止 (documentary voice が 崩れる)
06

Export

右上 「エクスポート」 → 1080p / 30fps / mp4 で 書き出し。 透かしなし (CapCut 2025-09〜 全プラン 透かし外し 済)。

07

Instagram Reels 投稿

Instagram アプリ → Reels → mp4選択 → キャプション コピペ (Section 02 の 青枠から) → ハッシュタグ + 位置情報 「越前大野」 → 投稿。
