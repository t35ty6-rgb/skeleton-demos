01

CapCut 無料版 インストール

Mac / iPhone / iPad / Android 全部無料。 使いやすいのは iPad or iPhone だが、 細かい編集は Mac版 が 早い。

  • Mac版: capcut.com/ja-jp/download/mac から DMG DL
  • iPhone/iPad: App Store で 「CapCut」 検索
  • 透かしなし で 4K export 可能 (2025年9月以降)
02

Submagic 契約 ─ $19/月 Starter プラン

submagic.co で サインアップ → クレジットカード登録 → Starter プラン ($19/月) を 選択。

  • Starter は 15本/月 まで、 最大 2分 ─ Reels 3本 なら 余裕
  • 日本語字幕 99% 精度、 縦9:16 対応、 BGM ライブラリ 込み
  • クレジットが 会社カード なら Jobs 側で 契約可、 個人カード なら owner 実行
Submagic は 月払い ─ 制作終わったら 一時停止可 (無駄が出ない)
03

Raw footage を Google Drive に upload

会長 / 醤油屋 4代目 / アワーブリューイング 醸造家 の 撮影 mp4 or mov を Drive に 上げる。

  • ファイル名 「01_会長.mp4」「02_醤油屋.mp4」「03_醸造.mp4」 で 統一
  • Jobs に Drive フォルダ URL 共有 (閲覧権限のみで OK)
  • Jobs が 「使う秒数と 発言セレクト」 3本分 返信する

03

制作 workflowstep-by-step · 1本あたり 3-4時間

04

CapCut で 新規プロジェクト ─ 縦 9:16 設定

CapCut 起動 → 「新規プロジェクト」 → 画面比率を 9:16 (Instagram Reels) に設定。

  • 解像度: 1080 × 1920 (Full HD 縦)
  • フレームレート: 30fps
05

Raw 動画 import ─ Jobs 指定の 秒数区間だけ 使う

Drive から DL した mp4 を CapCut に drag&drop。 タイムラインに 置いた後、 Jobs から届いた 「使う秒数」 リスト (例: 00:23-00:41) の 区間だけ 残して 前後トリム。

Jobs が LLM で 「バイラル候補 30秒 3案」 を 提示するので、 選ぶだけでOK
06

Hook の 冒頭 3-5秒 を 短く 切る

1本の Reel は 最初 3秒 で 8割 決まる。 Reel 01 なら 会長の 「大野で、大野のためのビールを。」 を 頭に持ってくる (もし発言の途中なら 前後カット で 頭出し)。

07

音声書き出し ─ mp4 (縦) で export

CapCut 画面右上 「エクスポート」 → 1080 × 1920 / 30fps / mp4 で 書き出し。 字幕は入れない。 BGM もまだ入れない。 素の 話者音声 + 映像 だけ。

08

Submagic に 突っ込む ─ 字幕自動生成

submagic.co ログイン → 「New Project」 → CapCut で 書き出した mp4 upload → 言語 Japanese 選択。 30-60秒 で 字幕 自動生成。

  • スタイル: Minimal (白文字 黒縁) を 選ぶ ─ 派手なバイラル系より 静かな方が Gallery Minimalism に合う
  • フォント: Noto Sans JP or 源ノ角ゴシック
  • 位置: 画面下 1/3
09

字幕 の 微修正

Submagic は 99% 精度 だが 固有名詞 (大野・醤油屋名・アワーブリューイング) は 手動修正必須。 誤変換 と 人名 と 地名を チェック。

10

BGM 選定 ─ Submagic ライブラリから

Submagic 内 「Music」 タブ → 上の 台本で 提示した BGM 候補 を 試聴。 音量は -18dB 前後 (話者音声 の 邪魔しない 静か目)。

「Cinematic Piano (Slow)」「Ambient Warm」「Acoustic Guitar Soft」 が Gallery Minimalism 方向に合う
11

Export ─ 縦 1080×1920 mp4

Submagic 「Export」 → 1080p / mp4 / 縦9:16 で 書き出し。 3本 順番に 同じ手順で 完成させる。
