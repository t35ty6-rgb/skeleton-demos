SKEL·EC SETUP GUIDE

サロン公式LINEを
EC本番化する手順 (詳細版)

「どこをクリックして」「どこをスクロールして」「どんな文字が見えるか」 まで全部書いてあります。 PC の前で迷う瞬間ゼロを目指してます。

⏱ あなたの作業 : 約 10〜15 分
1

LINE Developers Console を開いてログイン

約 2 分
1

このURLをクリックして開きます

developers.line.biz/console を開く ↗
👀初めての場合: ログイン画面が出ます。LINE アカウント (個人) か、 ビジネスアカウント、 どちらでもログイン可能。 サロンの公式LINE を作った時に使ったアカウントを選んでください。
2

ログイン完了後、 トップ画面の見え方

ログイン後の画面は こんな感じになってます。

https://developers.line.biz/console/
画面左上に LINE Developers ロゴ
その下に大きな見出し 「あなたの Provider」
↓
その下に 四角いカード が並んでます。 これが 「Provider (プロバイダー)」 一覧。
例えば 「Skeleton株式会社」 「サロン名」 のような名前のカード。
💡Provider とは何?
LINE 公式アカウントや LINE ログインを「束ねている入れ物」 のようなもの。 通常は会社名で1つ作ります。
3

サロンの Provider をクリック

サロンの公式LINEを管理してる Provider のカードをクリックします。

🤔どれだかわからない場合: サロン名が入ってる Provider です。 例えば 「IDEAL by Hikaru」 とか 「○○整骨院」 とか。 もし Provider 名がわかりにくければ、 1つずつ開いて中の Channel 名を見て確認します。
2

Messaging API の Channel を開く

約 1 分
4

Provider のページに入った後の見え方

Provider のページに入ると、 こんな画面が表示されます。

画面上に Provider 名 (例: 「Skeleton株式会社」)
その下に 「Channels」 セクション
↓
Channel カード が複数並んでます。 種類は3つ:
・緑の吹き出しアイコン = Messaging API ← これを探す
・緑の人アイコン = LINE Login
・緑の店マーク = LINE 公式アカウントマネージャー連携
⚠️注意: 「LINE 公式アカウント」 と 「Messaging API のチャネル」 は別物。 必ず 緑の吹き出し アイコンの方を選んでください。
5

該当サロンの Messaging API Channel をクリック

サロン名のついた Messaging API のカード をクリックします。

👀名前の例: 「○○サロン公式」 「IDEAL by Hikaru」 「美容室ABC」 等、 サロン名が入ってるはずです。 紛らわしいので念のため 「Type」 が "Messaging API" になってるか確認してから押しましょう。
3

Channel ID と Channel Secret をコピー

約 3 分
6

Channel のページに入った後の画面構造

Channel のページに入ると、 上部に 5〜6個のタブ が並んでます。

Basic settings Messaging API LIFF Security Statistics Roles

デフォルトで 「Basic settings」 が選択されてます。 別のタブにいる場合は 「Basic settings」 を押してください (画面上部、 最初のタブ)。
7

下にスクロールして 「Channel ID」 を探す

Basic settings タブを 下にスクロール していくと、 こんな項目が並んでます。

Channel name : (サロン名)
Channel description : (説明文)
Channel icon : (アイコン画像)
Category : ...
Subcategory : ...
Email address : ...

①Channel ID : 1234567890 (コピー用ボタン📋付き)
②Channel secret : abc...xyz (コピー用ボタン📋付き)

Your user ID : ...
...
📋コピーの仕方: 各フィールドの 右側にコピーアイコン があります (📋 みたいなマーク)。 これをクリックすると自動でクリップボードにコピーされて、 「Copied!」 と表示されます。
① Channel ID 10桁数字
サンプル: 1234567890
② Channel secret 32桁の英数字
サンプル: a1b2c3d4e5f6...8901 (見た目はランダム)
4

Channel access token を取得 (③)

約 3 分
8

「Messaging API」 タブをクリック

画面上部のタブから 「Messaging API」 (左から2番目) をクリックします。

Basic settings → Messaging API LIFF Security ...
9

画面を一番下までスクロール

Messaging API タブの画面は、 上から こんな順番で項目が並んでます。 一番下までスクロール してください。

Bot info: QR code / Bot basic ID / Webhook URL...

LINE Official Account features:
・Auto-reply messages / Greeting messages
・Webhook (Use webhook: enabled/disabled)

Response settings: ...

↓ ここまでスクロールします ↓

③Channel access token (long-lived)
・現在のトークン: (まだない場合は空白)
・Issue ボタン (発行ボタン)
10

パターンA: トークンが まだない場合

「Channel access token (long-lived)」 の枠が 空白 になっています。

▼ やること
  1. 右側にある 緑色の 「Issue」 ボタン をクリック
  2. 確認ダイアログが出る場合 → 「Issue」 を押す
  3. 長い文字列が表示される (100文字以上)
  4. 右端の 📋 コピーアイコン でコピー
⚠️重要: このトークンは画面を閉じる前に必ずコピーしてください。 再表示はできません (再発行はできるが、 古いのは無効化される)。
11

パターンB: 既にトークンがある場合

「Channel access token (long-lived)」 の枠に 既に文字列が入ってる 場合。

▼ やること
  1. その文字列の 右端にある 📋 コピーアイコン をクリック
  2. 「Copied!」 と表示されればOK
✅これで OK です — 既存のトークンを使えば、 すでに動いている連携を壊さずに済みます。 もし他のシステムでこのトークン使ってない事が確実なら 「Reissue」 ボタンで再発行してもいいですが、 基本そのままで OK。
③ Channel access token 100文字以上の長い英数字
サンプル: aBcDeF12...JhKlMn34 (めちゃくちゃ長い)
5

Jobs に貼り付ける

約 1 分
12

チャットに 4 つ貼り付ける

取得した ①②③ と、 サロン名 (URL に使う英数字、 例: hikari-salon) をチャットに貼ってください。

▼ 例: 貼り付け形式 (こんな感じでチャットに送ってOK)
① Channel ID:  1234567890
② Channel secret:  abc123def456...xyz890
③ Access token:  aBcDe12FgHi...JkLmN34
サロン名:  hikari-salon
🔒セキュリティについて: これらの情報は機密ですが、 Jobs と1対1のチャットなら安全です。 公開する場所 (Twitter とか公開Slack) には絶対に貼らないでください。 もし誤って公開した場合は LINE Developers Console で すぐに 「Reissue」 (再発行) してください。
⌬

受け取った後 Jobs がやる作業

約 2 日
▼ Phase 2 ロードマップ (Jobs自走)
  1. Day 1 午前: Firebase project 作成、 Cloud Functions デプロイ、 Firestore セットアップ
  2. Day 1 午後: サロンの LINE Channel に Webhook 接続 (もらった ①②③ 使用)、 admin 画面を本番 API 接続化
  3. Day 2 午前: Stripe live 接続 (テスト決済で動作確認)、 LIFF 認証セットアップ
  4. Day 2 午後: 独自サブドメイン (sarondname.skel.ec) に SSL 付きでデプロイ
  5. Day 2 夕方: オーナーに 「触ってOK」 と LINE で連絡 → 動作確認 → 本番開始

📋 よくある質問

パスワード忘れた / アカウントログインできない
LINE Developers Console のログインは LINE アカウント連携。 LINE アプリにログインできるなら、 そのアカウントでログインボタン押せばOK。 「ビジネスアカウント」 別に作ってあった場合はパスワードリセット可能。
「Provider」 が複数あって どれかわからない
それぞれ開いて 中の Channel の名前を見れば判別できます。 サロン名や店舗名が入ってる Channel を含む Provider が正解です。
「Issue」 ボタン押したら 既存のトークンが消えた
それで OK です。 新しいトークンが発行されて、 古いのは無効化されました。 他のシステムでこの LINE OA 使ってる場合だけ、 その他システムも新しいトークンに更新が必要。
トークンを公開しちゃった / 流出したかも
即 LINE Developers Console に戻って 「Reissue」 (再発行) を押せば、 流出したトークンは無効化されます。 そして新しいトークンを Jobs に再送してください。
作業中で詰まった、 どうしよう
作業を止めて 「ここで詰まった」 とチャットしてください。 画面のスクショ送ってもらえれば、 どこを押せばいいか具体的に指示できます。
サロン側に何か準備してもらう必要は?
基本ナシ。 サロンが既に LINE 公式アカウント持ってるなら、 そこの管理権限を持ってる人 (オーナー自身でOK) が Phase 1 やれば完了。
LINE OAの送信通数を超えそうな場合
無料プランは月200通まで。 それ以上送るには LINE 公式アカウントの 有料プラン (月5,000円〜) に加入が必要。 サロンの集客状況見て プラン選びましょう。
