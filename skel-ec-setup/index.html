4つの情報をチャットに送る

①②③ と サロン名 (URL に使う英数字、 例: hikari-salon) をチャットに貼ってください。

🔒セキュリティ: これらは機密情報ですが、 Jobs と1対1のチャットなら安全です。 公開する場所 (Twitter とか公開Slack) には絶対に貼らないこと。
渡した後 何が起きる?Jobs が ①②③ を受け取った瞬間、 自動で:
❶ Channel ID / secret / token が 本物か LINE API に問い合わせて検証
❷ サロン専用の Webhook URLWebhook URL = LINE → Skel·EC への "通知の窓口"。 サロンA だけの専用 URL を発行 → LINE に登録 → サロンA の友だち追加 が Skel·EC のサロンA処理 に流れる。 (/lineWebhook/hikari-salon) を LINE 側に登録
❸ Use webhook を ON に切替
❹ 疎通テスト を実行 (LINE → 自社サーバー が繋がるか)
❺ Firestore のサロン専用フォルダ /tenants/hikari-salon/ を作成
所要時間 30秒。 完了したら オーナーから「動いてます」 連絡が来る。
6

ID 取得 後 もう1箇所: 応答設定を OFF にする

Skel·EC からの自動返信が動くように サロン公式LINEの 「あいさつメッセージ」 と 「応答メッセージ」 を OFF にする必要があります。 ON のままだと Skel·EC からの返信と 競合してエラー になる。

必須なぜ OFF にする?
LINE 公式アカウントには 2つの "自動返信機能" があります:
❶ LINE 純正の応答メッセージ (manager.line.biz 内で設定)
❷ Skel·EC の自動応答 (Webhook 経由)
両方 ON だと メッセージが二重に送られる / 衝突 する。 ❶ を OFF にして、 ❷ だけ動くようにする のが正解。

👉 LINE 公式アカウント Manager を開く:

manager.line.biz を開く ↗
  1. サロン公式アカウント を選択
  2. 左メニュー 「設定」 → 「応答設定」
  3. 応答モード = 「Bot」 を選択 (チャットモードではなく)
  4. あいさつメッセージ = オフ
  5. 応答メッセージ = オフ
  6. Webhook = オン (Skel·EC 側からも自動でONにするが、 念のため)
補足「友だち追加時のあいさつメッセージ」 や 「営業時間外メッセージ」 は Skel·EC 側で再現可能。 admin 画面 → 設定 → LINE → メッセージテンプレート で 同じ文言を登録すれば 元の挙動が戻ってきます。
⌬

受け取った後 Jobs がやる作業 (約 30 秒)

  1. 0 秒: ID 3つ + サロン名 を受信
  2. 0-10 秒: 自動セットアップ起動 → 各 ID を LINE API / Stripe API で本物検証
  3. 10-25 秒: Webhook URL 登録 + Use Webhook ON + 疎通テスト + Stripe webhook 作成
  4. 25-30 秒: Firestore tenant doc 作成 + 完了通知
  5. 完了後: オーナーに「サロン名 セットアップ完了」 LINE で連絡 → サロンに 動作確認 を依頼

📋 よくある質問

ログインできない / パスワード忘れた
LINE Developers Console のログインは LINE アカウント連携。 LINE アプリにログインできるなら、 そのアカウントでログインボタン押せばOK。
Provider が複数あって どれかわからない
それぞれ開いて 中の Channel の名前を見れば判別できます。 サロン名や店舗名が入ってる Channel を含む Provider が正解。
「Issue」 ボタン押したら 既存のトークンが消えた
それで OK。 新しいトークンが発行されて、 古いのは無効化されました。 他のシステムでこの LINE OA を使ってる場合は、 そちらも新しいトークンに更新が必要。
トークンを誤って公開した / 流出した
即 LINE Developers Console に戻って 「Reissue」 ボタンで再発行。 流出したトークンは無効化されます。
作業中で詰まった、 どうしよう
作業を止めて 「ここで詰まった」 とチャットしてください。 画面のスクショ送ってもらえれば、 どこを押せばいいか具体的に指示します。
既に LINE 公式アカウントで bot を運用してる場合は?
既存の Webhook URL が別システムを指してる場合、 Skel·EC 用に切り替える必要があります。 旧システムは停止 or 平行運用の判断が必要なので、 オーナーに「現状こういう bot 動いてる」 と先に共有してください。
Stripe アカウントが必要?
EC として決済を受けるなら必要。 サロンに Stripe アカウントが無い場合は、 セットアップ時に同時に作成 (オーナーがガイド)。 既存の Stripe アカウントがあれば sk_live_xxxx を一緒に送ってください。
サロン名 (slug) は どんな文字が使える?
英小文字 / 数字 / ハイフン のみ、 2〜40文字。 例: ideal-hikaru, momoi-seikotsu, cafe-2026。 大文字・日本語・スペース・アンダーバー は NG。
