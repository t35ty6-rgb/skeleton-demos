📋 ヒアリングシート — 印刷可能な事前ヒアリング票

💰 キャッシュフロー表 — 10年分の収支自動展開

顧客の年齢/年収/家族構成から 西暦×年齢×年収×支出×貯蓄 の表を自動生成。65歳以降は年金カーブに切替。「✨AIで個別作成」で 議事録 (自営/会社員/育休復帰 等) を反映した精緻版に置換可能。

🎒 教育費シミュレーション — 進路別 5パターン

全公立 / 高校から私立 / 中受 / 小受 / 海外留学 の5パターン × 幼〜大学までの 総額 + 月積立目安。児童手当 / 高校無償化 / 新NISA成長枠 まで含めた現実的な数字。

🏖 老後資金 必要額計算書 — 不足額の見える化

月の必要額 × 老後年数 − 公的年金見込み = 不足額。月¥25万 / 30年生活なら ¥2,400万 不足、など。40歳開始なら 月¥3.5万積立で達成可能、50歳開始なら 月¥8万必要、と 始める年齢別の差分も示す。

💹 NISA / iDeCo 配分シミュ — 3パターン提示

積極型 (40未満: 株70/債20/REIT10) / 標準型 (40-55: 株50/債40/REIT10) / 安定型 (55+: 株30/債60/REIT10) を棒グラフ + LINE で即送付可能。リスク許容度診断 (15問) も別途あり。

🛡 保険 見直しレポート — 必要vs現状ギャップ

死亡保障 / 医療 / 就業不能 / がん の必要額を家族構成から算出 → 現契約とのギャップ表で過不足が一目。「不足/完全不足/適正」 の判定タグ付き。

👴 相続 基礎控除 計算書 — 法定相続人別

3,000万 + 600万×法定相続人数 で自動計算。配偶者控除 1.6億 / 生前贈与の7年加算ルール (2024〜) も反映。基礎控除以下なら相続税ゼロ、超過分のみ課税。

FAQ

よくある質問

パソコンが苦手なのですが、50代でも使えますか?
はい。FP Compass は「面談前 → 録画 → 完了」の3ボタンしか触りません。初期設定 (LINE/Zoom連携) は Skeleton 運営側が代行で行います。FP様は「お客様と話す」ことに集中できます。
LINE 公式アカウント は 自分で作る必要がありますか?
いいえ。Skeleton 側で FP様 専用の LINE Channel + LIFF アプリ を代行で作成します (30分の初期セットアップに含まれます)。屋号・ロゴ・リッチメニュー もご相談ください。
既存の顧客データを取り込めますか?
CSV / Excel での一括インポート に対応しています (Pro プラン以降)。氏名・連絡先・家族構成・面談履歴 をマッピング設定で取込可。データ移行は無料サポート対象です。
解約はいつでも可能ですか?
いつでも解約可能です。月単位課金、違約金一切なし。データは解約後 30日間 保管され、エクスポートできます。
録音/録画データは安全ですか?
録画は FP様の Google Drive (個別アカウント) に直接保存され、Skeleton 側からはアクセスできません。文字起こし + AI議事録はテキストのみがクラウド上に暗号化保存。プライバシポリシは契約時にお渡しします。
他の CRM (Salesforce / Hubspot 等) とどう違いますか?
汎用CRM は「営業」 が前提のため、FP業務特有の「議事録 / 提案資料 / 継続フォロー設計」に手動で設計が必要です。FP Compass は LINE 連携 + Zoom 議事録 + 成果物自動生成 が標準実装。FP業務だけに特化した分、設定不要で即運用開始できます。
