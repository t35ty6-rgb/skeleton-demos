02 / 11 MEI Manual
第1章

MEIは、何をしてくれる道具か。

ひと言で言えば、 「お得意さまの記憶を、 店全員で共有する仕組み」。
ポイントカード機能はその入口にすぎません。
👥

顧客カルテを 店全員で共有

「あの方の好みは織部、ご長女が来年大学進学、母の日は粉引を贈った」 ── これまで店長ひとりが頭で覚えていたことが、スタッフ4人の画面に同じように映ります。担当者休みの日でも会話が途切れません。

🎁

ポイントは LINEの中で増える

紙のカードは要りません。お客さまが公式LINEを友だち追加した時点で発行され、レジで購入を記録するたびに自動で加算、お礼のメッセージと一緒にLINEへ届きます。なくす、忘れる、再発行する、がなくなります。

📣

新作の案内を 好みのお客さまだけに

「織部好きのお客さま8名」 だけに新作の入荷案内を送る、「3ヶ月ご無沙汰の方」 にだけ近況のお声がけを送る。一斉配信ではなく、相手に合わせた配信で、ブロック率を抑えながら来店につなげます。

04 / 11 MEI Manual
第3章

スタッフが毎日、画面でやること。

シーンは3つだけ。
これさえ習慣になれば、あとは自動で積み重なります。
SCENE 1 / お客さまが来店

レジで「LINEあります」と言われたら

  1. スタッフ画面の上の検索欄にお名前を入力(漢字でもふりがなでも、LINE表示名でも検索できます)
  2. 該当のお客さまの行をタップしてカルテを開く
  3. 「今日の購入を記録」 で商品を選んで個数を入力。複数商品は「+商品を追加」で増やす
  4. 支払方法を選んで「記録 → 自動LINE」ボタン。この時点で在庫が自動で減り、お礼LINEがお客さまに届きます
所要時間の目安 慣れたスタッフで30〜45秒、慣れていない方でも1分かかりません。
SCENE 2 / 新しい器が入荷した

新作を、好みのお客さまだけに案内する

  1. 「商品マスタ」 で 新商品を追加。商品名・作家・価格・初期在庫を入力
  2. 「在庫」 ページで、その商品が正しく登録されたか確認
  3. 「配信・施策」 ページで、たとえば「織部好み + 累計1万円以上」のセグメントを選択
  4. 「下書きを書く」 から案内文を作成して送信。配信数はその場で集計されます
送り過ぎ注意 週1回より多い配信は、LINEブロックが急に増える原因になります。
SCENE 3 / 週末・店じまいの後

今週の店を、数字で振り返る

  1. 「今日の店」 で週次/月次の売上推移を確認
  2. 「お声がけ候補」 で3ヶ月ご無沙汰のお客さまを確認、必要なら個別連絡
  3. 「在庫」 で残り少ない商品をチェック、発注リストを作成
  4. 気づいたお客さまの好み・要望は、カルテの「店長メモ」 に記録(他のスタッフも見えます)
店長メモが資産 「次回お会いした時に聞きたいこと」 まで書いておくと、雑談が続きます。

第5章 / LINE 初期設定 (1/5)

公式LINEアカウントを開設する。

所要時間: 10分
LINEビジネスIDがあれば3分で終わります
STEP 1

LINE公式アカウントを作る

まず、お店専用のLINE公式アカウントを発行します。お客さまが「友だち追加」 する先のアカウントです。すでに公式LINEをお持ちならこの工程はスキップ可。

  1. パソコンで manager.line.biz/signup を開く
  2. 普段使いのLINEアカウントでログイン。お店専用のメールアドレスをLINEビジネスIDとして発行(Gmailで可)
  3. アカウント名を「雑貨と道具 のうと」、業種を「ショッピング・小売」に設定
  4. 料金プランは「フリー (月200通)」でまず作成。後で必ず「ライトプラン」 に変更します

Messaging API を有効化して、認証情報を取得する。

所要時間: 5分

STEP 2-3

Channel ID / Secret / Access Token を発行

LINE公式アカウント管理画面の「設定」 → 「Messaging API」 タブから、自動配信やお礼メッセージを送るための認証情報を取得します。

  5. 右図の3つの値(Channel ID / Channel secret / Channel access token) を1つずつ「コピー」。メモ帳に貼っておきます

第5章 / LINE 初期設定 (3/5)

LIFFアプリを作って、お客さまの画面を開けるようにする。

所要時間: 3分
LIFF = LINEの中で開く専用Webアプリのことです
STEP 4

LIFF (Mini App) を作る

LIFFは、お客さまがLINEのトーク画面から開く、「マイページ」 のことです。ポイント残高や購入履歴を表示する画面のURLをLINEに登録します。

  1. 同じDeveloperコンソールで 「LIFF」 タブに切り替え
  2. 右上の「+ Add」ボタンをクリック
  3. LIFF app nameに「のうと マイページ」、Sizeは「Full」(画面全体表示)
  4. Endpoint URLにhttps://mei-nouto.web.appを貼り付け
  5. Scopesは「profile」と「openid」をチェック
  6. 作成後、表示された「LIFF ID」(例: 2006847291-x7K8mZpQ) を「コピー」

困った時の早見表。

この表のどれにも当てはまらない時は
迷わずスケルトンに連絡 → 即対応します
こんな時は
こう動く
担当
お客さまの名前で検索しても出てこない
まだLINE友だち追加されていない可能性。「新しいお客さま」 ボタンから手動でカルテ作成。後でLINE登録すれば自動でつながります。同姓同名の場合は電話番号で識別。
スタッフ
「記録 → 自動LINE」 を押してもLINEが届かない
設定タブのChannel access tokenが空、または期限切れの可能性。スタッフ画面の「設定」 → LINE連携を確認。トークンは長期(360日)で発行している前提。
スケルトン
LINEプラン枠を超えた、と通知が来た
LINE管理画面で翌月までに上位プランへ変更。今月は配信が止まりますが、購入記録とポイント加算は通常通り動きます。お客さまへは謝罪文を一斉送信できます。
店長
スタッフのスマホを紛失した
1時間以内にスケルトンに連絡。リモートでログイン無効化します。MEI自体に顧客の個人情報は端末に保存されない設計なので、画面を見られる以上の被害はありません。
スケルトン
お客さまから「データを消してほしい」 と言われた
店長が受付。カルテ画面の「削除」 ボタンで即時削除。30日間は復元可能なので、誤削除の場合は連絡。完全削除後は復元不可。
店長
スタッフ画面が真っ白になった、固まった
画面を1回リロード(Cmd+R / F5)。それでも改善しなければスマホ・PCを再起動。データは全部サーバーに保存されているので、消えることはありません。
スタッフ
在庫の数字が実際と合わない
在庫ページの±ボタンで手動調整可能。週末の棚卸し時に実数と画面の数字を合わせる、を習慣化。差分が大きい時は記録漏れの可能性。
