SECTION 01

全体 の 流れ

何を やるか、 ザックリ 把握 してから 始めると 迷いません。

FP Compass と お客様 を 「公式LINE」 でつなぎます。 やる事 は 大きく 3つ だけ:

①
LINE Developers で 鍵 を 作る
無料で プロバイダー → チャネル を 作って、 Token と Secret の 2つ の 鍵 を 取得。
②
FP Compass に 鍵 を 貼る
取得した 2つ の 鍵 を FP Compass の 設定画面 に 貼り付け。 後の 設定 (Webhook URL / リッチメニュー / アンケート埋込) は FP Compass が 全部 自動で やってくれます。
③
QR を お客様 に 渡す
FP Compass が 生成 した QR を 名刺・チラシ等 に 載せる。 お客様 が 友だち追加 → アンケート 回答 で 自動で 顧客台帳 に 登録。
アンケート URL や Webhook URL は FP Compass が 自動で 生成 します。 あなた が 手で 作る 必要は ありません。

FAQ

よくある 質問

LINE の 利用料 は かかりますか?

月 500通 まで 無料 (LINE公式アカウント Free プラン)。 通常 の FP Compass 利用 では 500通 を 超える ケース は ほぼ ない。

Channel access token は 期限切れ しますか?

「長期」 トークン は 期限 なし。 再発行 すると 古い トークン は 即無効 になる ので、 再発行 時 は FP Compass にも 新トークン を 入れ直す。

既に LINE 公式アカウント を 持ってます。 それ で 使えますか?

使えます。 Section 04 (Provider 作成) を 飛ばして、 既存 Provider 配下 で 新規 Messaging API チャネル を 作って ください。 既存チャネル の 流用 は 設定 競合 の リスク あり ので 新規 推奨。

誤って トークン を 公開して しまった!

すぐ LINE Developers の 「Messaging API設定」 で 「再発行」 → 古いトークン は 即 無効 化。 新トークン を FP Compass に 入れ直す。

1人 の FP で 複数 の LINE 公式アカウント を 紐付け できますか?

v1.0 時点 は 1FP = 1LINE。 複数 LINE は 順次 対応 予定。

お客様 と 個別 に やりとり できますか?

はい。 FP Compass の 顧客台帳 → 「LINE」 タブ から 1対1 で メッセージ 送受信。 AI による 返信案 自動生成。

困った時 は 連絡 ください

30秒 で 返信。 設定 中 詰まった 画面の スクショ を 送って もらえれば 即 解決方法 を 案内。
