01エグゼクティブサマリ

スケルトン株式会社は Amazon 3店舗 · 中国 OEM 直取引で 12ヶ月の稼働実績を持つ。 その主力直販商材が PEGAT 車用シートクッション (厚型 · 薄型の 2 SKU) で、 累計 4,212 個販売 · 直近30日の広告 ROAS 4.20倍 · 定常黒字フェーズに到達。

投資位置づけ: 立ち上げ期の不確実性 (製品適合 · 広告最適化 · レビュー獲得) は通過済。 追加資本の使途は 「既に売れているモデル」 の在庫積み増し · 広告費引き上げ · 追加 SKU 展開に限定。 現在 4,000 個の追加 OEM 発注 (9月中国出港 · 大野倉庫中継) が進行中で、 入荷と同時に販売加速予定。
数字表記の前提: 本資料の数字は Amazon SP-API · Ads API · 社内 Sheets の実測に基づく (章末 evidence 参照)。 会社全体の Amazon 3店舗合算売上は一部 API 認証更新中のため別途開示予定。 PEGAT 事業単独の数字は全て独立検証済。

03弊社の強み

同規模の個人 · 小規模 Amazon 事業者と比較して、 スケルトンは 「情報と自動化の内製化」 で差別化している。 属人運営では到達できない実測精度 · 反応速度 · 継続性を持つ。

01
Ads API 自動運用 pipeline
Amazon 広告は Web UI 手動運用が一般的だが、 弊社は Ads API 直叩きで bid · KW · budget を自動調整。 spend 実測 · CPA · ROAS を秒単位で取得、 日次で learning loop が回る。 直近30日の ROAS 4.20倍はこの精度の結果。
02
SP-API 連携 · 在庫 · 補てん全自動
SP-API で FBA 在庫 · 販売 · 補てんを自動 pull。 独自 tool 「reimbursement-hunter」 で FBA 補てん漏れを 6 detector で検出、 初回稼働で ¥70,103 の未請求を発見済。 属人では見逃す領域を内製化。
03
OEM リサーチ v3 方法論
新商品選定は 7 stage の独自方法論 (BSR 分析 · レビュー scrape · listing scrape · KW 実測 · JTBD 分析 · スプシ反映 · validator PASS) で意思決定。 全数字に出典明記、 感覚判断を排除。 バイクカバー等の次期 SKU 選定で既に稼働。
04
中国工場直取引 · Rakumade 経由
中国 OEM 工場と直取引 (代行商社経由ではなく発注 · 検品 · 出港を一次情報で管理)。 現在 4,000 個の厚型追加発注が 9月中国出港 → 大野倉庫中継 → FBA 納入の flow で進行中。
05
日次監視 · サイレント死検知
広告主力KW の予期せぬ停止 · LWA credential 切れ · autopilot 停滞 · learning log 断絶を独自 daily audit で検知。 「動いてるはず」 の楽観判断を構造で排除、 15 項目を毎朝監視。
06
大野倉庫 · 物流中継基盤
福井県大野市に自社中継倉庫 (大野倉庫) を持ち、 中国出港から FBA 納入までの中継 · 検品 · 分納を自社で制御。 FBA 単独委託では対応できない分割 · 抜き取り検品が可能。
差別化の一言: 同規模 Amazon セラーが 「手作業 · 経験則 · 属人的」 で運営する領域を、 弊社は全て 「API · 自動化 · 実測 evidence」 に置き換えている。 追加資本が入っても運営コストが線形に増えない。

08スケールの余地

現在の制約は 「在庫 · 広告予算 · SKU 数」 の 3 点。 追加資本はこの 3 制約を順に解除する使途に限定。

01
在庫積み増し
現在の 4,000 個追加発注 (9月着) を 8,000 → 12,000 個に引き上げることで 「在庫切れ期間」 (機会損失) を排除。 直近 8月中旬は在庫切れで主力KW が一時停止、 復旧作業が発生した。 資本で在庫 buffer を厚くする。
02
広告費引き上げ
直近30日 spend ¥406,457 / ROAS 4.20倍。 spend を ¥600,000 → ¥1,000,000 / 月に引き上げても、 KW と CPA のコントロールで ROAS 3.5〜4.0倍を維持できる見込み。 佐瀬コンサルの学習 loop で反応秒単位。
03
追加 SKU 展開
OEM リサーチ v3 方法論でバイクカバー等の次期 SKU 選定が進行中。 PEGAT 事業の KW · レビュー · 中国工場 network を横展開することで立ち上げ期を圧縮 (12ヶ月 → 6ヶ月目標)。
04
マルチチャネル拡張
現在 Amazon 独占。 楽天 · Yahoo · 自社 EC (Shopify) への横展開で追加販路を確保。 FBA と別の直送 flow が必要になるため、 大野倉庫の中継機能を拡張する使途も含む。

10開示すべきリスク

投資判断のために、 弊社が認識しているリスクを高 / 中 / 低の 3 段階で開示。 隠すより開示が誠実と判断。

在庫切れ (機会損失)
中国 OEM 発注 → 出港 → 大野倉庫 → FBA 納入の flow で 40〜60 日のリードタイム。 現在も一時在庫切れ中 (9月頭復旧予定)。 在庫 buffer 拡張で緩和。
中
為替 (中国元 / 日本円)
仕入は元建決済。 元高進行で単品仕入コストが上昇する可能性。 過去 12ヶ月で ± 5% の変動は吸収済。
中
Amazon 手数料改定
販売手数料 · FBA 手数料は Amazon 側で改定の可能性。 過去は年 1 回前後の改定頻度、 単品経済に ± ¥50 程度の影響。
低
競合参入
車用シートクッションカテゴリは参入障壁低。 レビュー累計 · KW 最適化 · 中国工場 network で先発優位を維持する必要あり。
中
広告 CPC 上昇
Amazon Ads の競合入札で CPC が上がると CPA も上昇。 KW 学習 loop で適応する設計だが、 極端な上昇で ROAS 悪化の可能性。
中
Amazon アカウント停止
アカウント停止は事業停止直結。 3 店舗分散とレビュー品質 · カテゴリ制約遵守でリスク分散。 過去 12ヶ月で警告履歴なし。
高

11運用体制

属人運営ではなく、 API 自動化 + 少人数判断の組み合わせで運営。 追加資本が入っても運営コストが線形に増えない設計。

経営判断
吉田司 (代表取締役) · 佐瀬コンサル (Amazon 広告顧問)
日次運用
Ads API 直叩きの内製自動 pipeline が KW · bid · spend を秒単位で監視 · 日次で自動調整 (直近30日 ROAS 4.20倍の維持に使用)
在庫 · 物流
