01エグゼクティブサマリ

スケルトン株式会社 は Amazon 3店舗 · 中国 OEM 直取引 で 12ヶ月 の 稼働実績 を 持つ。 その 主力 直販 商材 が PEGAT 車用シートクッション (厚型 · 薄型 の 2 SKU) で、 累計 4,212 個 販売 · 直近30日 の 広告 ROAS 4.20倍 · 定常黒字 フェーズ に 到達。

投資 位置づけ: 立ち上げ期 の 不確実性 (製品適合 · 広告最適化 · レビュー獲得) は 通過済。 追加資本 の 使途 は 「既に 売れている モデル」 の 在庫 積み増し · 広告費 引き上げ · 追加 SKU 展開 に 限定。 現在 4,000 個 の 追加 OEM 発注 (9月 中国 出港 · 大野倉庫 中継) が 進行中 で、 入荷 と 同時 に 販売 加速 予定。
数字 表記 の 前提: 本資料 の 数字 は Amazon SP-API · Ads API · 社内 Sheets の 実測 に 基づく (章末 evidence 参照)。 会社 全体 の Amazon 3店舗 合算 売上 は 一部 API 認証 更新 中 の ため 別途 開示 予定。 PEGAT 事業 単独 の 数字 は 全て 独立検証 済。

03弊社 の 強み

同規模 の 個人 · 小規模 Amazon 事業者 と 比較 して、 スケルトン は 「情報 と 自動化 の 内製化」 で 差別化 している。 属人 運営 で は 到達できない 実測精度 · 反応速度 · 継続性 を 持つ。

01
Ads API 自動運用 pipeline
Amazon 広告 は Web UI 手動運用 が 一般的 だが、 弊社 は Ads API 直叩き で bid · KW · budget を 自動 調整。 spend 実測 · CPA · ROAS を 秒単位 で 取得、 日次 で learning loop が 回る。 直近30日 の ROAS 4.20倍 は この 精度 の 結果。
02
SP-API 連携 · 在庫 · 補てん 全自動
SP-API で FBA 在庫 · 販売 · 補てん を 自動 pull。 独自 tool 「reimbursement-hunter」 で FBA 補てん漏れ を 6 detector で 検出、 初回稼働 で ¥70,103 の 未請求 を 発見 済。 属人 で は 見逃す 領域 を 内製 化。
03
OEM リサーチ v3 方法論
新商品 選定 は 7 stage の 独自 方法論 (BSR 分析 · レビュー scrape · listing scrape · KW 実測 · JTBD 分析 · スプシ 反映 · validator PASS) で 意思決定。 全 数字 に 出典 明記、 感覚 判断 を 排除。 バイクカバー 等 の 次期 SKU 選定 で 既に 稼働。
04
中国工場 直取引 · Rakumade 経由
中国 OEM 工場 と 直 取引 (代行 商社 経由 で は なく 発注 · 検品 · 出港 を 一次 情報 で 管理)。 現在 4,000 個 の 厚型 追加 発注 が 9月 中国 出港 → 大野倉庫 中継 → FBA 納入 の flow で 進行中。
05
日次 監視 · サイレント死 検知
広告 主力KW の 予期せぬ 停止 · LWA credential 切れ · autopilot 停滞 · learning log 断絶 を 独自 daily audit で 検知。 「動いてる はず」 の 楽観判断 を 構造 で 排除、 15 項目 を 毎朝 監視。
06
大野倉庫 · 物流 中継 基盤
福井県 大野市 に 自社 中継 倉庫 (大野倉庫) を 持ち、 中国 出港 から FBA 納入 まで の 中継 · 検品 · 分納 を 自社 で 制御。 FBA 単独 委託 で は 対応できない 分割 · 抜き取り 検品 が 可能。
差別化 の 一言: 同規模 Amazon セラー が 「手作業 · 経験則 · 属人的」 で 運営 する 領域 を、 弊社 は 全て 「API · 自動化 · 実測 evidence」 に 置き換えている。 追加資本 が 入って も 運営 コスト が 線形 に 増えない。

08スケール の 余地

現在 の 制約 は 「在庫 · 広告予算 · SKU 数」 の 3 点。 追加資本 は この 3 制約 を 順に 解除 する 使途 に 限定。

01
在庫 積み増し
現在 の 4,000 個 追加発注 (9月着) を 8,000 → 12,000 個 に 引き上げる こと で 「在庫 切れ 期間」 (機会損失) を 排除。 直近 8月中旬 は 在庫切れ で 主力KW が 一時 停止、 復旧作業 が 発生 した。 資本 で 在庫 buffer を 厚くする。
02
広告費 引き上げ
直近30日 spend ¥406,457 / ROAS 4.20倍。 spend を ¥600,000 → ¥1,000,000 / 月 に 引き上げても、 KW と CPA の コントロール で ROAS 3.5〜4.0倍 を 維持できる 見込み。 佐瀬 コンサル の 学習 loop で 反応 秒単位。
03
追加 SKU 展開
OEM リサーチ v3 方法論 で バイクカバー 等 の 次期 SKU 選定 が 進行中。 PEGAT 事業 の KW · レビュー · 中国工場 network を 横展開 する こと で 立ち上げ 期 を 圧縮 (12ヶ月 → 6ヶ月 目標)。
04
マルチチャネル 拡張
現在 Amazon 独占。 楽天 · Yahoo · 自社 EC (Shopify) への 横展開 で 追加 販路 を 確保。 FBA と 別 の 直送 flow が 必要 に なる ため、 大野倉庫 の 中継 機能 を 拡張 する 使途 も 含む。

10開示すべき リスク

投資 判断 の ため に、 弊社 が 認識 している リスク を 高 / 中 / 低 の 3 段階 で 開示。 隠す より 開示 が 誠実 と 判断。

在庫 切れ (機会損失)
中国 OEM 発注 → 出港 → 大野倉庫 → FBA 納入 の flow で 40〜60 日 の リードタイム。 現在 も 一時 在庫切れ 中 (9月頭 復旧 予定)。 在庫 buffer 拡張 で 緩和。
中
為替 (中国 元 / 日本 円)
仕入 は 元建 決済。 元高 進行 で 単品 仕入 コスト が 上昇 する 可能性。 過去 12ヶ月 で ± 5% の 変動 は 吸収 済。
中
Amazon 手数料 改定
販売手数料 · FBA 手数料 は Amazon 側 で 改定 の 可能性。 過去 は 年 1 回 前後 の 改定 頻度、 単品 経済 に ± ¥50 程度 の 影響。
低
競合 参入
車 用 シートクッション カテゴリ は 参入 障壁 低。 レビュー 累計 · KW 最適化 · 中国工場 network で 先発 優位 を 維持 する 必要 あり。
中
広告 CPC 上昇
Amazon Ads の 競合 入札 で CPC が 上がる と CPA も 上昇。 KW 学習 loop で 適応 する 設計 だが、 極端 な 上昇 で ROAS 悪化 の 可能性。
中
Amazon アカウント 停止
アカウント 停止 は 事業 停止 直結。 3 店舗 分散 と レビュー 品質 · カテゴリ 制約 遵守 で リスク 分散。 過去 12ヶ月 で 警告 履歴 なし。
高
レビュー 品質 低下
製品 品質 · 配送 品質 に 起因 する レビュー 低下 は 売上 直撃。 中国工場 検品 · 大野倉庫 検品 の 2 段 で 品質 制御。
中
