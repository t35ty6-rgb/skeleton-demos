各 行 の 「＋」 ボタン は 「その 人 が 連れて きた 人」 を 追加 する ボタン。 兄弟 (同 レベル) は お互い の 発注 に は 関与 しない。 詳細 は 下 の 「仕組み を 3分 で 理解」 参照。

仕組み を 3分 で 理解 する (ネットワークビジネス 初 めて の 人 向け)

このツール は こう 読む: tree の 一番 上 が 「自分」、 その 下 に 「自分 が 直接 連れて きた 人 (直下)」、 更に その 下 に 「その 人 が 連れて きた 人」 が 並ぶ。 親子 関係 = 「誰 が 誰 を 勧誘 したか」。 兄弟 (同 レベル) は お互い の 発注 に は 関与 しない。

ランク 上がる ほど 商品 を 安く 仕入れ できる (愛用者 = 定価 100% / GC = 80% / GA = 60% / GM = 52% / GE = 47% / GP以上 = 39%)。 この 差額 が 儲け の 元。

3 パターン の 具体例 (¥600,000 の 発注 で どこ に お金 が 流れる か)

  1. パターン ①: 自分 (GA) が 直接 連れて きた ひかる (GC) が 発注
    tree: 自分 GA → ひかる GC (¥600,000)
    → 自分 に +¥120,000 (= ¥600k × [40% − 20%] = 20% の spread)
    → ひかる に 0 円 (自分 の 発注 は 自分 の 儲け に なら ない)
  2. パターン ②: 自分 → ひかる (GC) → お母さん (愛用者 · 客)、 お母さん が 発注
    tree: 自分 GA → ひかる GC → お母さん 愛用者 (¥600,000)
    → ひかる に +¥120,000 (= ¥600k × [20% − 0%] = GC が 客 に 定価 で 売って 20% margin)
    → 自分 に +¥90,000 (= ¥600k × [40% − 20%] − 5% 愛用者 調整費 = ¥120k − ¥30k)
  3. パターン ③: 自分 → ひかる (GC) → お母さん (GC · 代理店)、 お母さん が 発注
    tree: 自分 GA → ひかる GC → お母さん GC (¥600,000)
    → ひかる に 0 円 (GC → GC の 同ランク 間 は 儲け 発生 しない)
    → 自分 に +¥120,000 (= ¥600k × [40% − 20%] の spread、 ひかる を 飛び越えて 自分 に 入る)

誤解 の ポイント: 「ひかる が 連れて きた 人 の 発注 なら 全部 ひかる に 入る」 と 思い がち だが、 ひかる 自身 が GA 以上 じゃ ない と、 同ランク (GC) 下 から は 1 円 も 入ら ない。 ひかる を GA に 昇格 させる か、 下 の 人 を 愛用者 (客) に する と 儲け が 出る。

同 ランク が 続く 場合 (breakaway ボーナス)

自分 と 直下 が 同 ランク (例: 自分 GM ← 田中 GM) の 場合、 spread は 0 だが 特別 の 「同 ランク ボーナス」 が 発生:

  • 自分 GM ← 田中 GM ← お母さん GC (¥100k 発注) の 場合、 田中 は 28% spread で ¥28,000、 自分 は GM 1次 ボーナス 2% で ¥2,000
  • 公式 プラン p.14 の 「※GA以上 の ランク が 2次、3次 と 続く 場合 は 直上 の ランク と ボーナス 率 に 基づき 配分 計算」 に 準拠

愛用者 (客) の 発注 に は 5% 引かれる

愛用者 が 発注 した 場合、 直上 の GA+ 代理店 の 販売卸差益 から 5% が 「送料 + 業務 対応 コスト の 調整費」 として 引かれる (2026年6月度〜 の 新 rule)。 GC が 直上 の 場合 は GC に は かから ず、 更に 上 の GA+ に 適用。

コミッション 発生 条件 (シミュレーター は 満たす 前提)

  • 当月内 に 「直新規 紹介 1名 以上」 又は 「1 アイテム 以上 の 自己購入」
  • 同ランク ボーナス は GA 以上 で、 GM/GE は サイド 売上 10万+/月、 GP+ は 50万+/月

注意

  • 入力 する 「契約 額」 は 上代税抜 (retail 相当)。 買い手 が 実 支払う 現金 では ない
  • 本 シミュレーター は 単月 の 収入 モデル。 昇格 条件 (総傘下 売上 累計 等) は 計算 対象外
  • 「調整費」 は 2026年6月度 以降 の 新 rule。 それ 以前 は 適用 なし
