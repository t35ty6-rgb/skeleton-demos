計算 ルール (公式 マーケティング プラン p.14 準拠)

  1. 販売卸差益 (waterfall) — 下 の 人 の 注文 に 対し、 「自分 の 販売卸差益率 − 直下 の 販売卸差益率」 の spread を 取る。 例: GC 20% → GA 40% で GA は 契約額 × 20%
  2. 同ランク が 2次・3次 と 続く 場合 — spread が 止まり、 その 上 の 同ランク は ボーナス 表 の 世代 別 料率 で 配分。 例: GM (me) ← GM ← GC の 場合、 中 GM が 28% (spread)、 上 GM (me) は GM 1次 ボーナス 2% (公式 プラン 「※GA 以上 の ランク が 2次、3次 と 続く 場合 は 直上 の ランク と ボーナス 率 に 基づき 配分 計算」 の 実装)
  3. 愛用者 の 注文 — 直上 の GA+ の 販売卸差益 から 上代税抜 の 5% を 「調整費」 として 控除 (2026年6月度〜)
  4. アシスタント 料 — 直上 GA+ の 販売卸差益 から 契約額 の 5% を 控除 (登録 された アシスタント へ)。 上 の toggle で ON/OFF
  5. コミッション 発生 条件 — 当月内 に 「直新規 紹介 1名 以上」 又は 「1 アイテム 以上 の 自己購入」 (シミュレーター は 条件 満たす 前提)
  6. ボーナス 資格 — GA 以上、 GM/GE は サイド 売上 10万+/月、 GP+ は 50万+/月 (シミュレーター は 資格 満たす 前提)

注意

  • 入力 する 「契約 額」 は 上代税抜 (retail 相当)。 買い手 が 実 支払う 現金 では ない
  • 本 シミュレーター は 単月 の 収入 モデル。 昇格 条件 (総傘下 売上 累計 等) は 計算 対象外
  • 「調整費」 は 2026年6月度 以降 の 新 rule。 それ 以前 は 適用 なし
