越前おおの 管理画面

登録済み メールと パスワードで ログインしてください。

Skel·EC と 同じ Firebase Auth を 使っています。
Skel·EC の パスワードで ログインできます。

🛠 初回セットアップが 必要です

この 管理画面を 使うには、Firebase プロジェクトの 接続情報を admin.html の FIREBASE_CONFIG に 入力する 必要が あります。 一度だけ 3〜5分 で 完了します。

  1. Firebase Console で 新規プロジェクトを 作成（プロジェクト名: skeleton-madeinono 推奨）。
  2. Firestore Database を 有効化（本番モード / asia-northeast1 リージョン）。
  3. Authentication を 有効化 → メール/パスワードプロバイダを 有効化 → オーナー自分の アドレスで ユーザー追加。
  4. プロジェクト設定 → ウェブアプリ を 追加 → 設定オブジェクトを コピー。
  5. この admin.html の 上部 FIREBASE_CONFIG 変数に 貼り付け（下例 参照）。
  6. Hosting は 任意（firebase init hosting → firebase deploy）。 ローカル file:// でも 動作します。
const FIREBASE_CONFIG = {
  apiKey: "AIza...",
  authDomain: "skeleton-madeinono.firebaseapp.com",
  projectId: "skeleton-madeinono",
  storageBucket: "skeleton-madeinono.appspot.com",
  messagingSenderId: "123456789012",
  appId: "1:123456789012:web:abc123"
};

設定後、この ページを 再読み込みしてください。 スケルトンサポート: Jobs (AI CEO) まで DM。
