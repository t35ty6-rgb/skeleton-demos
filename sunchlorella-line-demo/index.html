01   ISSUES

ヒアリングで見えた、6つの課題

現場・営業・本社それぞれで発生している「もったいない」を、まず1枚に整理しました。

01 営業実績

訪問販売の売上が、EC部門に直入りしてしまう

玄関先で受注しても、お客さまが後日オンラインで買うと、担当販売員の実績にならない。営業のモチベーションを削っている。

02 配信

公式LINEが一斉配信しかできない

年齢・商品履歴・定期便の有無で分けたいのに、今は「全員に同じ内容」しか送れない。
解約率と広告費が両方悪化している。

03 導線

LINE内で買い切れない

LINEでご案内しても、購入時に外部サイトへ飛ばされてしまう。中高齢のお客さまの離脱が最も多いポイント。

04 入力負担

メールアドレス入力が、購入の壁になっている

中高齢のお客さまにとって、メール登録は最大のハードル。
LINEアカウントだけで注文が完結する導線が必要。

05 運用

公式LINEが部署ごとに 4アカウントに分散

お客さまから見て「どこに聞けばいいか分からない」状態。
月額固定費も 4本ぶん、部署間の情報も分断されている。

06 可視化

チャネル横断の売上が見えていない

訪問販売・LINE EC・自社ECの数字が別バケツで、月次会議で「全体でどうなっているか」の議論ができない。

02   SOLUTION

解決策は、この 4本柱で束ねます

それぞれを別々のSaaSで買うと年間 数百万円 掛かる領域を、貴社専用の一つのOSに統合します。

1. 公式LINE 4→1 統合

部署別4アカウントを、1つの公式アカウントに束ねます。
  • 友達追加パラメータ (販売員QR/DM/イベント) でタグを自動付与
  • タグに応じて、リッチメニューが自動で切り替わる
  • 旧4アカから2週間の移行キャンペーン (移行率 60–80% 想定)
  • 月額固定費 × 4本 → 1本に集約

2. セグメント配信エンジン

属性・行動・購買意思の3階層タグで、届けたい人にだけ届ける。
  • タグAND/OR絞り込み → 該当人数リアルタイム表示
  • Flex Message ビジュアル編集 (画像+文+ボタン)
  • A/Bテスト配信 (30/70で試打 → 開封率高い方を本配信)
  • 誕生月/休眠/カート放棄 のトリガー自動配信

3. LIFF内 ワンタップEC

LINEから一歩も出ずに、商品閲覧・購入・定期便変更まで完結。
  • メールアドレス入力ゼロ (LINE User ID がキー)
  • 初回のみ氏名・住所入力、次回以降は自動
  • LINE Pay / クレジット / 代引き 全対応
  • 定期便は Stripe Subscription で継続課金/停止/次回スキップ

4. 訪問販売員アプリ + 本社ダッシュボード

この案件の本丸。営業実績の帰属を、永続的に守ります。
  • 玄関先でQR友達追加 → 販売員ID が LINE User ID に永続刻印
  • お客さまが後日LINEで買い足しても、担当販売員の実績に加算
  • 販売員別ランキング/インセンティブ自動計算
  • 本社は 3チャネル横断の売上・LTV・継続率を1画面で
