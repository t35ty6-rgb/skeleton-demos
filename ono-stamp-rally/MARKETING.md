# 福鉄スタンプラリー · 集客・運用マーケ設計

**このドキュメントの目的**: スタンプラリーを「一過性のキャンペーン」で終わらせず、集まった LINE 友だちを **沿線ファンとして継続顧客化** する全体設計。ラリー自体は集客装置、本命は継続する接点。

---

## ゴール設計

| 期間 | 目標 | 指標 |
|---|---|---|
| **PoC 3週間** | 参加者3,000名 / コンプリート率15% / 定期外再乗率+25% | 押印数 · LINE友だち追加数 · 沿線乗車数 |
| **中期 3ヶ月** | LINE友だち 2,000名を沿線ファン化 | リテンション率 (次期ラリー再参加) · 月次push開封率 |
| **長期 1年** | 季節ラリー4回で年間参加者10,000名 · 定期券販売への貢献 | 定期券販売数(前年比) · 沿線店舗パートナー数 · UGC (SNS投稿)数 |

## Phase 1 · 集客 (ラリー開始前〜期間中)

### 動線A · 現地告知
- **駅ホーム** — A2ポスター (QR大書き) を10駅に掲出
- **車内** — F1000形の車内モニターに30秒紹介動画
- **参加店** — 沿線カフェ10店舗にステッカー貼付「うちに QR あります」
- **窓口** — 駅窓口で紙のガイドブックA5配布 (アプリDL不要、URL 1つでOK)

### 動線B · SNS・地元媒体
- 福鉄公式X / Instagram で 週2回告知
- 福井市 / 鯖江市 / 越前市 の観光協会と相互投稿
- 地元テレビ (FBC/FTB) / 福井新聞 プレスリリース
- インフルエンサー (鯖江眼鏡系、恐竜モニュメント系) にお試し参加依頼

### 動線C · LINE 導線
- 福井駅前 恐竜モニュメントに「参加はここから」QR (LINE友だち追加 → LIFF起動)
- 車内広告に QR (「今すぐ参加」)
- 沿線店舗パートナーが提示する QR も同じ動線

### 動線D · パートナー店連携
- 沿線飲食店・カフェ10店舗と 「ドリンク引換パートナー」 契約
- 引換時に「次回ラリーもぜひ」 の一言 (継続化のきっかけ)
- パートナー店にも 独自の QR (店舗限定ボーナススタンプ) 発行可

## Phase 2 · 育成 (ラリー期間中〜終了1ヶ月)

集まった友だちをセグメント化して段階配信。**broadcast は禁止、必ず push (to: userId) で送る** (memory準拠)。

### セグメント定義

| ID | セグメント | 条件 | 想定人数(3,000中) |
|---|---|---|---|
| **S1** | 新規参加 | 押印1個 | 900 |
| **S2** | 育成中 | 押印2〜3個 | 800 |
| **S3** | あと少し | 押印5〜6個 | 500 |
| **S4** | コンプ達成 | 押印10個 | 450 |
| **S5** | 途中離脱 | 3日以上押印なし | 350 |

### 配信スケジュール (期間中)

| セグメント | タイミング | 文面例 |
|---|---|---|
| S1 → 翌日 | 初押印+1日 | 「◯◯さん、越前和紙の里 押印おめでとう！あと3個で 沿線カフェ ドリンク1杯 交換できます。 次のオススメは 徒歩12分の 武生中央公園」 |
| S2 → 週末前 | 金曜18時 | 「今週末はどこ行く？ ◯◯さん、まだ行ってない7スポットはこちら [地図画像]」 |
| S3 → 期限3日前 | 8/28 09時 | 「コンプまで あと4個！ 残り3日、金曜〜日曜で回れる おすすめ動線: 福井駅発 → 城址 → 養浩館 → 足羽神社 (2時間、徒歩)」 |
| S4 → 即時 | コンプ達成瞬間 | 「◯◯さん、コンプおめでとう！硬券セットは福井駅観光案内所で 8/31まで お受け取りください。次期ラリーは秋10月開催、いち早くお知らせします」 |
| S5 → 3日目 | 3日更新なし | 「◯◯さん、ラリーは8/31まで。次にオススメは 現在地から 一番近い ◯◯です [写真]」 |

### 育成B · 沿線イベント連動
- **サンドームコンサート日**: SP-02の押印を来場者限定x2倍
- **菊人形祭り期間**: SP-03 のみ 特別スタンプ (SNSシェア推奨)
- **福井まつり**: 全スポットでボーナス

### 育成C · UGC 促進
- ハッシュタグ `#福鉄さんぽ` で SNS投稿 → 抽選で 1日フリーきっぷ + 沿線カフェ ペア券
- コンプ時の 硬券帳画像 を LINE shareTargetPicker で友達招待動線
- 「◯人目のコンプ達成者」 記念画像 自動生成

## Phase 3 · 継続化 (ラリー終了1ヶ月〜)

**ここが本命**。ラリーは集客の装置、継続化が福鉄本業に効く。

### 継続A · 定常配信
- 月次「沿線便り」push · 季節スポット/新店紹介/イベント案内
- 誕生月 「◯◯さんの LINE友だち歴1周年 · 沿線ドリンククーポン」
- 天気連動 push (晴天週末に「今日は西山公園日和」)

### 継続B · 定期券・回数券 販促 (福鉄本業への還流)
- コンプ達成者に **「通勤定期券 初回3ヶ月 5%OFF」** クーポン
- **「回数券 10%OFF for ラリー参加者」** 期間限定
- 学生ラリー参加者は **「通学定期 春の応援キャンペーン」** に招待

### 継続C · 次期ラリー誘導
- 3ヶ月毎に **季節ラリー4本** (春の桜 / 夏のフェス / 秋の紅葉 / 冬のイルミ)
- 前回参加者は **早期エントリー** (3日前告知 + ボーナス初回スタンプ)
- 前回コンプ者は 硬券帳の **「金の栞」** (次期ラリーで倍率x1.5)
- 通算コンプ回数で 累計ランク (ブロンズ→シルバー→ゴールド→プラチナ)

### 継続D · 沿線店舗ネットワーク化
- 「福鉄さんぽパートナー」 認証で 店舗マップ公開
- 送客データを 月次で 店舗にレポート (福鉄→店舗の営業ツール化)
- パートナー店 集客増 → 契約継続率UP → 福鉄の 沿線価値UP

### 継続E · コミュニティ化
- LINE オープンチャット 「福鉄さんぽ会」 開設
- 月1回 リアルイベント (駅巡り会、沿線カフェ巡り)
- 常連さん を 「福鉄さんぽ大使」 認定 (口コミの中核)

## 実装との対応

### アプリ側 (Phase 2 · 実装済または実装予定)
- **LIFF化** — LINE友だち追加 → LIFF起動で userId + 名前 自動取得 [実装済]
- **SNSシェア** — コンプ時に shareTargetPicker で 硬券帳をシェア [未実装]
- **プロフィール画面** — pictureUrl + 押印履歴 + 総距離 表示 [未実装]
- **友だち招待** — LINE友だち招待動線 [未実装]

### 運営側 (admin 拡張)
- **セグメント配信 UI** — S1〜S5 別に push文面作成 → 送信 [Phase 2で実装]
- **月次レポート auto生成** — PDF + Google Sheets 転記 [Phase 2]
- **沿線店舗連携ダッシュボード** — 送客数 / 引換数 / 評価 [Phase 3]
- **パートナー店 QR発行機能** — 店舗独自 QR 生成 [Phase 3]

### Backend (Firebase + Messaging API)
- **Firestore** — LINE userId をキーに 押印履歴保存
  - `fukutetsu/rallies/{rallyId}/participants/{userId}` — ユーザー情報
  - `fukutetsu/rallies/{rallyId}/stamps/{docId}` — 押印ログ
  - `fukutetsu/segments/{segId}` — セグメント定義
- **Cloud Functions**
  - `onStampCreated` — 押印時に セグメント再計算 · 累計チェック · コンプ達成push
  - `scheduledSegmentPush` — 定時 (毎日20時) セグメント自動走査 → push
  - `weatherTrigger` — 天気APIと連動 push (継続 Phase)
- **Messaging API** — LINE公式アカウント から push (to: userId必須、broadcast禁止)
