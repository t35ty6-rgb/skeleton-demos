「新規プロバイダ作成」 ボタン → プロバイダ名 = 「Skeleton FP 事務所名」 など 自由に入力 → 作成。

Jobs 側 ログ用。 後で 何 作ったか わかる ように。 空欄 OK。
3

Messaging API チャネル 作成

プロバイダ の 中 に お客様 と 通信 する チャネル を 作る

作った プロバイダ を 開く → 「新規チャネル作成」 → 「Messaging API」 を 選ぶ。

入力欄:

  • チャネル名: 公式アカウント名 と 同じ で OK (例: 山田FP事務所)
  • チャネル説明: 「FP相談 LINE」 等 適当 で OK
  • 大業種 / 小業種: 「金融」 → 「保険・FP」 等 該当 する もの
  • その他: そのまま 同意 → 作成

作成完了 (チャネル管理画面 に 入れた) を 確認 してから 「次へ」。

4

Channel access token を 取得

サーバー から LINE に メッセージ送信 する 鍵

チャネル管理画面 の 「Messaging API設定」 タブ を 開く → 一番下 まで スクロール → 「チャネルアクセストークン(長期)」 欄 の 「発行」 ボタン を 押す。

↑ こんな 感じ で 表示される
Messaging API設定 タブ → チャネルアクセストークン(長期)
qwerty12345abcdEFGHIJKLmnopQRSTuv... (200文字以上)
↑ この 長い文字列 を 全部コピー
200文字以上 の 長い文字列。 改行 入って OK (空白 除外される)。
5

Channel secret を 取得

webhook の 信頼性を 検証する 鍵 (改ざん防止)

同じ チャネル管理画面 で 「チャネル基本設定」 タブ に 切り替え → 「チャネルシークレット」 欄 の 「表示」 → コピー。

↑ こんな 感じ で 表示される
チャネル基本設定 タブ → チャネルシークレット
a1b2c3d4e5f6... (32文字)
↑ この 32文字 を コピー
32文字 の 短い文字列。
6

LINE Manager で 3つ 設定

自動応答 を OFF / Webhook を ON にする

LINE Official Account Manager を 開いて 「応答設定」 ページ で 3つ の トグル を 設定。

LINE Official Account Manager →

なぜ?
・Webhook ON = お客様 が 友だち追加 や メッセージ送信 した タイミング を Skelton サーバー に 通知
・応答メッセージ OFF = LINE 標準の自動返信 を 切る (Jobs が AI 返信案 を 作るので)
・あいさつ OFF = LINE 標準の あいさつ メッセージ を 切る (Jobs が テンプレ + アンケートURL を 送るので)

7

🚀 自動セットアップ 開始

Jobs が 入力情報 で 残り全部 セットアップ

下の ボタン を 押すと Jobs (Cloud Function) が 全自動 で:

  • ① Token 検証 (LINE API)
  • ② basicId / botUserId / 名前 / アイコン 取得
  • ③ tenant doc に 保存
  • ④ Webhook URL を LINE Console に 自動設定
  • ⑤ リッチメニュー 自動生成 + 配信
  • ⑥ アンケートURL / 友だち追加URL / QR 発行

stg.app.skeleton-inc.jp の ログイン情報 を 入力 (一度だけ)
