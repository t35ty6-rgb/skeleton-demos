OWNER · 数分/月

  • 営業 / 受注判断
  • 申込書URL を 送る (LINE 1通)
  • Jobs からの 完成通知 確認
  • 入金確認 (月次)

  • 申込書 受信 → 自動セットアップ (30分)

  • SaaS テナント作成 + 設定反映
  • サロン / オーナー 双方 に 通知
  • バグ修正 / 機能追加 / サポート

  • 申込書 を 埋める (10分)
  • 届いた ログイン情報 で 入る
  • 予約URL を お客様 に 共有
  • 日常 業務 で SaaS を 使う
  • 月¥3,000 を 振込
