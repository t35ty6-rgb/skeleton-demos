Megumi さん の 競合位置

他 の ジム と 比べて 「ここ が 違う」 と 外 から 見て 分かる ポイント。 値段 決め の 判断材料 に。

  1. 女性 の トレーナー 産後 / フェムケア / 更年期 は 男性 トレーナー が 入り にくい 領域。 「先生 が 女性」 だけ で 値段 を 支える 理由 に なる。
  2. フォトヨガ / 産後ケア / 美肌食 の 3つ 富山 で 直接 かぶる 競合 が 見当たら ない。 「近所 の 大手 ジム と 比べら れない」 場所 に いる 状態 は 強い。
  3. 対面 (射水) と オンライン の 両輪 対面 で 信頼 作って、 引越し や 産後 で 通え なく なった 客 を オンライン に 移せる 動線 が 作れる。 「一度 通った 客 が 一生 の 客」 に なる 仕組み は 対面 のみ の ジム に は 出せ ない。
  4. 美肌食マイスター の 資格 食事相談 が 「PT の おまけ」 じゃなく 単独 で 単価 が 立つ。 相場 (¥5,000〜¥10,000/回) の 中位 で 出せる のは 資格 が ある 人 だけ。

手取り の 計算 式 (汎用)

月額料金 (SkelFit) と Stripe 手数料 が どこ で 差引 される か の 汎用 式:

  • 売上 単価 × 客数
  • Stripe 手数料 − (単価 × 3.6% + ¥40) × 決済回数
  • SkelFit 月額 − ¥9,800 (SOLO) / ¥19,800 (PRO) / ¥39,800 (STUDIO)
  • 手取り = 売上 − Stripe − SkelFit

例: 月4回券 ¥15,000 を 5人 に 売ると 売上 ¥75,000、 Stripe ¥2,900 (3.6%×5 + ¥40×5)、 SkelFit SOLO ¥9,800 を 引いて 手取り 約 ¥62,300。 単価 と 客数 を 動かすと 手取り が どれ ぐらい 変わる か、 一度 Excel で 表 を 作って みる と 見え やすい かも。 客 が 20名 を 超えた ら SOLO → PRO の 昇格 が 必要。
