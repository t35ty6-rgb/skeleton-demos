FP Compass ご利用開始 ガイド

この度は FP Compass をご導入いただき、誠にありがとうございます。本書では、初日にやっていただきたい 5 ステップを順番にご案内します。所要時間は合計 60 分です。
ご担当 ○○ 様

まずは 専用 CRM URL をブックマークしていただくところから始めましょう。すべての設定は本書 1 枚で完結するように作っています。途中で詰まった場合は最後のページの サポート窓口 までお気軽にご連絡ください。Skeleton 担当者が即日中にフォローいたします。
1
専用 CRM URL を開く
5 分

Skeleton から別途お送りした招待メール内の 専用 CRM URL をクリックしてください。Chrome ブラウザでの利用を推奨します。

🔗
Action
専用 CRM URL を開いたら、Chrome のブックマークバーに追加してください。毎日 1 タップで開けるようになります。
💡 ヒント: Safari でも基本機能は動作しますが、Zoom 録画は Chrome 必須です。日常的に Chrome での利用を推奨します。
2
Google アカウントでログイン
3 分

初回起動時、「Google でログイン」 ボタンを押してください。普段お使いの Gmail アカウントを 1 回タップで連携完了です。パスワードを覚える必要はありません。

🟢
Action
Google アカウントを選択 → 「許可」 をタップ。30 日間ログイン状態が維持されます。
🔒 セキュリティについて: FP Compass はパスワードを保存しません。Google が公式に管理する認証だけを使用するため、万一の漏洩リスクを根本から減らしています。Pro プランをご契約の方は、追加で 2 要素認証 (Google Authenticator 等) の設定もお願いします。
3
LINE 公式アカウントを連携する
20 分

お客様 (エンドユーザ) との LINE 双方向連携を設定します。お送りした Webhook URL を LINE Developers Console で 1 箇所に貼り付けるだけです。

💬
Action
① LINE Developers (developers.line.biz) にログイン
② Messaging API チャネルを選択
③「Webhook URL」に Skeleton 発行のURLを貼り付け
④「Webhook 利用」を ON
📋 困った時: Skeleton 担当者と画面共有で 10 分でサポートします。Zoom 設定支援を希望される場合は遠慮なくご連絡を。
4
Zoom を連携する (オプション・推奨)
20 分

Zoom 面談を 自動 URL 発行 + AI 議事録生成 で省力化したい場合、Zoom Server-to-Server OAuth を設定します。

📹
Action
① Zoom Marketplace で Server-to-Server OAuth アプリを作成
② 認証情報 (Account ID / Client ID / Client Secret) を取得
③ 取得した情報を Skeleton 担当者へメール送付 (暗号化 PDF 推奨)
④ Skeleton 側で設定完了 (当日中)
💡 ヒント: Zoom 連携をしなくても CRM の主要機能は使えます。後からでも追加可能です。
5
初回顧客を 1 名 登録してみる
10 分

準備が整ったら、実際の顧客を 1 名 登録してみましょう。後日のフォローアップに繋がります。

👤
Action
CRM 右上の「+ 顧客追加」 → 名前 / 生年月日 / 家族構成 を入力 → 「保存」
これで タイムライン (向こう30年のライフイベント) が自動展開されます。
