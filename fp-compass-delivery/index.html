04 ご利用開始 5 ステップ

  1. URL をブックマーク — Chrome のブックマークバーに本番システムURL を追加 (デモ顧客 30 名で動作確認できます)
  2. デモ顧客で動作確認 — 任意の顧客クリック → タイムライン / LINE 履歴 / 面談記録 各タブを一通り操作
  3. 右上「🗑 全データリセット」 — デモ顧客を全消去して 0 人状態にし、ご自身の本番運用を開始
  4. 顧客追加 — 「+ 顧客追加」から実顧客を登録 (家族構成 / 職業 / 最終接触日 等を入力)
  5. 面談実施 — Zoom 面談時に「録画ON」ボタン → 終了後に AI 議事録が自動生成 → 次の提案 LINE まで一気通貫

05 ご利用 注意事項

1. データ保管: 顧客情報は Google Sheets + Drive 上に保管されます (ご担当 Google アカウント配下) 。
2. AI 議事録: Whisper の文字起こし精度は約 90 % です。固有名詞は手動補正してください。
3. AI 下書き: 生成された LINE 下書きは必ず送信前に内容ご確認をお願いします (誤情報含む場合あり) 。
4. ブラウザ: Chrome 推奨 (Safari / Firefox / Edge も基本動作しますが、Zoom 録画は Chrome 必須) 。
5. メンテナンス: システム更新は無停止で随時実施いたします。
