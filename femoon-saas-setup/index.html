tenant / tenantId (あなた専用ID)
SaaS 上 で サロン 単位 を 表す 箱。 申込フォーム の メアド から 1つ 自動発行 される。 顧客データ / 予約データ は すべて この 箱 の 中 に だけ 入り、 他店 と 混ざらない。 管理画面URL の 末尾 ?tenant=xxxxx が これ
申込フォーム
PHASE 1 で 記入 する 1ページ の フォーム。 SaaS 設定 を Skeleton社 が 全部 代行 する ため の 入り口
不定休 ルール
申込フォーム の 1欄。 「第1火曜・第3日曜 も 休み」 等 と 書くと、 予約カレンダー が 自動 で その日 を 休業 表示 に する。 第N曜日 パターン に 対応
プロバイダー
会社・お店 単位 の 一番 上 の 箱。 同じ プロバイダー の 中 に Messaging API (PHASE 3) と LINEログイン (PHASE 4) 両方 を 入れて こそ 連動 する。 名前 は FEMOON で 統一
チャネル
LINE で 機能 を 1つ 提供 する ため の 単位。 公式アカウント 用 の Messaging API チャネル と LIFF 用 の LINEログイン チャネル の 2種類 を 使う
LIFF (LINE Front-end Framework)
LINE の 中 で 開ける Webページ。 普通 と 違って LINE が ユーザー情報 (名前/userId) を 教えて くれる ので 「誰宛て に 通知」 を 送れる ように なる
LIFF ID
2010xxxxxx-xxxxxxxx 形式 の 番号。 LIFFアプリ を 作る と 自動 発行 される
LIFF URL
https://liff.line.me/{LIFF ID} の 形 の URL。 リッチメニュー に 貼ると LINE 内 で 予約フォーム が 開く
エンドポイントURL
LIFF が 開いた 時 に 実際 表示 される Webページ の URL。 ここ に PHASE 2 の メール で もらった 予約フォームURL を 貼る
Messaging API チャネル
LINE から メッセージ を 送る 用 の チャネル。 LIFF は ここ に 作れない。 LINEログイン チャネル と 別物
LINEログイン チャネル
LIFF を 入れる 用 の チャネル。 PHASE 4 で 新規 作成 する のは これ
Scope (profile / openid)
LIFF が お客様 から 取れる 情報 の 範囲。 profile = お名前 と プロフィール画像、 openid = userId (誰宛て に 通知 する か の 鍵)。 両方 ON 必須
サイズ (Full / Tall / Compact)
LIFF が 開いた 時 の 画面 の 大きさ。 Full = 全画面 (今回 これ)
ボットリンク機能 (Bot link)
LIFF で ログイン した お客様 を 公式アカウント の 友達 に 自動 追加 する 機能。 On (Aggressive) で 友達追加 → 通知 が 届く ように なる
