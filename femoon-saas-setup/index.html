STEP 06 / 10 — LINE連携 (7サブステップ)
LINE連携 を 完全 セットアップ
15-20分
DO
① 公式アカウント作成 → ② Messaging API有効化 → ③ トークン発行 → ④ SaaSに貼り付け
SUB STEP 6.1 — 公式アカウント を 作る
LINE Official Account Manager を 開く
https://manager.line.biz/
↗ 開く
① LINEログイン (普段使ってる LINE で OK)
② 右上 緑「アカウントを作成」
③ アカウント名 (例: フェムケアサロン FEMOON) / 業種を入れて 「作成」
④ ベーシックID (@xxxxxx で 始まる文字列) が 自動 発行される — これが 「公式アカウントID」
SUB STEP 6.2 — Messaging API を 有効化
作成した 公式アカウント の 設定 を 開く
① OA Manager のホーム画面 → 右上 ⚙ 「設定」
② 左メニュー 「Messaging API」
③ 「Messaging APIを利用する」 緑ボタン → プロバイダー名入力(任意・例: 自社名) → 同意 → 完了
④ 「Channel ID」「Channel Secret」 が 出る (この段階では 後で使うが すぐ次の手順)
SUB STEP 6.3 — アクセストークン を 発行
LINE Developers Console を 開く
https://developers.line.biz/console/
↗ 開く
① 「LINEアカウント」 でログイン (同じLINE)
② プロバイダー (6.2 で 作ったやつ) を クリック
③ Messaging API チャネル を クリック
④ 上のタブ 「Messaging API」
⑤ 一番下 「チャネルアクセストークン」 → 緑「発行」
⑥ 長い文字列 (200文字くらい) が 出る → これが 「Messaging APIトークン」
トークンは 1度だけ表示。 すぐ コピー して メモ帳 等に 一時保存 推奨。 紛失したら 同じ画面 で 再発行 可能。
SUB STEP 6.4 — 通知先 LINE userId を 取得
予約 が 入った 時 通知 を 受けたい LINEアカウント の userId
取得 方法:
① 作った 公式アカウント を スマホ の LINE で 友だち追加 (LINE Official Account Manager で QRコード が 出る)
② LINE Developers Console → Messaging API チャネル → 上タブ「Messaging API」 → 一番下「あなたの User ID」 (Uxxxx...) を コピー
※ 「Your user ID」 と 英語表示の場合あり
※ Jobs に 「userId 取って」 と LINE で 連絡 → 1分以内 で 代理 取得 可能

SUB STEP 6.6 — LIFF ID (任意・後回しでもOK)
LINEから 予約 する時 名前 自動入力 する場合 のみ
① LINE Developers Console → Messaging API チャネル → 上タブ 「LIFF」
② 緑「追加」 ボタン
③ 設定:
   ・ LIFFアプリ名: 自由 (例: 予約フォーム)
   ・ サイズ: Full
   ・ エンドポイントURL: SaaS の 予約フォームURL (STEP 9 で 取得する もの)
   ・ Scope: ☑ profile, ☑ openid
④ 「追加」 → LIFF ID (2010xxxxxx-xxxxxx 形式) が 発行 される → SaaSに 貼り付け
LIFF ID を 入れなくても 予約フォーム は 動く (Webブラウザ で 開けば OK)。 「LINE内 で 開いたとき 名前 自動入力 したい」 場合 のみ 必要。 後で 追加 で OK。

「📋 コピー」 ボタン を 押す → トースト 「✅ 予約フォームURLをコピーしました」
URL の 意味 (覚える 必要 なし)
https://skeleton-femoon-saas.web.app/book/t3-5ty6-84n9q1
✦ 黄色 の 部分 = あなたの サロン 固有の ID (テナントID)
✦ 別 の サロン が 登録 すると 違う ID が 自動 で 振られる
✦ お客様 は この URL 丸ごと を 開く → あなたの サロン の 予約画面 が 開く
✦ 「コピー」 ボタン で 取れる URL を そのまま 使う → ID 部分 は 覚える 必要 なし
サロン毎 に URL は 違う — 隣 の サロン と URL は 共有 されない。 自分 の 設定タブ で 「📋 コピー」 した URL が 自分専用。
クリップボード に お客様用 予約URL が 入る。 隣 の 「👁 確認」 ボタン で 別タブ プレビュー (お客様 が 見る 画面) も できる
