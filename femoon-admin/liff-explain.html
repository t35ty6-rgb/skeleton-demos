📲 LIFF直送の仕組み

「LINE直送可」緑バッジが何で付くか、なぜ1クリックで送信できるかを図解で説明。

🔄 LIFF経由で予約してくれた人 = 自動送信できる流れ

📱
① お客様がフェムーン公式LINE開く
▼
🎀
② リッチメニュー「ご予約はこちら」タップ
▼
📝
③ LINE内ブラウザで予約フォームが開く
↑ ここで LINEが自動的に「お客様の userId」を予約フォームに渡す
▼
📊
④ 予約成立 → スプレッドシートに userId付きで記録される
▼
✅
⑤ 管理画面 → 顧客カードに 📲LINE直送可 緑バッジが付く
▼
📤
⑥ オーナーが「即連絡」ボタン → 確認OK → LINE APIで自動送信 → お客様のLINEに即届く 🎉

🔍 緑バッジが付く場所はどこ？

場所: 顧客管理モーダル内の各顧客カード
位置: お客様のお名前の右隣り

例: 山田 花子 📲LINE直送可 ▸ 詳細

バッジが付いてる人 = LINE userIdが保存済 = ワンクリックで直接送信できる
バッジが無い人 = userId無 = LINE管理画面でコピペ送信が必要

🔀 LIFF経由 vs 通常Web の比較

LIFF経由
LINEの「ご予約」ボタンから来た
通常Web
URLを直接開いた / 過去予約者
userId あり
userId なし
📲 直送可バッジ 付く
バッジ 付かない
即連絡 = API自動送信
即連絡 = コピペ手動
🚀 LIFF経由予約を増やすには？
① 全てのお客様にLINE友だち追加してもらう
② リッチメニューの「ご予約」を一番目立つように設置 (✅ 実装済)
③ ホームページ等の予約リンクは、LIFFのURL (line.me/...) を使う

これだけで自動的に 📲LINE直送可 が付くお客様が増えていく。
過去予約者には次回時にLINE誘導すればOK。
