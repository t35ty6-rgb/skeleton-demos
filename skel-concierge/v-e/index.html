三ヶ月後、 週三時間 の 「考える 余白」 を 取り戻す。
田中 太郎さま の 初回 ヒアリング。

吉 担当 吉田 · 45 分 · Zoom · 2026-07-04 15:00 – 15:45 · 読了 5 分

初回 の 面談 は、「困りごとの 輪郭」 を 御一緒に 描く 時間 だった。 田中さま の 御相談 は 一言 で 云えば、 「日々の 仕事 に 呑まれ、 自分で 判断 する 時間 が 消えた」 こと。 御本人 の 言葉 で 云えば、 「頭 が 借りられて いる」 状態。 三ヶ月後 の 姿 は、 週 三時間、 誰にも 邪魔されない 「考える 余白」 の 復活 を 御定義 された。

01 · 現状「頭 が 借りられて いる」 と いう 表現

田中さま は、 御自身 の 状態 を 「頭 が 借りられて いる」 と 云われた。 具体 は、 一日 の 中 で 能動 の 意思決定 が 三十分 以下。 残り は 顧客・部下・家庭 の 求め に 応じ た 受動 の 反応。 五年前 と 比較 し、 「決めた 記憶」 が 週 二回 以下 まで 減少。 これ を 「危機」 と 御認識 されて いる。

「決めた という 手触り が 無い 一週間 が 続くと、 何 の ため に 働いて いる の か 分からなく なる。」— 田中 太郎さま、 15:12

02 · 三ヶ月後「週 三時間 の 余白」 を 御定義

三ヶ月後 (10月 上旬) の 御姿 は、 「週 三時間、 誰にも 邪魔されない 静かな 時間 を 御確保 出来て いる」。 内訳 は 火・木 の 早朝 各 一時間 半 を 予定 として 死守。 その 時間 で 中期 (半年〜一年) の 判断 材料 を 御整理 され、 週次 の 御自身 会議 として 御活用。

この 御姿 が 実現 出来 た か どうか は、 「決めた 事」 が 週 三件 以上 記録 に 残って いる か で 御判定 する と 御合意 頂いた。 数 は 少なく 見え る が、 田中さま の 御現状 (週 一件 以下) から 見る と 三倍 の 差 で あり、 意味 の 大きい 目標。

Action Items · 御手当 (期限 順)
  • 01火・木 早朝 6:30–8:00 を 御自身 御予定 として 御登録。 家族 御周知 と 携帯 の 通知 静音 化 を セット で。田中さま · 7/7 まで
  • 02週次 御振返 テンプレ の 御共有。 「今週 決めた 事 三件」 「来週 決める 事 三件」 の 二欄。当方 · 7/8 まで
  • 03二回目 面談 御予約 (7月 18日 頃)。 二週間 の 御手応え を 御確認。当方 · LINE 御案内

03 · 論点「決める 訓練」 は 出来る か

田中さま の 御懸念 は、 「時間 を 御確保 して も、 決められ ない ので は」。 これ に 対 し、 「決める」 の 定義 を 「今週 の 自分 の 一票 を 一件、 A4 一枚 に 御記述 する」 に 御限定 する と 御提案。 田中さま は 「それ なら 出来 そう」 と 御同意。 但し、 記述 の 質 は 問わず、 「三件 書 いた 事実」 のみ を 御計測 する。 質 を 求める と 一件目 で 止まる 御懸念 が あるため。

次回 面談 (7/18 予定) で は、 二週間 の 御記述 の 実物 を 御持参 頂き、 「決めた 事」 の 傾向 を 御一緒 に 拝見する。 御続き の 議論 は 「捨てる 事 の 御選定」 に 進む 見込み。
