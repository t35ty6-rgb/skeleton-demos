STEP 09 / 12
Scopes を 追加 → App を Activate
2分
DO
「Scopes」 タブ で 「+ Add Scopes」 → 下 の scope を 全 て 追加 → 最後 に 「Activate your app」
必要 な Scopes (必ず 全部 チェック):
・meeting:write:admin (会議 作成)
・meeting:read:admin (会議 情報 取得)
・recording:read:admin (Cloud 録画 取得)
・user:read:admin (host user 情報)
Activate を 押さ ない と token 発行 出来 ません 罠。 忘れず 押す。
