# 宝喜園 CRM セットアップ手順

予約フォーム と 通販注文 の 両方 を 1 つの Google Sheet に集約して、顧客ごとに「何を注文したか」「いつ予約したか」を横串で見えるようにする 設定 手順。

## 完成後にできること

- **顧客DB シート** : email を主キーに、name / tel / 初回来店 / 直近来店 / 総購入額 / 予約回数 / 注文回数 が 自動で 溜まる
- **予約履歴 シート** : 予約 1 件 = 1 行 (日時 / 客名 / 店 / 用途 / 希望日 / 人数)
- **注文履歴 シート** : 通販注文 1 件 = 1 行 (注文番号 / 客名 / 合計 / 支払 / 商品リスト / 配送先)

深尾さんが Sheet を開くだけで、「田中様、 5 月に らんたんで食事、 7 月にチーズケーキ通販」 のような 履歴が 1 画面で把握できます。

## デプロイ手順 (深尾さん・所要 5 分)

### 1. Google Sheet を作成

- Chrome で https://sheets.new を開く
- ファイル名を **「宝喜園 CRM」** に変更

### 2. Apps Script を開く

- Sheet の 上部メニュー **「拡張機能」** → **「Apps Script」**
- 新規タブで Apps Script エディタが開く

### 3. コードを貼り付け

- 左側の **Code.gs** をクリック
- エディタ内の コード を すべて 削除 (Ctrl+A → Delete)
- Jobs から渡された **`gas-crm.gs`** の中身を全部コピーして貼り付け
- **Ctrl+S** (Mac: Cmd+S) で保存
- プロジェクト名を聞かれたら 「宝喜園CRM」 で保存

### 4. Web App としてデプロイ

- 右上の **「デプロイ」** ボタン → **「新しいデプロイ」**
- **「種類を選択」** の 歯車アイコン → **「ウェブアプリ」** を選択
- 設定:
  - **説明** : 宝喜園 CRM v1
  - **実行するユーザー** : 自分
  - **アクセスできるユーザー** : **全員** ← ここ重要
- **「デプロイ」** をクリック
- 「アクセスを承認」 が出たら 承認 → Google アカウント選択 → 「詳細」 → 「宝喜園CRM (安全ではないページ) に移動」 → 許可
- 表示された **「ウェブアプリ URL」** をコピー
  - 形式: `https://script.google.com/macros/s/xxxxxxxxx/exec`

### 5. Jobs に URL を伝える

- LINE or メールで Jobs に URL を送る
- Jobs が HTML 側 に URL を組み込んで再デプロイ → CRM 連携完成

## 動作確認 (完成後)

1. https://t35ty6-rgb.github.io/skeleton-demos/rantan-hp/reserve.html を開く
2. テスト予約 (自分のメアドで)
3. Sheet の **「予約履歴」** に 1 行増える ✓
4. **「顧客DB」** に 自分のメアド の行が追加される ✓
5. もう 1 度 別の店で予約 → 予約回数 が 2 になる ✓
6. 通販でチーズケーキ購入 → **「注文履歴」** に追加、 顧客DB の 注文回数 と 総購入額 が更新される ✓

## トラブルシューティング

- **Sheet に何も入らない** → デプロイ時の「アクセスできるユーザー」が「全員」になっているか確認
- **エラーが出る** → Sheet の一番左のシート名が「シート1」のままで OK。 コード側が自動で 3 シート作成します
- **URL が変わった** → Apps Script で「デプロイを管理」 → 既存デプロイ を編集 → 新しい URL が発行される。 Jobs に伝えて再組み込み

## 将来の拡張

- 顧客の 誕生月 or 前回来店から 半年 で 自動リマインダー メール (GAS の トリガー機能)
- LINE 公式アカウント と 連携 (LINE Messaging API)
- 在庫管理 (通販 SKU 別 の 残数管理)
- Stripe 決済 直結 (現状は 銀行振込 / 代引き / カードは別途 リンク)

これらは 実装 半日〜1 日 で 追加可能。 まずは 現状 の CRM で運用開始 → 客数増えたら 拡張、が現実的です。
