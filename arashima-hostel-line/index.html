HOW IT WORKS

リッチメニュー 6マスの役割

お客様の用件をすべて1画面で。タップごとに何が起きるかを、設計しています。

A

予約する

LIFF mini-app を起動。建屋 → 客室 → 日付 → 確認 → 完了 の4ステップ。所要 30 秒。完了時に LINE トークへ確認メッセージを push。

→ LIFF
B

客室・プラン

Flex Message のカルーセルで全室を表示。気に入った部屋から直接予約 LIFF へ遷移可能。

→ Flex Carousel
C

アクセス

テキスト + 位置情報 + 道順写真 (3 ステップ) を一気に返信。地図アプリへもワンタップ。

→ Text + Location
D

予約変更・キャンセル

userId から予約履歴を呼び出し、変更可能な予約を Flex で表示。タップで日付変更フォームへ。

→ LIFF (履歴連動)
E

館内案内

共用キッチン・ラウンジ・自転車・洗濯・Wi-Fi の使い方を Flex Bubble で 5 通連続返信。

→ Flex Bubbles
F

お問い合わせ

担当者にエスカレーション。営業時間内なら 1 時間以内、時間外は翌朝に有人返信。

→ Human Reply
FOR OPERATORS

宿の側から見える画面

予約が入ると、オーナーの LINE にも通知が届きます。専用の管理画面で、その日の予約とゲストの履歴を確認できます。

① 新規予約の即時通知

お客様が予約 LIFF で確定した瞬間、オーナーの LINE に予約サマリーが届きます。電話やメールチェックの手間ゼロ。

② 当日のチェックイン状況

朝9時にその日のチェックイン予定を一覧で通知。客室番号・到着予定時刻・備考まで一画面で把握。

③ ゲスト履歴とリピーター判定

同じ userId で2回目以降の予約は「リピーター」バッジ付き。前回の備考や好みも紐づけて表示。

④ 自動リマインダー

前日18時に道順・チェックイン時刻、当日朝に鍵の場所を、Bot がお客様に自動 push。
