📚 用語集 (困った時 用)

予約フォームURL
お客様 が 予約 を 入れる ページ の URL。 SaaS設定 を 完了 すると 自動 発行 される。 末尾 の 番号 が お店専用 で 全店 違う
LIFF (LINE Front-end Framework)
LINEの 中 で 開ける Webページ。 普通 と 違って LINE が ユーザー情報 (名前/userId) を 教えて くれる ので 「誰宛て に 通知」 を 送れる ように なる
LIFF ID
2010xxxxxx-xxxxxxxx 形式 の 番号。 LIFFアプリ を 作ると 自動 発行 される
LIFF URL
https://liff.line.me/{LIFF ID} の 形 の URL。 リッチメニュー に 貼ると LINE内 で 予約フォーム が 開く
エンドポイントURL
LIFF が 開いた時 に 実際 表示される Webページ の URL。 ここ に 予約フォームURL (PHASE 1 で コピー した やつ) を 貼る
Messaging API チャネル
LINEから メッセージ を 送る 用 の チャネル。 LIFF は ここ に 作れない。 別物
LINEログイン チャネル
LIFF を 入れる 用 の チャネル。 PHASE 2 で 新規 作成 する のは これ
Scope (profile / openid)
LIFF が お客様 から 取れる 情報 の 範囲。 profile = お名前 と プロフィール画像、 openid = userId (誰宛て に 通知 する か の 鍵)。 両方 ON 必須
サイズ (Full / Tall / Compact)
LIFF が 開いた時 の 画面 の 大きさ。 Full = 全画面 (今回 これ)
ボットリンク機能 (Bot link)
LIFF で ログイン した お客様 を 公式アカウント の 友達 に 自動 追加 する 機能。 On (Aggressive) で 友達追加 → 通知 が 届く ように なる
プロバイダー
会社・お店 単位 の 一番上 の 箱。 同じ プロバイダー の 中 に Messaging API と LINEログイン 両方 入れて こそ 連動 する
