01 はじめまして の、ごあいさつ

産後、15キロ 増えました。
そこから、私も、始めました。 — それが、B'up の 出発点です。

出産の後、自分の体が、自分の 体じゃないような 感覚が ありました。 鏡を見るのが 少し 億劫で、写真に 写るのも 避けていた 時期が、確かに あります。

特別な マシンも、厳しい 食事制限も、私には 続きませんでした。 代わりに 選んだのは、自分の 体だけ を 使う 静かな トレーニングと、 毎日 の 食事 を 少しだけ 整える こと。 それだけです。

三年 かけて、体は 少しずつ 戻り、
気がつけば、大会にも 出るようになりました。

2022–2025  富山グランプリ 複数優勝
BBJ 日本大会 4年連続 出場

派手な 経歴 のように 見えるかもしれません。 でも、私が 一番 大切に していることは、 「無理を しないで、続けられる 体づくり」を、目の前の あなたに 伝える ことだけです。

02 あなたに、当てはまる こと が あれば

鏡だらけの ジムが、少し 苦手。
そんな あなたのための 場所です。

もし、次の どれか に 「うんうん」と 頷いてしまったら、 B'up は きっと、あなたに 合う 場所 だと 思います。

当てはまる もの に ✓
  • ✓産後、体型 が 戻らない。 抱っこ で 肩や 腰が 常に つらい。
  • ✓40代 に なって、これまで の やり方 では 落ちなく なった。
  • ✓ジム に 通おうとしたが、大きな 施設 の 空気 が どうも 苦手。
  • ✓糖質制限 や 過激な 運動 は、生活 が 回らなくなる。
  • ✓誰か に 見られながら 汗を かく のが、正直、恥ずかしい。

B'up は、マシンも、他の 会員も、大きな 鏡も、ありません。 あるのは、私と、あなたと、静かな 時間だけです。

03 60分の 一日 を、追いかけて

話す。 見る。 動く。 整える。
60分の 中に、四つの 時間が あります。

10 min  ·  consultation

まずは、話を 聞くこと から。

今日 の 体調、ここまでの 生活、睡眠、食事。 産後 の 方 は、抱っこ による 猫背 も 確認します。 「早く 始める」よりも、「正しい 場所から 始める」こと を、大切に しています。

10 min  ·  posture check

骨盤・肩・脚 の バランス を、丁寧 に。

「痩せない」「疲れやすい」 の 原因 は、姿勢 の 崩れ に あることが 多いです。 鏡 の 前で 立ち姿、座り姿、歩き方 を 見ながら、優先順位 を 一緒に 決めます。

30 min  ·  training

自分の 体だけ で、静かに 動く。

呼吸・体幹・お尻・脚 の 順で、自分の 体重 を 使った トレーニング を 組み立てます。 「翌日 に 響かない ギリギリ」 の 強度、会話 しながら 進められる ペース が 基本です。

10 min  ·  cool down & advice

ストレッチ と、次回 までの 過ごし方。

ここが 雑だと、続かない 原因 に なります。 最後 に、次回 まで の 「今日から 一つ だけ 意識する こと」 を、無理 の ない 範囲で お伝えします。

04 正しく 食べて、壊さず 整える

食事 は、我慢 じゃない。
選び方 の、ちょっとした 話 です。 — 美肌食マイスター / アンチエイジングアドバイザーの視点から。

B'up では、糖質制限 や カロリー計算 を 強要 することは しません。 その 代わりに、今日 の 食事 に、あと 一つ 加える と 良い もの、 あるいは 減らしても 良い もの を、 その日 の 話 の 中で お伝え しています。

「守れなかった 罪悪感」 を 持ち帰らせない こと、 それが、続く 食事アドバイス の 唯一 の 条件 だと 思っています。
