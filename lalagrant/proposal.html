いろはグループ の 会員 サイト を、
こんな 形 で 作って みました。

補整下着 の 正しい 選び方 · 着用 · 手入れ を 教育 コンテンツ で 会員 に 届け、 セミナー は Zoom から 自動 で 蓄積、 顧客 カルテ に before / after 写真 と 施術 履歴 を サロン と 共有。 まずは 骨組み デモ で 触って いただければ。
デモ を 開く 機能 を 見る
骨組み デモ (動画 未収録) · PC · スマホ 両対応 · クリック で 全 機能 触れます
4 つ の 画面

会員 が 触る、 4 つ の タブ。

下部 タブ ひとつ で 「学ぶ」 → 「マイカルテ」 → 「セミナー予定」 → 「サロン予約」 の 4画面 が 完結。 それぞれ が いろはグループ の 会員体験 の ひとつ の 面 を 担当。
01 · 学ぶ

教育 コンテンツ 100+ 本

7 大カテゴリ × 小 カテゴリ × 個別 動画 の 3階層。 選び方 · 着用 · 体形補整 · 手入れ · 美容連携 · セミナー · 販売員 限定 まで。
02 · マイカルテ

採寸 · Before / After · スタッフ メモ

サロン と 会員 の 2人 で 育てる カルテ。 採寸 差分 pill (前回 比 -2.4cm 等)、 写真 4枠、 来店 履歴 timeline、 スタッフ メモ、 購入 履歴 を 一望。
03 · セミナー予定

Zoom 録画 の 自動 蓄積

稲井田社長 の 月次 講演、 ゲスト講師、 会員限定 Q&A、 商品発表会。 Zoom で 撮影 した セミナー が 自動 で セミナー タブ に 追加、 アーカイブ 視聴 も 可能。
04 · サロン予約

全国 いろは サロン の 予約

直近予約 の 変更 · キャンセル + 全国 サロン の 一覧 と 予約 導線。 会員 は 優先 予約枠 あり、 地図 表示 · 電話 直結 も 統合。
主な 機能

会員 100人 から 始まる、 拡張 可能 な 基盤。

既存 の スケルトン SaaS 資産 (femoon SaaS + Skel·CRM) を 統合 して 構築。 LINE Messaging API の 従量 は 会員 100人 なら 無料 枠 で 収まる 想定。

7 カテゴリ × 100+ コンテンツ

選び方 / 着用 / 体形補整 / 手入れ / 美容連携 / セミナー / 販売員限定。 進捗 badge · 難易度 · 所要時間 を 全 項目 に。

LINE で 会員 通知

会員 認証 は LIFF、 セミナー 開催 と 新 コンテンツ は LINE で push。 独自 会員 ID 発行 不要、 友だち登録 だけ で 完結。

Zoom → 自動 蓄積

Zoom cloud recording が 保存 された 瞬間、 Webhook で セミナー カテゴリ に 自動 追加。 タイトル は 会議 名 から 引き継ぎ + 手動 上書き 可能。

顧客 カルテ + Before / After

採寸 差分 · 施術 履歴 · 写真 · スタッフ メモ を 一元管理。 サロン スタッフ と 会員 が 共同 で 育てる 記録、 fem­oon SaaS カルテ 実装 を 移植。

販売員 限定 tab

会員 tag で 認証 分離。 商品知識 · 接客 スクリプト · クロージング · 新商品 研修 は 販売員 のみ 閲覧。 一般 会員 は 鍵 表示。

全国 サロン 予約 統合

全国 いろは サロン の 予約 · 変更 · キャンセル を 会員 サイト 内 で 完結。 会員 優先 枠 の 提供、 地図 · 電話 直結、 スタッフ 指名 も 検討 可能。
Roadmap · これから の 進め方

骨組み から 実装 へ、 3 ステップ。

本 デモ は 骨組み (動画 未収録)。 承認後 に 実 実装 へ、 既存 SaaS 資産 を 統合 する 形 で 立ち上げ ます。
1

骨組み デモ 承認

画面 構成 · カテゴリ 粒度 · カルテ 項目 の 過不足 を 稲井田社長 に 確認 いただき、 v0.6 で 修正 反映。
今 · 触って いただく フェーズ
2

実 実装 (Phase 1)

femoon SaaS (予約 + カルテ + LINE 配信) に いろはグループ tenant 追加。 Skel·CRM の 動画ホスティング + 会員 tag 認証 を merge、 Zoom Webhook 連携。
承認 後 · 2 週間 目安
3

会員 100人 で 運用 開始

初期 会員 に LINE 招待 → LIFF 登録 → 教育 コンテンツ 配信 開始。 セミナー は Zoom で 撮影 → 自動 蓄積、 サロン と カルテ 共有 開始。
Phase 1 完了 後
