===プロンプトここから===

【依頼内容】
産直EC「Mio (Made in Ono)」 の **決済の仕組み** を、商工会議所スタッフ・出品事業者の双方が読んで理解できる説明スライドにしてください。専門用語ゼロ、図解多め、A4横スライド10枚前後でお願いします。

【サービスの前提】
- サービス名：Mio (Made in Ono)
- 主催：越前大野商工会議所
- 形態：地元事業者の商品をオンラインで直販する産直EC
- 制作：スケルトン株式会社
- 公開URL：https://t35ty6-rgb.github.io/skeleton-demos/mio-ec/

【決済方式（事実）】
- 決済システム：**Stripe（ストライプ）** ― 世界190カ国で導入の業界標準
- 決済方法：**クレジットカードのみ** （Visa / Mastercard / American Express / Diners Club / JCB）
- 決済タイミング：注文確定時に即時決済
- カード番号は Stripe が直接処理。Mio EC のサーバーには一切保存されない
- セキュリティ規格：**PCI DSS Level 1**（クレジットカード業界の最高レベル）
- 決済手数料：カード 3.6%（出品事業者ではなく Mio 運営側で吸収）
- 銀行振込・代引・コンビニ後払い等は非対応（運営工数とトラブルを削減するため）

【出品事業者にとってのメリット】
- 入金管理・督促・コンビニ番号発行などの事務作業ゼロ
- 売上は Stripe ダッシュボードでリアルタイム確認、口座への自動入金
- カード番号を扱わないので個人情報リスクなし

【商品登録〜販売開始までの流れ（出品事業者目線）】
1. Stripe ダッシュボードで商品を登録（商品名・価格・写真）
2. 「決済リンクを作成」 を1クリック → 専用URL（payment_link）が発行される
3. Mio EC 側がそのリンクを商品ページに貼る（GitHub Actions で自動同期）
4. お客様が「注文する」ボタンを押すと Stripe のチェックアウト画面へ遷移
5. 決済完了 → 出品事業者・お客様双方に自動でメール通知

【注文〜入金までのフロー（お金の流れ）】
お客様カード決済 → Stripe が一旦預かる → 手数料3.6%差引 → 出品事業者の銀行口座へ自動入金（標準4営業日サイクル）

【強調してほしいポイント】
- 「カード番号を扱わない＝事業者側の責任ゼロ」

- 「銀行振込/代引なし＝ノークレーム運用」
