Windows セットアップ手順

PREP

準備するもの

項目入手先
Windows PC 1 台セットアップ対象
インターネット接続必須（Node 等を DL する）
メルカリの メアドとパスワード司の手元
SMS が届く電話2 段階認証用
セットアップ用 zipDrive から DL（下に手順）
SA 鍵ファイル
(google-credentials.json)		Jobs から LINE で個別送信
STEP 1

zip と SA 鍵を Windows に置く

① zip ファイル を Drive から DL

1
Google Drive を開く → 「マイドライブ」 → 「Skeleton配布物」 → 「メルカリ自動化Windowsインストーラ」 フォルダ
2
「メルカリ自動発送通知_とく.zip」 をクリックして DL（50KB と軽い）

② SA 鍵ファイル を 受け取り

1
Jobs（AI CEO）に LINE で「とくPC用意した、SA鍵送って」と送る
2
JSON テキストが返ってくるので、メモ帳を開いてペースト
3
名前を付けて保存：ファイル名 google-credentials.json （拡張子 .txt にならないよう注意）
⚠ 重要： SA 鍵は 絶対に他人に渡さない、ネットに上げない。これがあるとうちの会社のスプシ全部にアクセスできてしまう。
STEP 2

zip を解凍する

1
DL した 「メルカリ自動発送通知_とく.zip」 を 右クリック
2
「すべて展開...」 を選ぶ
3
展開先はそのままで OK。 展開 ボタンを押す
4
展開された 「メルカリ自動発送通知_とく」 フォルダが自動で開く

中身はこんな感じ：

  • セットアップ.bat ← これを後でダブルクリック
  • setup-core.ps1
  • はじめにお読みください.txt
  • google-credentials.json.PLACE_HERE ← 目印
  • tool フォルダ
STEP 3

SA 鍵ファイルを フォルダに入れる

Step 1 で保存した google-credentials.json を 開いたフォルダの中に ドラッグ＆ドロップ。

💡 確認ポイント： 入れた後、フォルダ内に google-credentials.json （拡張子 .json）があれば OK。 google-credentials.json.txt や google-credentials.json.json になってないかチェック。

もう要らないので google-credentials.json.PLACE_HERE は削除して OK。

STEP 4

「セットアップ.bat」 をダブルクリック

フォルダの中の 「セットアップ.bat」 を ダブルクリック。

⚠ 「ユーザーアカウント制御」 が出たら： 「はい」 を押す（管理者権限で動かす必要がある）。

真っ黒なウィンドウが開いて、青いタイトルが表示される：

╔══════════════════════════════════════════════════════════════╗ ║ メルカリ 自動発送通知ツール ─ Windows セットアップ ║ ╚══════════════════════════════════════════════════════════════╝
STEP 5

3 項目入力する

画面の指示通りに 1 行ずつ入力：

アカウント名 : とく （Enter）

メアド : メルカリに登録してるメールアドレス（Enter）

パスワード : メルカリのパスワード（Enter。入力中の文字は画面に表示されない＝普通）

💡 ペーストするには： マウスの 右クリック でペーストできる（Ctrl+V は効かない）。

入力が終わると、自動で以下が走る：

  • Node.js / Git / Google Drive の導入（5〜10 分・winget で自動）
  • ツール本体の配置
  • npm install + Playwright Chromium の DL（500MB ぐらい）

進捗が画面に流れる。エラー表示がなければ OK。

STEP 6

メルカリにログイン（SMS だけ手入力）

「Enter キーを押すと開きます...」 と表示されたら Enter。

Chrome のウィンドウが開いてメルカリのログイン画面になる：

1
メアドとパスワードは自動で入力される（Step 5 で入れたやつ）
2
スマホに SMS で 6 桁の認証コードが届く
3
それを Chrome の画面に入力
4
ログイン完了 → Chrome は自動で閉じる

そのあと自動で：

  • Windows Task Scheduler に 自動実行タスクが 2 本登録される
  • 動作確認のスクレーピングが 1 回走る（副作用ゼロ）
  • 緑色で 「✅ セットアップ完了」 が出る
STEP 7

PC のスリープを無効にする

セットアップは終わったが、 スリープしてしまうと自動実行が走らない。 設定を変更：

1
Windows + I で 設定を開く
2
「システム」 → 「電源」
3
「画面とスリープ」 を開く
4
「電源接続時、次の時間経過後にデバイスをスリープ状態にする」 を 「なし」 に設定
💡 さらに念のため： 設定 → アカウント → サインインオプション → 「PC をスリープから復帰させたとき、サインインを求める」 をオフ にしておくと安心。

🎉 これで終わり

今夜 23 時から、自動で売却商品がスプシに記録されます。

発送通知の自動運転は最初 OFF にしてあるので、1 件試して問題なければ Jobs に LINE で 「発送通知の自動運転、有効化して」 とお願いしてください。

AFTER

セットアップ後にやること

① 動いてるか確認

  • 今夜 23 時すぎに スプシ「メルスト日報」 を開く → 新しい行が追加されてれば成功
  • 翌朝 Jobs に 「動いてた？」 と聞けば確認結果を LINE で返す

② 1 件だけ発送通知を手動テスト

発送依頼が来てる取引があれば、 PowerShell で以下を実行：

cd $HOME\.skeleton-mercari npm run confirm

1 件目で y を押すと実発送通知が飛ぶ。 問題なければ Jobs に LINE で 「発送通知の自動運転、ON にして」。

③ 他アカも導入したい場合

みゆ／ひかる／かつまアカも同じ手順。 Jobs に LINE で 「みゆPC 用の zip作って」 とお願いすれば、Drive に新しい zip が上がる。

TROUBLE

困ったとき

動かない・エラーが出る

  • セットアップ.bat の画面に出てる赤い文字をスマホで撮って LINE で送る
  • ログ場所： C:\Users\(あなた)\.skeleton-mercari\logs\run.log

SMS が来ない

  • 30 秒以内に来ないときはメルカリアプリで再送リクエスト
  • それでも来ないときは 楽天モバイル / 機内モード解除 など電波チェック

セットアップ.bat が動かない

  • ファイルを右クリック → 「管理者として実行」 を試す
  • SmartScreen で警告が出たら 「詳細情報」 → 「実行」

winget が無いと言われた

  • Windows 11 なら標準搭載。 Windows 10 の場合は Microsoft Store で 「アプリ インストーラー」 を入れる

どうにも分からないときは Jobs に 「メルカリツールで詰まった」 と LINE してください。リモートで一緒に直します。
