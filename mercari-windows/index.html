ご利用方法

SETUP STEPS
01STEP

EXE をダブルクリック

所要 30 秒

ダウンロードした下記ファイルを そのままダブルクリック。 解凍などの操作は不要です。

メルカリ自動発送通知_とく.exe

SmartScreen 等の警告が出たら：

  1. 「詳細情報」 をクリック
  2. 「実行」 をクリック

続いて Windows の UAC ダイアログ：

  1. 「はい」 をクリック

自動で内部ファイルが展開され、青いセットアップウィンドウが開きます。

補足 Node.js / Git / Google Drive が既にインストール済みの場合、それらの工程は自動でスキップされます。
02STEP

情報を入力 ( 4 項目 )

所要 2 分

青いウィンドウの指示通り、 1 行ずつ入力してください:

  1. アカウント名 ( 例：とく )
  2. メルカリのメールアドレス
  3. メルカリのパスワード ( 入力中の文字は画面に表示されません )
  4. SA 鍵ファイル ( google-credentials.json ) — エクスプローラーから青いウィンドウへ ドラッグ＆ドロップすると自動でパスが入ります
事前準備 SA 鍵ファイル ( google-credentials.json ) は別途 LINE にてお送りします。
パソコンのデスクトップに保存してから、セットアップを開始してください。
続いて自動進行 Node.js / Git / Google Drive の導入、ツール本体の配置、 npm install、 Playwright Chromium のダウンロード ( 約 500MB ) が自動で進みます。
03STEP

メルカリログイン & 完了画面待ち

所要 5 分前後

途中で Chrome が自動的に開き、メルカリのログイン画面が表示されます。

  1. メールアドレスとパスワードは 自動入力されます
  2. 「ログイン」 をクリック
  3. スマートフォンに届く SMS の認証コード を入力
  4. マイページが表示されたら、 青いウィンドウに戻って Enter

ログイン後、 Task Scheduler への登録と動作確認テストが自動で走り、 完了画面が表示されます。

SETUP COMPLETE

ご利用準備完了

今夜 23 時、自動でメルカリの売却商品がスプシに記録されます。

PC のスリープを無効化

POWER SETTINGS

PC がスリープすると 23 時の自動実行が走りません。
設定 → システム → 電源 → 「画面とスリープ」 を 「なし」 に設定してください。

推奨設定

設定 → アカウント → サインインオプション → 「PC をスリープから復帰させたとき、サインインを求める」 を オフ にしておくと、より安定して動作します。

翌朝の動作確認 ( 任意 )

VERIFICATION

翌朝、自動実行が成功したかをご確認になりたい場合は、 スプシ 「メルスト日報」 に新しい行が追加されているかご確認ください。

あるいは、 PowerShell で下記を実行:

cd $HOME\.skeleton-mercari
npm run scrape:sold

下記のような実行結果が表示されれば成功です:

[scrape] todos「発送をお願いします」: 3 件
[append] append 完了: 3 行
=== 完了 ===
