USER GUIDE · FP COMPASS v1.0 · 2026-06

FP さんが 登録 から 運用開始 までの全手順

商談相手の FP さんが「ここをクリックして、 次にここ入れて」 を写真付きで追える 7 ステップ。

⚡ START — まずここから

下の URL をクリックしてサービスを開く

https://app.skeleton-inc.jp/
いますぐ開く
代理店紹介の場合: 代理店から共有された https://app.skeleton-inc.jp/?agent=XXX のような URL を使用すると、 紹介履歴が記録され代理店側に成果が反映されます。
FP紹介の場合: 紹介者の URL https://app.skeleton-inc.jp/?ref=XXX から入ると、 紹介してくれた FP の月額が下がります。
FOR — 想定読者

代理店経由 で FP Compass を紹介された FP さん

「初めて触る、 何を入れて何が起きるかわからない」 という人向け。

GOAL — 完了基準

14 日間の無料トライアルを開始 → 顧客管理画面で運用開始

所要時間: 5 分前後。 クレジットカード必要。

1

https://app.skeleton-inc.jp/ にアクセス

~30 秒

ブラウザ (Chrome / Safari 等) のアドレスバーに https://app.skeleton-inc.jp/ と入力するか、 代理店から送られてきた URL リンクをタップ → FP Compass のページが開きます。

📱 サービス機能の説明を先に見たい場合
ログイン画面の前に、 機能・料金の詳しい説明を見たい人は https://app.skeleton-inc.jp/lp/ を直接開いてください。 こちらは未登録でも見られる紹介ページです。

🔐 パスワードのコツ
FP は顧客の機密情報を扱うので、 銀行アプリと違うパスワード を使ってください。 おすすめは パスワード管理アプリ (1Password 等) で生成。

入力完了したら 「アカウント作成」 ボタンを押します。

4

~2 分

アカウント作成と同時に、 Stripe 社の決済画面 に自動で飛びます。 ここでクレジットカード情報を入力します。

FIG 7 — Stripe 決済画面 (上部)

FIG 8 — カード情報入力フォーム
1
メールアドレス: 領収書受け取り用 (登録メアドと同じで OK)
2
カード情報: カード番号、 有効期限、 セキュリティコード

カード保有者名: ローマ字で 「TARO TANAKA」 等
4

⚠ 14日トライアル後の自動課金について
14日経過時点で自動的に ¥19,800 が引き落とされます。 トライアルだけ試して継続しない場合は、 14日以内に管理画面から解約 してください。

入力完了したら 「登録する」 または 「サブスクリプションを開始」 ボタンを押します。

6

紹介プログラムを使う (任意・料金が下がる)

いつでも

右上の 「🎁 紹介」 を押すと、 あなた専用の紹介URL が出ます。 他の FP に共有して登録してもらえば、 あなたの月額が下がります。

FIG 10 — 紹介プログラム ダッシュボード
1

2

3

4
紹介したFP一覧: 誰がトライアル中 / 有料中 / 解約済かが見える
📊 割引のしくみ
紹介 1 人で -¥3,500/月、 6 人で ¥0 (永久無料)。 紹介相手が有料利用中の間ずっと割引維持。
7

解約 / データダウンロード (必要になった時)

~3 分

アカウント設定画面 (/account) で、 解約 や 全データを JSON でダウンロード ができます。

⚠ 解約前にデータをダウンロード
解約すると当月末まで利用可能、 その後 30日でデータ完全削除 されます。 解約前に必ず JSON ダウンロードしておきましょう。
📥 データダウンロードできるもの
顧客情報、 LINE 履歴、 議事録、 提案履歴、 キャンセル履歴、 ライフイベント — すべて 1 つの JSON ファイルで取れます (個人情報保護法 第33条 開示請求権対応)。

これで 運用開始。 以降は通常使うだけ

14 日間試して気に入れば自動継続。 気に入らなければトライアル中に /account から解約。 解約してもデータは 30日間保管、 ダウンロードもいつでもできます。

  • サインアップ完了 → 即顧客管理画面 (5分)
  • 14日無料・カード登録のみで開始
  • 紹介で 6人 → 永久無料 (継続条件付き)
  • 解約はワンクリック、 データは自分でDL可
  • サポート: support@skeleton-inc.jp
