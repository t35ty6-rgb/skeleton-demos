SKEL·EC 工程表

提案から運用開始までの工程

サロン 1 件あたりの作業 を 時系列で整理。 何分後に何が起きるか / 誰が動くか が一目で分かる。

サロン オーナー Jobs (自動)
1

Day 1 — 商談・契約

1〜3日
OWNER 0:00 サロンと商談 → デモ画面提示
https://t35ty6-rgb.github.io/skeleton-demos/skel-ec/ をブラウザで見せながら、 サロンに「これがオーナー画面、 これがお客のLINE」 と説明。
SALON 30 分後 「やりたい」 と判断 → 契約締結
月額プラン or 初期費用プラン を選択。 オーナーが サロン slug を仮決め (例: hikari-salon)
OWNER 直後 セットアップガイドを LINE で送る
URL を送るだけ: https://t35ty6-rgb.github.io/skeleton-demos/skel-ec-setup/
Phase 1 終了時 オーナー累計作業 30 分
2

Day 2 — Credentials 受領

サロンの作業日
SALON サロンの空き時間 ガイドを開いて LINE Developers Console にアクセス
画面付きガイドの 1〜11 ステップに従う。 サロンの PC で 10 分の作業。 オーナーは 何もしない。
SALON +10 分 ① ② ③ をコピー → オーナーに LINE で送る
テキストで貼り付け:
① Channel ID: 1234567890
② Channel secret: abc123...
③ Access token: aBcDe...
サロン名: hikari-salon
OWNER 直後 「受け取った、 今からセットアップする」 と返信
サロンへの確認のみ。 1分。
Phase 2 終了時 オーナー累計作業 31 分
3

Day 2 — 自動セットアップ実行

同日 30 秒で完了
OWNER 0:00 admin の LINEアカウント modal を開く
画面右上 「LINEアカウント」 ボタン押す。
OWNER +30 秒 ①②③ を 「入力」 ボタン から貼り付け
3つの欄に それぞれペースト → 保存。 2分以内に終わる。
OWNER +3 分 ショップ設定で サロン slug を入力
ホーム → 設定 → ショップ基本設定 で hikari-salon を入力
OWNER +4 分 🚀 「本番モードに自動セットアップ」 ボタン押す
クリック1回。
  • LINE webhook URL を LINE API に自動登録
  • Use webhook ON を LINE API に自動設定
  • LINE 疎通テスト 自動実行
  • Stripe webhook endpoint を Stripe API に自動作成
  • Stripe webhook secret を admin に自動保存
  • Firestore tenant doc 作成 (credentials 暗号化保管)
JOBS +30 秒 🎉 「本番セットアップ完了」 モーダル表示
全 6 ステップの結果が緑のチェック ✓ で並ぶ。 完了報告。
Phase 3 終了時 オーナー累計作業 35 分
4

Day 2 — 動作確認テスト

同日 5 分
OWNER 0:00 自分の LINE で サロン公式アカウントを 友だち追加
サロンが教えてくれた LINE Basic ID (@xxxx) で追加。
JOBS 2 秒 follow イベント受信 → 顧客 doc 作成 + ウェルカム自動送信
勝手に Firestore に顧客記録 + LINE で「ご登録ありがとうございます」 メッセージ届く。
OWNER +1 分 admin の 顧客一覧で 自分が出るか確認
名前/アイコン/友だち追加日時 が表示されたら ✅ 正常動作。
OWNER +2 分 「営業時間」 と LINE に送る → 自動応答が返ってくるか確認
設定したキーワード反応が動けば ✅
OWNER +3 分 shop URL で テスト商品を購入 (Stripe テストカード)
テストカード 4242 4242 4242 4242 で決済。 admin に注文出る + LINEに通知 来たら ✅
Phase 4 終了時 オーナー累計作業 40 分
5

Day 3 — サロンに引き渡し

翌日 30 分
OWNER 0:00 サロン用 admin URL + ログイン情報 を発行 → サロンに送付
例: https://admin.skel.ec/hikari-salon + メアド + 初回パスワード。
OWNER +5 分 Zoom or 対面で 30 分レクチャ開始
画面共有で 操作デモ。 サロン側は 見るだけでOK。
OWNER +5〜25 分 主要操作を一緒にやる
• 商品登録の手順 (3〜5品 一緒に登録)
• 注文受付後の発送ステータス変更
• 配信 (キャンペーン送信)
• 顧客タグの使い方
SALON +30 分 「これで自分でできそう」 と把握 → 引き渡し完了
サロンが 自走可能 な状態に。 質問あれば LINE で随時対応の約束。
Phase 5 終了時 オーナー累計作業 70 分
6
