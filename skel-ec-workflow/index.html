本文に入る前に: この資料に出てくる用語

用語サロン slug (スラッグ)
= サロンの "名札"。 英小文字+数字+ハイフン。 例 hikari-salon。 URL や 内部の名前に使う。 サロン名「IDEAL by Hikaru」 を URL に乗せる用に短くしたもの。
用語Channel ID / Channel secret / Access token
= LINE が発行する 3点セットの鍵。 サロンが LINE Developers Console から取得して オーナーに渡す。 サロンごとに別物。
用語Webhook (ウェブフック)
= "通知 専用 URL"。 LINE で誰かが友だち追加 した瞬間、 LINE が Skel·EC に「ピンポーン」 と知らせるための インターホン。
用語Stripe webhook secret
= 決済代行 Stripe 側の 専用ハンコ。 「これは本物の Stripe からの通知」 を確認するため。 自動セットアップで Stripe API から取得して 保存。
用語Firestore (ファイヤストア)
= Google が運営する クラウドデータベース。 顧客 / 注文 / 商品 すべての保存先。 サロンごとに 物理的に別フォルダ で保存。
用語Cloud Function
= 自動処理 プログラム。 「友だち追加された」 「決済された」 等のイベントが来た時だけ 一瞬起動して処理。 普段は休んでて 月¥0〜。

Day 2 — 自動セットアップ実行

同日 30 秒で完了
OWNER 0:00 admin の LINEアカウント modal を開く
画面右上 「LINEアカウント」 ボタン押す。
OWNER +30 秒 ①②③ を 「入力」 ボタン から貼り付け
3つの欄に それぞれペースト → 保存。 2分以内に終わる。
OWNER +3 分 ショップ設定で サロン slug を入力
ホーム → 設定 → ショップ基本設定 で hikari-salon を入力
OWNER +4 分 🚀 「本番モードに自動セットアップ」 ボタン押す
クリック1回。
  • LINE webhookWebhook = LINE → Skel·EC への "通知の窓口 URL"。 友だち追加されたら ここに通知が飛んでくる。 自動セットアップは サロン用 URL を 自動で LINE に登録する。 URL を LINE API に自動登録
  • Use webhook ON を LINE API に自動設定
  • LINE 疎通テスト 自動実行
  • Stripe webhook endpoint を Stripe API に自動作成
  • Stripe webhook secret を admin に自動保存
  • Firestore tenant doc 作成 (credentials 暗号化保管)
自動の内訳この 6 ステップを クリック1回で 30秒 でやる。 手動でやると サロンごとに 1時間かかる作業。 (各 API への登録 + テスト + 保存)。 オーナーが触らないので ヒューマンエラーゼロ。
JOBS +30 秒 🎉 「本番セットアップ完了」 モーダル表示
全 6 ステップの結果が緑のチェック ✓ で並ぶ。 完了報告。
Phase 3 終了時 オーナー累計作業 35 分
