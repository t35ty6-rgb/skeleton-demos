SKEL·EC WORKFLOW

提案 → 導入 → 運用
役割分担と受け渡しフロー

サロン (お客) との商談から、 オーナーが渡すもの、 Jobs が自動でやること、 引き渡し後の継続運用まで。 各フェーズで「誰がどこまでやるか」 を明確化。

サロン (お客様)
オーナー (吉田)
Jobs (自動・Cloud Functions)
1

提案・商談 サロン発掘 → ヒアリング → デモ提示

1〜3日
SALONサロン側
  • LINE 公式アカウントは持ってる、 EC は まだ未着手
  • 「LINE で売れたら…」 の漠然とした希望
  • 知り合い経由 or 広告経由で オーナーと接点
商談
OWNERオーナー (吉田)
  • Skel·EC デモ画面 を見せる (https://t35ty6-rgb.github.io/skeleton-demos/skel-ec/)
  • 商材ヒアリング (何売るか / 客層 / 予算)
  • 料金提示・契約締結
  • サロン名 → URL slug 仮決め (例: hikari-salon)
⇣
2

Credentials 受領 LINE と Stripe の鍵を集める

10〜15分
OWNERオーナー
  • サロンに セットアップガイドURL を送る (https://t35ty6-rgb.github.io/skeleton-demos/skel-ec-setup/)
  • サロンが ①②③ をコピペして返してきたら、 一旦預かる
  • Stripe は (使うなら) Skeleton 法人 sk_live を使うか、 サロンが新規作成して取得
credentials
SALONサロン側
  • ガイドを見ながら LINE Developers Console を開く
  • ①Channel ID / ②Channel secret / ③Access token をコピー → オーナーに送る (LINEで全く問題なし)
  • 所要 約 10分。 PC が苦手な店主でも画面付きガイドで進められる
📋オーナー → Jobs に渡るもの: ① Channel ID / ② Channel secret / ③ Access token / サロン slug / (任意) Stripe sk
⇣
3

自動セットアップ 1クリックで本番モード起動

30秒
OWNERオーナー
  • admin で受け取った credentials を 各欄に貼り付け (5箇所、 2分)
  • ショップ設定で サロン slug を確定 (例: hikari-salon)
  • 「🚀 本番モードに自動セットアップ」 ボタンを押す
  • 30秒待つ → 「🎉 本番セットアップ完了」 モーダル確認
setupTenant API
JOBSJobs (Cloud Functions)
  • ① LINE webhook URL を LINE API に自動登録
  • ② LINE Use webhook を ON 化
  • ③ LINE → 自社サーバー の 疎通テスト
  • ④ Stripe webhook endpoint を 自動作成 (4イベント購読)
  • ⑤ Stripe webhook secret を admin に自動保存
  • ⑥ Firestore に tenant doc 作成 (creds 暗号化保管)
⇣
4

動作確認 友だち追加 → 通知 → 決済 までスループット

5分
OWNERオーナー
  • 自分の LINE で サロン公式アカウントを 友だち追加
  • admin 顧客一覧で 自分が出るか 確認
  • 「営業時間」 と送ってみて 自動応答が返るか確認
  • shop URL から テスト商品を カートに入れて 決済テスト (Stripe テストカード 4242 4242 4242 4242)
  • 注文が admin に出るか + LINE に通知来るか 確認
webhook受信
JOBSJobs
  • 友だち追加 follow イベント → 顧客 doc 作成 + ウェルカム送信
  • メッセージ受信 → キーワード判定 → 自動応答
  • Stripe決済完了 webhook → 注文作成 + LINE通知
  • admin リアルタイム反映
⇣
5

サロンへ引き渡し admin の操作レク + URLとパスワード送付

30分
OWNERオーナー
  • サロンに admin URL を送る (例: https://admin.skel.ec/hikari-salon)
  • サロン用 ログイン情報 を発行 (メアド + 初回パスワード)
  • 30分 オンラインレクチャ:
    • 商品登録の仕方
    • 注文受付後の発送ステータス変更
    • 配信 (キャンペーン送信)
    • 顧客タグの使い方
  • サロンの最初の商品 3〜5点 を一緒に登録
ログイン
SALONサロン側
  • admin URL にログイン
  • 商品マスタを見ながら 残りの商品を順次登録
  • 公式LINE の リッチメニュー に 「ショップ」 ボタン 追加 (admin から)
  • 友だちに 「LINEからショップ開けます」 とお知らせ配信
⇣
6

運用継続 サロンが日々使う / Jobs は裏で動き続ける

継続的
SALONサロン側 (日々)
  • admin で 注文確認 → 発送 → ステータス更新
  • 新商品追加 / 在庫管理
  • 月数回 キャンペーン配信
  • 顧客対応 (LINE で個別返信)
24/7
JOBSJobs (24/7 自動)
  • 全 LINE イベント (友だち / メッセージ / postback) を 自動処理
  • 全 Stripe決済を自動的に 注文化 + 通知
  • Firestore リアルタイム同期
  • 毎月 LINE / Stripe 残り送信通数を集計
  • 異常検知 → オーナーに LINE通知 (オーナーは 「あ、 これ調べる」 だけ)
OWNERオーナー (月1)
  • 各サロンの 運用状況確認 (admin / Firestore で多店舗一覧)
  • 請求書発行 (Skeleton 月額/従量モデル)
  • サロンからの拡張要望 → Jobs に依頼 → 反映
