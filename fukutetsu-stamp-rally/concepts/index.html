Jobs の 案内

左5 (和) と 右5 (洋) で 世界観 を できる限り 引き離した。 それぞれ 押しの ターゲット層 が違う ので:

· A · E = 現状 沿線利用者 (中高年 · 鉄道ファン) の 継続動機 に効く
· D = インバウンド · 外国人観光客 の 差別化 · 記念品層 に効く
· G · I = 若い女性 · カフェ好き · インスタ発信 の 拡散 に効く
· C · J = 子連れ ファミリー の 沿線利用 引き込み
· F = 若年男性 · ゲーマー の 新規開拓 (夜間 · 深夜 利用)
· B · H = 汎用性重視 (法人 · 自治体プレゼン) で 誰にも 響く 保守本命

どれで行く? もし迷ったら A + D + C の3本柱 を 並行運用 (時期/イベント で 表面テーマ を 切り替え) も可。 メインを 一つ選定後、 全画面 全機能 完全リメイク する。
