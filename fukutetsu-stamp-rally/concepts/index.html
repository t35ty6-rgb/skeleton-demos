🎯 Jobs の 判断案

本命: A案 (現行) を 磨き続ける — 硬券世界観 が このアプリの アイデンティティ に 一番ハマる。
次点: D案 浮世絵 — 訪日外国人 の インバウンド需要 を 狙うなら 差別化 一番強い。 全画面 縦書き で 「日本らしさ」 最大化。
市場拡張: C案 遊び心 — 若年層 ファミリー 客 の 引き込み。 Duolingo型 の 継続体験 で 沿線利用 を 促進。
回避: B案 モダン ミニマル は 汎用SaaS 感 出過ぎ 個性弱まる · E案 昭和 は ノスタルジー だが 若年層 に届かない。

どれで 行く? 選定後 は 全画面 完全リメイク して 一気に本番切替 する。
