CHAPTER 01

FEMOON SaaS って 何?

サロン (美容院・エステ・整体 など) が お客様 から LINE 経由 で 予約 を 受け、 売上 を 管理 する ため の 月額課金型 クラウドサービス。 料金 は 月額 ¥9,800 (税込)。

サロン は ふだん 「ホットペッパー」 や 「サロンボード」 で 予約 を 受けて いるけど、 LINE で 直接 予約 を 取りたい、 顧客 と LINE で やり とり したい、 という ニーズ に 応える プロダクト。

サロン に 提供 する 機能

  • 予約フォーム (LINE リッチメニュー から 開ける、 お客様 が 日時・コース を 選んで 予約)
  • 管理画面 (admin) (サロン側 で 予約状況・顧客情報 を 一覧 で 管理)
  • LINE 通知 (予約 入る たび に サロン と お客様 両方 の LINE に カード型 通知)
  • カレンダー追加 (お客様 が 通知 から ワンタップ で Google カレンダー に 登録)
  • 不定休 対応 (「第1火曜 休み」 等 の パターン を 予約カレンダー が 自動 認識)
CHAPTER 02

登場人物 3人

この サービス に 関わる 人 は 3種類。 それぞれ 役割 と やる こと が 違う。

役者 A
オーナー
Skeleton 社 代表。 サロン に 営業 して 受注 取る。 受注後 の セットアップ は あなた に 依頼 する。
役者 B
サロン
SaaS を 月額 ¥9,800 で 買う 顧客。 美容院・エステ など の 経営者。 お店 の 営業時間 や メニュー を 持って いる。
役者 C
お客様
サロン に 通う エンドユーザー。 LINE から 予約 する。 あなた が 直接 やり取り する こと は ない。

あなた は この 3人 の どこ に も 属さない、 裏方 セットアップ 担当。 LINE で オーナー から 指示 を 受けて、 サロン に 完成品 を 渡す のが 仕事。

CHAPTER 03

全体 の 流れ

時間軸 で 並べた フロー。 あなた が 動く タイミング は STEP 4 と STEP 7 の 2回 だけ。

[STEP 1] オーナー → サロン に 営業 → 契約合意 ↓ [STEP 2] オーナー が QR発行ツール で サロン専用URL 生成 → LINE で サロンに 送る ↓ [STEP 3] サロン が ウィザード (12問+決済) を 完走 → ¥9,800 課金 確定 ↓ (約60秒後 自動) [STEP 4] watcher が 自動 で セットアップ + オーナーの LINE に「開通キット」通知 ↑ ← あなたが 受け取って 内容 確認 ↓ [STEP 5] あなた が LINE 開通キット を サロン に 転送 ↓ [STEP 6] サロン が パスワード設定リンク クリック → パス決定 → admin ログイン ↓ [STEP 7] サロン から LINE OA の チャネルアクセストークン 等 を 預かる ↑ ← あなたが admin 設定タブ に 入力 + リッチメニュー アップ ↓ [STEP 8] 動作確認 (テスト予約 入れて 通知 届くか) → サロン に 「使えます」 連絡 ↓ [完了] サロン が お客様 から 予約 受け始める
watcher は Mac mini で 24時間 動いてる 自動化プログラム。 サロン が ウィザード 完走 した 60秒後 に 自動的 に サロン用 環境 を 作って、 オーナー の LINE に 「次これ送って」 メッセージ を 流す。 あなた が 起動 したり 監視 する 必要 は ない。

CHAPTER 05

LINE 接続 を 仕上げる (難所)

ここ だけ は 完全 自動化 できて いない。 サロン が 持って いる LINE 公式 アカウント の 「鍵」 4種類 を 預かって、 admin に 入れる。 1サロン 15分 くらい かかる。

サロン から 預かる 4つ の 鍵

  • チャネルアクセストークン (長期) — 英数字 200文字 ぐらい の 長い 文字列
  • 公式アカウント ID — 例 @062yzmhp
  • LIFF ID — 例 2010266648-iX5kooZe (これ だけ サロン側 で 新規作成 が 必要)
  • 通知先 LINE userId — オーナー本人 の userId、 「U」 で 始まる 32文字
1
サロン側 (依頼)

サロン に LINE で 「鍵 4つ 教えて ください」 と 依頼

サロン が 自分で LINE Developers Console を 開いて 取得 する 必要 が ある。 手順書 を 送る:
LINE 連携 の 仕上げ に 4つ の 情報 が 必要 です。 下記 の 手順書 通り に 取って お知らせ ください:

📘 取得手順 (10分): https://t35ty6-rgb.github.io/skeleton-demos/femoon-saas-setup/

① チャネルアクセストークン
② 公式アカウント ID (@xxxxxx)
③ LIFF ID (2010xxxxxx-xxxxxxxx)
④ 通知先 LINE userId (オーナー様 ご本人)

※ 質問 あれば 何でも 聞いて ください。
2
あなた

サロン から 4つ 届いたら admin に 入れる

サロン の admin (https://skeleton-femoon-saas.web.app/admin/?tenant=○○○) に サロン の Email + パス で ログイン → 上部タブ 「設定」 → 「LINE 連携」 セクション。
サロン の パスワード は あなた も 知らない。 設定 入力 だけ なら オーナー が 「臨時 で パス 教えて ください」 と サロン に LINE で 確認 する。 入力後 サロン側 で パス変更 して もらう。

または Firestore 直 編集: Firebase Console > Firestore > tenants/{tenantId} の 下記 フィールド を 直接 書き換える 方が 安全:

tenants/{tenantId} に 書き込む 4 fields

  • lineMessagingToken ← チャネルアクセストークン
  • lineOfficialAccountId ← 公式アカウントID
  • liffId ← LIFF ID
  • ownerLineUid ← 通知先 userId

同時 に tenants/{tenantId}/public_config/meta の lineMessagingToken / ownerLineUid / liffId も 同じ値 で 更新 (予約フォーム 側 が ここ を 読む)。

3
あなた

サロン の LINE リッチメニュー に 予約URL を 紐付ける

サロン から LINE Official Account Manager の 一時 ログイン情報 を 預かる か、 LINE で 画面共有 しながら 一緒に 操作 する。

手順 (3分):

リッチメニュー設定

  • https://manager.line.biz/ に サロン の LINE アカウント で ログイン
  • 該当 公式アカウント 選択 → 左 「リッチメニュー」
  • 「作成」 → 画像 アップ (デフォルト 画像 で OK、 後で 変更可)
  • テンプレ 「大」 → 左セル に 「リンク」 アクション 設定 → URL に https://liff.line.me/{LIFF ID} を 貼る
  • 表示テキスト 「ご予約」 / 上書 / 即時 ON で 保存
LIFF URL ではなく 予約フォーム URL を 直接 貼っちゃダメ。 LINE 内 で 開くのは liff.line.me/... 形式 だけ。 これで お客様 の LINE userId が 自動 で 取れて、 予約完了通知 が 届く ように なる。
CHAPTER 06

動作 確認 (5分)

セットアップ が 終わったら 必ず テスト 予約 を 入れて 通知 が 届く か 自分 の 目 で 確認。 サロン に 渡す 前 の 最終 関門。

確認チェックリスト

  • 自分の LINE で サロン の 公式アカウント を 友達追加
  • リッチメニュー 左の 「ご予約」 ボタン タップ → 予約フォーム が LINE 内 で 開く (Safari/Chrome で 開いたら NG → LIFF URL 設定 ミス)
  • テスト予約 を 1件 入れる (お名前 「テスト」 等)
  • 確定後 自分の LINE に カード型 「ご予約 ありがとうございます」 通知 が 届く
  • カード の 「カレンダー に 追加」 ボタン タップ → Google カレンダー の イベント追加 画面 が 開く
  • 同時 に サロン (オーナー指定 userId) にも 「新規 予約 が 入りました」 通知 が 届いて いる
  • admin にログイン → 予約タブ で テスト予約 が 表示 されて いる

全部 ✓ ついたら サロン に 「LINE 連携 完了 しました、 使えます」 と 連絡。 テスト予約 は 後で キャンセル で 消す。

CHAPTER 07

困った時 (FAQ)

よくある 詰まり ポイント と 対処。 解決 しない 時 は オーナー or Jobs に LINE で 「申込番号 ○○ の ここ で 詰まった」 と 投げる。

watcher の LINE通知 が 届かない
Mac mini が 起動 してる か 確認 (LaunchAgent com.skeleton.femoon-watcher)。 起動 して いれば 60秒 以内 に 新規 申込 を 拾う。 Mac mini が 落ちて いる 場合 は 復旧後 まとめて 処理 される。 申込 データ 自体 は Firestore に 残って いる ので 失われない。
サロン が 「パスワード設定 リンク 開けない」 と 言ってきた
リンク は 1回 のみ 有効 (1時間)。 期限切れ なら 再発行: Firebase Console > Authentication で 該当 ユーザー の 「︙」 → 「パスワード再設定 リンク 送信」。 または スクリプト node ~/.skeleton-femoon-watcher/regen-reset-link.mjs <email> で 再発行 可。
サロン が 「ログイン できない」 と 言ってきた
まず メアド を 確認 (申込時 と admin ログイン に 使う メアド は 同じ?)。 typo の 可能性 が 一番 高い。 次 に admin ログイン画面 の 「パスワード を お忘れ の方 は こちら」 リンク を 押して もらう → サロン の メアド に リセット メール が 自動 で 飛ぶ → メール の リンク から パス 再設定。
テスト予約 入れたけど 通知 来ない
99% は LINE 4つ の 鍵 の どれか が 間違って いる。 admin 設定タブ で:
① チャネルアクセストークン は サロン に 最新 を 出し直し もらう (古い と 失効してる 可能性)
② ownerLineUid が 「U」 で 始まる 32文字 か
③ public_config/meta にも 同じ token が 入って いる か
で 確認。 サロン が 友達追加 してない LINE OA から は 送れない (404) ので、 通知先 userId の 人 が 公式 アカウント を 友達追加 してる か も 要確認。
決済 が 「unpaid」 のまま
サロン が Stripe Checkout 画面 まで 行って カード入力 せず に 抜けた 状態。 オーナー が サロン に LINE で 「決済 まだ 完了 してない みたい、 もう一度 ウィザード 末尾 から 試して」 と 連絡。 tenant は 既に 作成 されてる ので 同じ メアド で 再ログイン すれば そのまま 使える、 決済 だけ Stripe で 完了 すれば tenants/{id}.billing.status が active に なる。
サロン が LIFF を 自分で 作れない / 詰まった
LIFF 作成 は 一番 詰まり やすい。 詳細手順書 femoon-saas-liff-setup を 送る。 それでも 詰まったら オーナー が サロン と Zoom で 画面共有 で 一緒 に やる。 LIFF だけ は 完全代行 が 難しい (LINE アカウント の 持ち主 しか 操作できない 仕様)。
サロン から 「解約 したい」 と 言われた
Stripe Dashboard > Subscriptions で 該当 サブスク を 探して 「キャンセル」 (期間末 か 即時 か 確認)。 同時 に tenants/{tenantId}.status を 'canceled' に 変更。 サロン の admin は 月末 まで 使える (Stripe 仕様)。
完

これで 1サロン 開通 完了。

分からない こと が 残って いれば 絶対 に サロン に 渡す 前 に オーナー / Jobs に 確認。 半端 な 状態 で サロン に 渡す と 信頼 が 落ちる。 5分 待って もらえば 解決 する。
