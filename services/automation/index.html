Features

5つの機能。

単機能を5つ束ねた、現場特化のSaaSです。サロン業界での実運用で揉まれた仕様。

1分以内のLINE通知

予約メール受信 → 1分以内にスタッフのLINEグループに通知。遅延ゼロを目指す設計。

Googleカレンダー自動登録

予約日時・顧客名・メニュー・担当を含むイベントを自動作成。キャンセル時は自動削除。

4サイト同時監視

ホットペッパー / 楽天 / minimo / EPARK の4予約サイトをまとめて1つのGmailで監視。

週次ヘルスチェック

毎週月曜9時、過去7日の処理件数と稼働状況をLINEにサマリー送信。「動いてるか不安」を解消。

fixAndDiagnose

1コマンドで全機能の動作診断 + 4サイトのテスト予約を投入。納品時の動作確認に使用。

月次レポート

月初に「先月の予約件数・キャンセル率・人気メニュー」をLINEで配信。経営判断のヒントに。

How it works

導入の5ステップ。

申込から本番稼働まで、Skeleton側で進められるところは全部代行します。

STEP 01 / 申込時

申込フォームに記入

客は申込フォーム(マルチステップ式・約5分)で必要情報を入力。サロン情報・予約サイト・既存メアド等を申告。

STEP 02 / 準備期間

専用Gmail・LINE公式アカウント開設

客が用意する形(画像つきマニュアルあり)。Skeleton側でGAS構築のための鍵類を準備。

STEP 03 / 客のドライブにGASクローン

6ファイルをコピペで配置

Config.gsには申込内容(LINEトークン・グループID)が事前焼き込み済み。手書きゼロでセットアップ。

STEP 04 / 当日納品

15分の現場作業で稼働開始

installTriggers実行 → setupSiteCalendars実行 → fixAndDiagnose で動作確認。LINEに4種類のテスト通知が届けば完了。

STEP 05 / 納品後

月次保守 + サポート

稼働状況の監視・LINEトークン期限管理・パーサ更新・トラブル対応はすべてSkeleton側。客は通知を受け取るだけ。
