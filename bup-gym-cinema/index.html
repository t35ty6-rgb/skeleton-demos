Chapter I — The three pillars

Body, reimagined—
from three angles. 流行 の トレーニング でも、 短期 の 数字 でも なく。

「壊さず 続けられる 日常」 を 一緒 に 組み立てる。 BODY · BEAUTY · BALANCE の 3 軸 が、 その 骨格 です。

Body.体 を、 整える。

呼吸 · 体幹 · お尻 · 脚 の 順 で、 自分 の 身体 を 使った トレーニング を 段階的 に。 マシン に 頼らず、 産後 や 40代 の 身体 に 無理 の ない 強度 で 積み重ねます。

Posture.姿勢 と、 佇まい。

「痩せない」 「疲れやすい」 の 原因 の 多く は、 姿勢 の 崩れ と 筋力 の アンバランス。 骨盤 · 肩 · 脚 の バランス を 整え、 立ち姿 · 歩き方 · 座り姿 を リ · デザイン します。

Daily.続けられる 日常。

週1 でも、 月2 でも、 「行ける ペース」 で。 美肌食 マイスター視点 の 食事 アドバイス と セット で、 極端 な 制限 なし。 「日常 の 自分 が 少しずつ 好き に なれる」 変化 を。

Chapter II — Who this is for

こんな 方 に、
来て ほしい。 誰か の 視線 が 気になる、 マシン に 慣れない、 一度 続かなかった。

そんな 「大手 が 苦手 な 人」 の 声 から、 この スタジオ は 始まりました。

  • 01
    産後、 体型 が なかなか 戻らない 抱っこ や 授乳 で 崩れた 姿勢 と 筋力 を、 負担 の ない 範囲 から 少しずつ。 骨盤 の 開き · 反り腰 · 猫背 に、 特に 丁寧 に 向き合います。
  • 02
    40代、 代謝 の 変化 を 感じる 「同じ 食事量 なのに 落ちない」 その 原因 は、 たいてい 筋肉 と 姿勢 です。 短期 の ダイエット じゃなく、 3年後 の 自分 に 効く 積み方 を。
  • 03
    大きな ジム が、 少し 苦手 鏡だらけ の 空間 や、 慣れない マシン、 周り の 視線 が 苦手 な 方 こそ。 マンツーマン、 完全 個室、 会話 しながら できる 強度 が 基本 です。
  • 04
    ダイエット で 失敗 した 経験 「早く 痩せる」 より 「壊さず 続けられる」 やり方 を、 一緒 に 組み立てます。 リバウンド の 原因 を、 姿勢 と 筋力 と 食事 の 三点 から 潰します。

Chapter V — The session

60分、 四つ の
ステップで。 話す · 見る · 動く · 整える。 その日 の 体調 に 合わせて。

01Consult

まず は、 じっくり 話 を 聞く こと から。

所要 約10分

今日 の 体調、 これまで の ダイエット歴、 生活リズム、 睡眠、 食事 の 傾向 まで、 一つずつ 丁寧 に 整理 して いきます。 特に 初回 は、 産後 の 身体 状態 や 過去 の 怪我 なども お聞き し、 無理 の ない スタート地点 を 一緒 に 決めます。

「早く 始めたい」 より も 「正しく 始める」 を 大切 に して いる ので、 ここで 急ぐ こと は ありません。

02Posture

骨盤 · 肩 · 脚 の バランス を 丁寧 に。

所要 約10分

「痩せない」 「疲れやすい」 の 原因 の 多く は、 姿勢 の 崩れ と 筋力 の アンバランス に あります。 鏡 の 前 で 立ち姿 · 座り姿 · 歩き方 を 確認 し、 どこに 癖 が あるか、 どこ の 筋肉 が 使えて いないか を 見極めます。

産後 の 方 は 特に、 骨盤 の 開き や 反り腰、 抱っこ に よる 猫背 が 定着 しがち。 ここで 見つかった 課題 が、 そのまま トレーニング の 優先順位 に なります。

03Train

その日 の 体調 に 合わせて、 自重中心 で。

所要 約30分

マシン は 一切 使いません。 呼吸 · 体幹 · お尻 · 脚 の 順 で、 自分 の 身体 を 使った トレーニング を 段階的 に 組み立てます。 強度 は 「翌日 に 響かない ギリギリ」 を 狙って 調整 する ので、 続けやすさ が 違います。

体力 に 自信 の ない 方 でも、 5分 ごと に 小休憩 を 挟みながら 進める ので 大丈夫。 会話 しながら できる 強度 が 基本 です。

04Cool

ストレッチ と、 次回 まで の 過ごし方。

所要 約10分

トレーニング後 は 入念 に ストレッチ。 当日 〜 翌日 の 身体 の 変化 を 最小限 に 抑え、 次 の セッション まで 良い 状態 を 保てる よう に します。

最後 に、 次回 まで の 「今日 から 意識 する こと」 を 1〜2個 だけ お伝え します。 食事 の ちょっとした 置き換え、 日常 での 姿勢 意識、 寝る前 の 1分 ストレッチ など、 無理 なく 続けられる 範囲 で。
