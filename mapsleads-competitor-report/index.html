提案 3 案 (owner 判断 用)

A 実店舗 pattern (シンプル化) Jobs 推奨
h1 = 店名 (or「【地域】の【業種】」) だけ · eyebrow = 「【地域】· 【最寄駅 徒歩◯分】」 の 現実情報 · sub = 1文 で 特徴 (「◯分」「◯種類」「◯年」等 の 具体数字)。
→ Jobs の 創作 排除。 事実 1-3 に 完全 依拠。 「クソ」の 原因 が Jobs の 尖り 過剰 由来 なら 一発 で 解決。
B RIZAP · BEYOND pattern (「一文で 生活を語る」)
h1 = 15-25字 の 「感情 + 断定」 (「変わるよろこびを、あなたの毎日へ」型)。 逆説 · 尖り 排除、 「感情 + シンプル」 に 徹底。
→ 実 pattern に 忠実 だが、 小規模店 に 「うち の 店 が RIZAP みたい」 と 感じさせる リスク。
C 現 v0.9.3 (30社 verbatim 派生) 継続 + 微調整
現状 の 「カウンセリング、30分から。」「豆を、その日焙煎する店。」等 は 実 pattern に 近い が owner「クソすぎる」判定 で reject 済。
→ 一部 業種 だけ pick して 差替 が 可能。
